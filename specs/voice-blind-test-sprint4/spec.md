## 现状（调研结论）
- **英语已搁置**：ASR 与发音评测最主要的使用方（开口成章）暂停；“讲给老师听”（SIE-02a）与语文朗读是其他潜在使用方，都还没有语音功能。
- **没有任何语音代码与供应商**：ADR 08 盘点“Gemini、流式 ASR、第三方 TTS / 评测全仓库零命中”；`docs/compliance/vendors.md` 为空；本环境无凭据（规则 9）。
- **盲测需要真实学生语音**，而监护人同意流程与用途分项授权（`purpose_grant`）尚未上线；学生语音属于个人信息（L2 / L3），声纹不得用于任何推断（规则 12）。
- **语音分钟计量的配置已有**：0008 / 0015 已登记资源 `voice_realtime`（按分钟、向上取整、`voice` 池、各档额度），但没有任何调用方；预留 / 结算 / 回滚沿用通用计量函数。

## 设计要点
### 1. 盲测方案（文档，本任务交付）
- 候选：ASR、音素级发音评测各三家境内候选（名单由人按 ADR 04 / 08 签字确定，本任务不选）；TTS 不在本冲刺。
- 测试集：
  - **第一阶段（本任务可做）**：合成与授权公开语料——由项目成员（成人）录制的朗读与对话脚本、公开授权的中英文语音集（许可证逐一核对）；覆盖普通话、带南京口音的普通话、初中英语朗读与对话；
  - **第二阶段（同意流程上线后）**：经监护人书面同意、用途分项授权的学生语音，只在境内环境处理，评测完删除原音频，仓库只收汇总。
- 指标：ASR 字错率 / 词错率（中文 CER、英文 WER，分口音、分噪声条件）、实时率与首字延迟 p50 / p95；音素评测与人工专家标注的一致性（音素级准确率、句级分数相关系数、错误检出的召回与精确）；成本（每分钟单价）；合规条款（境内部署、不用于训练、数据保留期、删除承诺）。
- 盲测方式：执行人按随机编号提交，评分人不知道供应商；每家同一批音频；结果带置信区间。

### 2. 评测框架 `evals/voice-blind/`（本任务交付，只用合成数据验证）
- 供应商适配接口（不含任何具体供应商实现与密钥）；输入清单（音频引用、参考文本、口音标签），输出统一结果格式；
- 指标计算：CER / WER（编辑距离，中文按字、英文按词，标点与大小写规则可配置）、延迟分位数、音素一致性（与专家标注对齐）；自助法 95% 区间，固定种子；
- 报告：Markdown + JSON，只含汇总、按条件分组的指标与样本编号，不含音频、转写原文（第二阶段）、任何个人信息；
- 用合成“假供应商”（对参考文本做确定性扰动）证明指标计算与报告正确；标注“流程样例，不是评测结论”。

### 3. 语音分钟计量（本任务做规则与校验，不接供应商）
- 口径沿用 0008 / 0015：`voice_realtime` 按分钟向上取整、`voice` 池；本任务只写一个平台侧的计量辅助（按预计分钟预留、按实际时长结算、失败回滚、幂等键），接在尚不存在的语音会话之前，用合成调用证明预留 / 结算 / 回滚与幂等；**不改任何计量函数与额度**（必停项）。
- 语音能否计入“AI 互动时长”等其他资源、宵禁与单日上限对语音是否一样，列待人确认。

## 范围
### 做
盲测方案文档（候选筛选标准、测试集设计、指标、盲测流程、合规清单、执行手册）；`evals/voice-blind/` 框架与合成验证；语音分钟计量辅助与幂等测试；lessons。
### 不做
选定供应商、接入任何 ASR / TTS / 评测服务、采集或处理任何学生语音（等同意流程与 ADR 签字）；声纹或音色相关的任何分析（规则 12）；英语适配器；改计量函数或额度。

## 验收标准（可测试）
- [ ] 方案文档覆盖候选标准、两阶段测试集、指标、盲测流程、合规清单与执行手册；明确第二阶段前提（同意流程、用途授权、境内处理、删除）。

- [ ] 计量辅助：按分钟向上取整、预留 / 结算 / 回滚、同一幂等键重放不重复扣（库上测试，沿用现有计量测试做法）。
- [ ] 不联网、不持有密钥（测试断言）；严格 `make check`、安全审查通过；真实盲测报告与选型建议不在本任务通过条件里（第二阶段由人执行后补）。

## 涉及的必停项
- **新增第三方服务 / 模型供应商 / 数据出境**：本任务不接任何供应商；候选名单与接入另走签字。
- **计量**：只加调用辅助，不改规则；PR 首行 `[NEEDS-HUMAN]`。**个人信息**：本任务不处理任何学生语音。
