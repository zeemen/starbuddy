## 范围
1. **BFF**（`services/bff`）：
   - `GET /bff/v0/students/{id}/monthly-plan`（家长）：先按本人会话确认有效绑定家长（学生会话在请求体、CSRF、限流之前回与“不存在”逐字节相同的 404，沿用第 1 步 `guardianOnly404`）；
     本月无快照时调洞察服务 `POST /internal/v1/monthly-plan/generate`（带 actor = 当前家长账号），再经 `insight.monthly_plan_guardian_view` 读；
     无权益返回 `entitled: false`（前端显示升级说明占位），不泄露其他信息。
   - `GET /bff/v0/students/{id}/my-plan`（学生本人）：只经 `insight.monthly_plan_student_view` 读；本月无快照时不触发生成，返回空状态（生成只由家长端或调度器触发）。
   - 渲染：BFF 把模板键与变量渲染成文字（模板库与洞察服务同一份文件，按指纹核对版本一致，不一致按不可用处理）；
     成品句子再过禁用推断词表与“名次 / 概率 / 承诺”词表，命中则该条不出并记计数（不记内容）。每条关于学生的句子带 claim_id，前端以 `data-claim-id` 渲染，沿用“为什么 / 我不同意”入口。
   - 开关 `STARBUDDY_MONTHLY_PLAN=monthly_plan`，只在 dev/test，其他环境设了拒绝启动；关时两条路由不注册。不计量。路由并入 `activeRoutes` 与授权矩阵。
2. **前端**（`apps/web`）：
   - 家长端 `family/[studentId]/monthly-plan`：四块——本月诉求摘要（只读，链接到“我的诉求”）、上月回顾、学生学习计划、家长注意事项；分差以区间显示；无权益显示升级说明占位。
   - 学生端今日页或科目页加“本月计划”入口，页面只显示学生学习计划（优先知识点、每周节奏、复测与小复评安排）。
   - 文案全部 `{{TODO_COPY:monthly_plan.*}}`；学生端 DOM 不出现诉求、注意事项、回顾、分差、关注学科系数（静态测试 + e2e + `expectNoDomLeak`）。
3. **测试与变异**：BFF 单测与集成测试（生成触发只在家长、本月已有快照不再调、无权益、洞察服务不可用、模板指纹不一致、词表命中）；BFF 变异组“月度计划：”；e2e 一套开关打开（合成种子：Pro 家庭有判断与掌握数据），axe 与 DOM 泄露检查；Gate 0 若计数变化告诉我。

## 不做
- 调度器、导出、家长端编辑计划、学生调整计划、模型生成文字、填真实文案。

## 验收
- 开关关时现有页面与响应不变；家长打开即生成且同月只生成一次；学生只看到学习计划；
- 每条关于学生的句子带判断 ID 且可点开“为什么”；成品句子过两张词表；严格 `make check` 通过。
