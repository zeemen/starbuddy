# PLT-14 家长诉求与月度改进计划

2026-10-10 用户提出：家长端增加诉求（偏科、学科目标分数、目标学校等），系统根据学生成绩与测试，按月给出学习改进计划，
同时包括家长注意事项、学生学习计划等不同维度。编号 PLT-14 为本任务首次使用（PLT-13 留给调度器）。

## 用户确认的口径（2026-10-10）
1. 家长诉求（目标分、关注学校、关注学科、补充说明）**学生看不到**；只影响计划的优先顺序，学生端只看到自己的学习计划。
2. 目标分按**学校考试分科分**（月考 / 期中 / 期末），与已有成绩录入对比；中考总分不做。
3. 计量：按权益规格书，**Pro / Max 自动月报**，自动生成不计次；需新增套餐开关（迁移）。
4. 文字全部**固定模板**按条件填空，不调模型；文案由人写人审。

## 依据
- 增补篇（docs/plan/平台规划-v1.3增补篇-升学导航与家庭支持.html）：目标只进入跨科 ROI 权重（:346），差距分解到科、到知识点（:136、:152），
  按年级开放（:349-354），家长自述不进学生模型（:171、:422），不给名次、录取概率、提分承诺（:167），差距须与“下一步做什么”同屏（:168），
  学生与家长各设目标、系统不裁决（:360-363），协同看板即周报（:428）。
- 权益规格书 V1.2 :147：月度学情报告（自动）只给 Pro、Max；SIE :460 每月分科小复评；SIE :506 家长看“一条具体配合建议”。
- 现有可复用：成绩录入与预测对账（0022 `exam_record`、0034）、家长周报（0036，只由判断渲染）、policy 招录库（0013、0045–0052，无数据）、
  今日计划读时汇总（PLT-11）、掌握与复测（KGE-04/05）、判断账本与 explain。

## 硬约束（不随本任务改变）
- 规则 11：页面上每句关于学生的话都引用一条“成立 / 假设”判断；计划条目只陈述“做什么”，不陈述学生“是什么”。
- 规则 12：“偏科”不作为标签出现；只用“X 科有 N 个知识点待点亮 / 本月优先”这类基于节点判断的事实句。
- 规则 6：家长诉求存为家长自述，与学生自述、客观成绩分表存；两边说法不同两边都存。
- 不出现名次、录取概率、提分承诺、同伴比较；目标学校只显示招录库已发布的事实（往年线、计划数），不算“够不够得着”。
- 文案全部模板渲染（`{{TODO_COPY}}` 占位，人写人审），不调模型。

## 拟分三步（每步单独提交）
1. **家长诉求收集**（迁移，必停）：家长端表单与存储——关注学科（最多 2 科）、分科目标分（学校考试口径，可选）、关注学校（引用 `policy.school`，初一初二只能“认识高中”，初三起可选）、补充说明（短文本，长度上限，禁用推断词表过滤）。学生不可见（字段与 DOM 均不出现在学生端）。
2. **月度计划生成**（迁移 + 判断模板，必停）：每月 1 日（或家长首次提交诉求后）由编排层确定性生成快照并落库：
   - 学生学习计划：本月优先知识点（跨科 ROI：缺口 × 考情分值权重 × 频率；关注学科与目标作为权重项）、每周节奏（复用今日计划预算）、本月复测与小复评安排；
   - 家长注意事项：从固定模板库按条件选取（例如“本月复测 N 次，请保证每周 X 天、每天 Y 分钟的安静时段”），不对孩子作评价；
   - 回顾：上月计划完成情况（以事实计数呈现）、本月目标与当前成绩的差距（分数区间，不给概率），与下一步同屏。
3. **家长端页面与学生端**：家长端“月度计划”页（含诉求、回顾、学生计划、家长注意事项）；学生端只看自己的学习计划部分，不出现家长诉求与家长注意事项；Pro / Max 才生成，其他档显示升级说明。

## 不做
- 中考总分分数带、四档标签、志愿推荐（属去向层，需南京数据回填与校准）。
- 人设口吻的“家庭成长顾问”话术、模型生成文字。
- 学生端看到家长的目标分、关注学校或家长注意事项。

## 验收（每步）
- 迁移在副本演练、RLS 测试附上；家长只能按 guardian_student_link 读写；学生不可见字段在 DOM 中不出现。
- 计划生成确定性、可重放；每句关于学生的陈述可追到判断 ID；禁用推断与“名次 / 概率 / 承诺”词表测试通过。
- 套餐开关按 Pro / Max 生效，生成幂等（同一学生同一月份只一份快照，重跑不写新行）；严格 `make check` 通过。
