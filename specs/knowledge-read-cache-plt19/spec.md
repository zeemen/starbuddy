# PLT-19 公共层只读缓存 · 第一步（知识服务进程内缓存，开关缺省关）

2026-10-18 起由 Claude 按用户授权自主推进（开发计划 v2.0 阶段 1 · 5 月“增长工程：队列、缓存”；风险表“成本高于可承受 → 页面缓存”；完整方案“页面缓存按节点、版次、地区分键”）。
编号 PLT-19 为仓库排队号。零迁移、不改契约（响应字节不变）、不碰个人层、零新依赖（ADR 10 / ADR 06：不引入 Redis 等外部存储）。

## 现状（只读摸底）
- 全仓无响应缓存：BFF 全部 `no-store`；前端全部 `cache:'no-store'`；唯一的进程内 LRU + TTL 在 `services/learning/learning/present_item.py`（题面，按学科 × 题号 × 内容版本）。
- 知识服务：页面快照目录不可变（换提交即换目录、文件 0444），热切换是一次引用赋值，每请求开头取一次快照；地图每科只有一个已发布版本，已发布版本的节点与边冻结。故（`map_version_id`，页面快照 commit）可作缓存键。
- 公共层读工具：`node.get`、`node.path`、`page.get`（结果依赖 edition / region）可按版本缓存；`item.search`、`item.similar`、`rubric.get` 在同一地图版本内结果会变（审核、时政每日下架），不缓存。

## 范围（`services/knowledge`）
1. 新建 `knowledge/service/cache.py`：进程内 LRU（照 `present_item.py` 写法），容量与开关集中在配置（`config.py`，开关缺省关；关时行为与响应逐字节不变）。不设 TTL：键含版本，版本变则自然失效。
2. 只缓存 `node.get`、`node.path`、`page.get`：
   - 键 = 工具名 + 学科 + `map_version_id` + 页面快照 commit（仅 `page.get`）+ 规范化请求参数（排序键、去掉 `request_id` / 调用方等每请求字段；edition、region 必须入键）；
   - 每次请求仍先查一次 `published_version`，保证发布、撤下即时生效；撤下（retired）或版本变化后旧键不可再命中；
   - 只缓存成功结果；错误、空结果中依赖时间的部分、带 `request_id` 回显等每请求字段不入缓存（命中时按请求重新填写）；
   - 命中时返回深拷贝或不可变结构，调用方修改不能污染缓存；
   - 热切换页面快照时清空 `page.get` 相关条目（键已含 commit，清空只为释放内存）。
3. 观测：命中 / 未命中 / 淘汰计数（按工具），进访问日志或现有指标出口；不含调用方的学生信息（这些工具本就不含个人层参数，须测试断言请求参数中出现学生 ID 类字段时不缓存并告警）。
4. 测试：
   - 开关关：现有测试全部不变；开关开：命中与未命中返回逐字节相同（去掉每请求字段后）；
   - 版本发布 / 撤下 / 热切换后不返回旧值；edition、region 不同不串；不缓存的工具确实不缓存；LRU 容量与淘汰；并发访问安全（若服务为异步单线程则说明理由）；
   - 变异接进 `knowledge-mutation`（或新增 `knowledge-cache-mutation`）：键漏 edition / region / map_version_id / commit、不查 published_version、缓存错误结果、返回同一对象、热切换不清空等。
5. `tools/loadtest`：可选加一个知识读场景（合成），用于对比开关前后 p95；不进 check。

## 不做
- BFF 或前端的 ETag / 304 / Cache-Control（需改响应头与契约评审，第二步）；个人层任何缓存（星图星态、今日计划、档案页、周报）；`item.*`、`rubric.get` 缓存；多实例共享缓存；通用任务队列。

## 验收
- 开关关时行为不变；开关开时命中结果与未命中一致、版本变化即时生效；变异全部发现；严格 `make check` 通过。
