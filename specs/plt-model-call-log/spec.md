# PLT 模型调用记录落库（platform.model_call_log）

2026-10-26 起由 Claude 推进。背景：模型路由的调用记录（`services/learning/learning/model_router/ledger.py`）目前只写结构化日志与内存；成本仪表盘（specs/cost-dashboard-plt17）与压测 RUNBOOK 都以“另起任务落库”为前提，内测期间需要可对账的模型花费与失败率。提交首行 `[NEEDS-HUMAN]`（迁移、权限）。

## 范围（默认，待人确认）
1. **迁移草稿**（下一编号）`platform.model_call_log`：只存元数据——时间、环境、任务类型、数据级别、学科、供应商、模型、版本、`model_version`、提示词模板与版本、结果（ok / failed / budget_exceeded / unavailable / …）、尝试次数、是否切备、各尝试的错误类别、输入 / 输出 token、估算成本（元，无单价为空）、耗时、`usage_ref` / `idempotency_ref`（与现有 sha256 截断一致）。**不存提示词、对话原文、作答内容、学生 / 账号 ID**（ADR 04 增补第 6 条）。按月分区或 BRIN 索引；RLS 开启，只学习服务角色可 INSERT（列级），成本导出与运营只读经 SECURITY DEFINER 聚合函数（不直接读行）。留存 180 天，到期由调度器任务批删（任务定义随本任务，时间表签字后启用）。
2. **写入**：`ledger.py` 新增 `DbSink`，与 `LogSink` 组成 Tee；写库失败只记计数与日志、不影响路由结果（异常隔离，与 LT-05 计量计数同口径）；批量 / 异步写入避免拉长调用耗时（有界队列，满了丢弃并计数）。
3. **对账**：调用记录的 `usage_ref` 能与计量账本对上（同一 sha256 截断规则），补一条只读对账函数草案（按日、按任务的次数与 token 汇总）。
4. **指标与告警**：写库失败、队列丢弃计数接入 LT-05 指标清单与告警。
5. **测试**：库测试（越权、列级、RLS、留存删除只删过期行）、变异；学习服务单测（Tee、异常隔离、队列满丢弃、不含禁止字段的静态扫描）；deploy 一致性。
