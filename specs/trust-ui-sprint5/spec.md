## 设计要点
### 1. “为什么”（学生端、家长端）
- 入口：星的详情、今日计划理由、首份报告每句旁；点开调 BFF → `insight.explain`（按受众可见范围，家长带 `link_id`）。
- 展示：结论句（模板渲染）、状态与置信度说明（学生看“初步判断 / 待验证”，家长另附置信度说明）、证据链（证据种类、时间、提示等级；题目以编号与节点名呈现，**不展示逐句对话**）、依据版本。看不到的判断连存在都不暴露（沿用 0010 与 SIE-02b）。

### 2. “我不同意”（三条路）
- 学生本人、已绑定家长对自己可见的判断发起；三个按钮对应 `i_know` / `careless` / `data_error`，文案由人提供（必停，签字前用明显占位）。
- 我其实会：提示“24 小时内会安排 2 道验证题”，验证题进入今日计划（不单独推送）；结果出来后判断页显示“支持 / 不支持”与新证据。
- 那次是粗心：只记录学生自述，界面不出现任何“粗心”标签或评价；不改判断。
- 识别错了 / 分数录错了：打开原始事实（作答、成绩录入）供选择更正项，提交进复核队列；显示处理状态。
- 异议状态页：列出自己提出的异议与状态；可撤回未处理的异议。

### 3. 对账卡界面
- 考试录入（范围节点、日期、满分；学生或家长）→ 考前显示“已冻结的预测区间”（80%，学生版只显示区间，家长版附置信度说明）→ 成绩录入后显示对账卡：区间内 / 外、偏差来自哪些节点、平台据此改了什么、偏差方向（四方向之一）；每句带判断 ID（前端断言，无 ID 的句子不渲染）。
- 冻结后的预测只读；七八年级 100 分制、九年级 120 分制。

### 4. 跨科周报 v0
- 学生版“成长手记”：本周点亮了什么、正在攻克什么、下一步；家长版：本周进展、当前卡点、一条具体配合建议、预测与对账摘要。
- **只由判断渲染**：周报 = 固定结构 + 衔接短语 + 判断渲染句，每句带判断 ID；生成后过陈述—判断一致性检查与禁用推断词表（复用 SIE-02b 报告管线），任一不过则不出周报。家长版不含逐句对话、同伴比较、排名、层级标签；学生版不含家长问卷与家长评价（SIE 第八章“看不到”）。
- 生成：洞察服务每周定时任务生成结构化内容（句子数组）并存快照（新增 `insight.weekly_report` 或复用首份报告存法，#3）；审核抽检接统一复核队列（抽检比例 #4）；首发只含数学两维 + 各科使用时长与计划完成（后者是客观记录，不是判断，单独一栏并注明来源）。
- 跨科：各科只在有已发布地图与可见判断时出现；英语不出现（搁置）。

### 5. 家长端数据权利入口
- 画像数据查看、导出（SIE-03 JSON 包下载）、删除申请（二次确认、冷静期倒计时、可撤回）、监护操作留痕列表；只对已绑定有效的孩子（规则 5）。

### 6. 功能开关与可用性走查
- 每块一个开关（why / dispute / reconcile / weekly / data_rights），默认关；4-H 的“预留验收”在开关关时继续成立。
- 可用性走查：按脚本（学生 5 个任务、家长 5 个任务）由产品在开发环境用合成家庭走查，记录结果到 lessons；本仓提供走查脚本与合成家庭种子。

### 不做

## 验收标准（可测试）
- [ ] 学生与家长各自能看到可见判断的“为什么”，证据链不含逐句对话；不可见判断不暴露存在性（E2E + BFF 测试）。
- [ ] “我不同意”三条路在合成家庭上端到端：我其实会 → 今日计划出现 2 道验证题 → 结果回显；粗心 → 界面无任何标签；数据有误 → 复核队列出现任务、处理后判断撤回并更新显示。
- [ ] 对账卡：冻结后只读；每句带判断 ID（无 ID 句不渲染的测试）；偏差方向只显示四值之一。
- [ ] 周报：每句带判断 ID；删掉或降为不可见任一判断，对应句子消失；禁用推断、程度升级任一命中则不出周报；家长版无对话原文、同伴比较、排名；学生版无家长问卷与评价。
- [ ] 家长只能对已绑定有效的孩子导出、申请删除；删除冷静期可撤回；监护操作留痕。
- [ ] 开关关闭时 4-H 预留验收继续通过；axe 无严重问题；严格 `make check`、安全审查、契约审查通过；可用性走查结果记录在 lessons（走查由产品执行）。
