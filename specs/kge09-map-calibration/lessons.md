## 交付
- `tools/kge-calibrate`（纯标准库）：
  - 前置边检验：强前置 A→B 比较“A 已掌握 / 未掌握”两组在 B 上的掌握率，Newcombe 区间、Benjamini–Hochberg；显著为正为“成立”，区间含 0 或按族校正后的上界低于效应量阈值为“不成立候选”，样本不足不出结论。弱前置只报告。
  - 隐藏依赖：同主题未连边节点对的 phi，有共同前置时只在共同前置（只算可计算且有观测的祖先）都已掌握的学生里计算，排除传递可达；两向都列为候选。
  - “掌握”口径与学习服务星亮同一：门槛 `transfer` / `retain`；导出函数草案按 `star_level_rule` 取星亮层次（与 `star_basis_level` 同口径），门槛与概率取同一行；不另设概率阈值。
  - 防泄露：报表无精确计数；人数向下取整到 10；四格加确定性表键扰动（±2），公开门槛每格 ≥ 22 保证真实 ≥ 20；任一格不足时结论只写“样本不足”；p 值分档；不含伪名。差分测试：删一人重跑，无法确定此人所在格。
  - 输入守卫：拒绝姓名、学校、手机号等字段；伪名 `^(syn|pil)-[a-z]{10,24}$`，`synthetic=true` 只收 `syn-`；读前 stat 限长；输出目录须为空、文件 0600 独占新建。
  - 合成队列生成器（固定种子）埋入成立前置、不成立前置、隐藏依赖；31 个种子：不成立前置召回 83/93、隐藏依赖 62/62、真成立前置确认 186/186、误报 0。
  - `RUNBOOK.md`、`sql/export-function.draft.sql`（另起 PR 的函数草案，库内生成一次性 salt）、`sql/export-mastery.readonly.sql`（只调用该函数）。
- 测试 124 项；变异 98 个全部发现；make 目标 `kge-calibrate-test`、`kge-calibrate-mutation`。

## 审查意见的处理（按默认）
- 契约阻断：“掌握”导出取各层次最高值、与星亮口径不同却写成相同 → 改为星亮层次规则同口径，删概率阈值路径；共同前置含不可计算节点时真实候选被压成“样本不足” → 只算可计算且有观测的祖先。
- 安全阻断：跨次/跨表相减可还原个人（实测删一人即还原 21 个节点）→ 去掉精确数、取整 + 表键扰动、差分测试；RUNBOOK 导出命令与自身前置条件冲突并引导真实数据“演练” → 改为只调用另起的函数，函数合并与守卫放开前不得真实导出；salt 经命令行与 SQL 文本可能入日志 → 库内生成。
- 建议采纳：伪名收紧、合成标记取自元数据、同意名单排序与删除排除、资源上限、输出文件权限、各组观测率、按族校正的置信水平。

## 与 spec 的偏差
1. 新增“按族校正后的区间上界 < 效应量阈值”也算不成立候选（总体能力会让任意两节点弱正相关，“区间含 0”在大样本下判不出）。
2. 隐藏依赖按共同前置分层（关掉会把兄弟节点误报）。
3. 新增表键扰动（不是差分隐私）；人数分档、比率保留两位、p 值分档。
4. 地图只收 JSON；掌握状态 CSV 的元数据行为本工具自定格式。

## 待人确认
1. **“掌握”口径**：沿用星亮门槛（transfer / retain、星亮层次规则），请确认适用于地图校准。
2. **阈值**：最小格 20、公开门槛 22、扰动 ±2 与分布、置信水平 0.95、FDR 0.05、效应量 0.1（绝对差，基础率极端时含义不同）、min_phi 0.3、节点对上限、误报上限——均为占位。
3. **扰动机制**：表键扰动能挡住删一人的差分，但不是差分隐私；残余风险：学生总数分档跨档会透露“少了一人”（不透露其掌握情况），观测率未纳入差分枚举。是否改用差分隐私并设隐私预算。
4. **导出函数**：SECURITY DEFINER 只读函数属权限变更，须另起 `[NEEDS-HUMAN]` PR；谁执行导出、何时放开 `synthetic=false` 守卫、同意用途是否覆盖“内容改进 / 聚合回流”、试点库是否属规则 9 的“生产”，由人定。
5. **总体能力混杂**：前置检验靠效应量上界缓解，隐藏依赖只靠 min_phi；真实数据上同主题节点 phi 可能普遍偏高；是否改用分层（如 Mantel–Haenszel）留待下一步。
6. **选择偏差**：编排可能因前置未掌握而少给 B 出题，“A 未掌握组”在 B 上的观测会自选；报告已给各组观测率供判断。
7. 隐藏前置会让某格天然偏小，最小格要求意味着试点规模需足够大。
8. 编号 KGE-09 为仓库排队号。

# 第二步实现记录（易错聚类与节点内部分化，spec-step2.md）

提交首行 `[NEEDS-HUMAN]`：第二个 SECURITY DEFINER 导出函数草案（读作答、判分、错因等个人层表；不合并、不执行，另起 PR），以及敏感编码与隐私口径的取舍。

## 交付
- 输入：作答行、错因行（只收合成样例，守卫与伪名规则同第一步；两表伪名完全不相交即报错；拒绝形似 UUID 的题目 ID）、易错点编码对照（教研临时口径，同一易错点只能映射一个跨科大类，以 kge 的 `error_type` 为准）。
- 错因分类表只读解析 `docs/mapping/error-taxonomy.md` 的生成表，含状态列；**待定与敏感编码（含 `xinli_xiguan`）解析时即丢弃**，不进检验与候选，工作单单列“不参与检验的编码”；学科不认识的行拒绝。
- 易错候选：节点上某编码占比显著高于主题基线且无易错点覆盖 → 新增易错点候选；已覆盖、对照缺失单独标注；低置信错因聚集 → 难归类信号（不提议新编码）。
- 节点内部分化：题目正确率最佳二分 + 参数自助法（上限 1e4 次，每节点题数上限 40），BH 校正；再用 **H 比值**（两群之间 Loevinger H ÷ 群内两半 H 均值）区分“两种能力”与“同一能力的难易分档”，比值 ≤ 0.5 才判拆分；错因两群作加强证据。
- 防泄露：沿用第一步；题目人数门槛 24（两格扰动余量）；答对、答错两格都 ≥ 22 才给精确正确率，否则只给分档；同一节点各编码表共用行合计扰动；差分测试覆盖新输出与多表联合。
- 导出草案：错因与作答同口径（独立、A 级、无提示、首次作答），排除需人工复核、低置信判分与猜对；按学生 × 节点 × 编码去重；附题目认知层次；只放行可用编码。
- 第一步节点对扫描跳过没有掌握数据的主题。
- 测试 235 项；变异 194 个全部发现；21–31 个种子上三类结构全部找出、0 误报，难度分档从未判成拆分，待定与敏感编码从未进入检验。

## 审查意见的处理（按默认）
- 安全阻断：题目人数门槛只留一份扰动余量（真实 18、19 人会被列出）→ 改为两份；全对 / 全错题泄露个人对错 → 两格门槛与分档；敏感编码被导出与检验 → 解析与导出双重排除。
- 契约阻断：只看 phi 会把带猜对与失误的难易分档判成拆分 → 改为 H 比值并加反例；易错点对照可跨两个大类、与 0011 冲突 → 强制同一大类。
- 建议采纳：共用扰动、同口径导出、资源上限、伪名一致性、UUID 拒绝、空主题跳过。

## 与 spec 的偏差
1. 拆分判据在题目两群之外加了学生层面的 H 比值（只用 Loevinger H 时 21 个种子中有 2 个把分档误判成拆分）。
2. 两群检验用最佳二分 + 正态零假设的参数自助法（spec 写置换检验或双峰性检验）。
3. 易错点与编码的关联来自教研给的对照文件（快照白名单无 `error_type`）。
4. 统计单位是学生；主题基线中一名学生按伪名哈希只取一个节点的记录。

## 待人确认
1. 错因证据取法：`error_attribution` 无节点列，草案经 `evidence_ids` 找作答题目再按主节点挂接（另可经 `kge.skill_link`）；置信度阈值 0.6、`min_grade_confidence` 为占位。
2. 作答口径与掌握计算的差异：只收 `independent`（掌握计算还算 transfer、delayed_retest）；“每题首次作答”不同于“每题目族首次计入”；打标取当前发布版本的 `item_tag`（掌握计算按证据自身地图版本经 `id_migration` 映射）；节点不分认知层次（报表附层次供判断）。
3. 两群检验阈值（每群至少 3 题、两群差 ≥ 0.2、过关线 0.5、H 比值 0.5、每节点题数上限 40、自助法 2000 次）。
4. 易错点编码对照由谁维护；是否把 `error_type` 加进快照白名单（契约变更，必停）。
5. 敏感与待定编码清单以分类表状态列为准；是否还有其他编码应排除。
6. 隐私残余：小四格在合计已知时可能被唯一反推，防护只靠扰动（不是差分隐私）；难归类候选可能唯一；学生层面四格与错因四格的学生集合互相嵌套；差分可看出某人在哪些节点有错因记录（成员身份）。
7. 最小格规则会漏掉“集中在本节点、别处罕见”的编码（基线格不足时只能记样本不足），是否改用跨主题基线。

9. 导出：两个函数需一次调用同时返回作答与错因（salt 只在函数内生成），由执行人按记录类型拆分；函数须另起 `[NEEDS-HUMAN]` PR；合成守卫放开另起任务经人确认。
