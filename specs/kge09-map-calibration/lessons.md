## 交付
- `tools/kge-calibrate`（纯标准库）：
  - 前置边检验：强前置 A→B 比较“A 已掌握 / 未掌握”两组在 B 上的掌握率，Newcombe 区间、Benjamini–Hochberg；显著为正为“成立”，区间含 0 或按族校正后的上界低于效应量阈值为“不成立候选”，样本不足不出结论。弱前置只报告。
  - 隐藏依赖：同主题未连边节点对的 phi，有共同前置时只在共同前置（只算可计算且有观测的祖先）都已掌握的学生里计算，排除传递可达；两向都列为候选。
  - “掌握”口径与学习服务星亮同一：门槛 `transfer` / `retain`；导出函数草案按 `star_level_rule` 取星亮层次（与 `star_basis_level` 同口径），门槛与概率取同一行；不另设概率阈值。
  - 防泄露：报表无精确计数；人数向下取整到 10；四格加确定性表键扰动（±2），公开门槛每格 ≥ 22 保证真实 ≥ 20；任一格不足时结论只写“样本不足”；p 值分档；不含伪名。差分测试：删一人重跑，无法确定此人所在格。
  - 输入守卫：拒绝姓名、学校、手机号等字段；伪名 `^(syn|pil)-[a-z]{10,24}$`，`synthetic=true` 只收 `syn-`；读前 stat 限长；输出目录须为空、文件 0600 独占新建。
  - 合成队列生成器（固定种子）埋入成立前置、不成立前置、隐藏依赖；31 个种子：不成立前置召回 83/93、隐藏依赖 62/62、真成立前置确认 186/186、误报 0。
  - `RUNBOOK.md`、`sql/export-function.draft.sql`（另起 PR 的函数草案，库内生成一次性 salt）、`sql/export-mastery.readonly.sql`（只调用该函数）。
- 测试 124 项；变异 98 个全部发现；make 目标 `kge-calibrate-test`、`kge-calibrate-mutation`。

## 审查意见的处理（按默认）
- 契约阻断：“掌握”导出取各层次最高值、与星亮口径不同却写成相同 → 改为星亮层次规则同口径，删概率阈值路径；共同前置含不可计算节点时真实候选被压成“样本不足” → 只算可计算且有观测的祖先。
- 安全阻断：跨次/跨表相减可还原个人（实测删一人即还原 21 个节点）→ 去掉精确数、取整 + 表键扰动、差分测试；RUNBOOK 导出命令与自身前置条件冲突并引导真实数据“演练” → 改为只调用另起的函数，函数合并与守卫放开前不得真实导出；salt 经命令行与 SQL 文本可能入日志 → 库内生成。
- 建议采纳：伪名收紧、合成标记取自元数据、同意名单排序与删除排除、资源上限、输出文件权限、各组观测率、按族校正的置信水平。

## 与 spec 的偏差
1. 新增“按族校正后的区间上界 < 效应量阈值”也算不成立候选（总体能力会让任意两节点弱正相关，“区间含 0”在大样本下判不出）。
2. 隐藏依赖按共同前置分层（关掉会把兄弟节点误报）。
3. 新增表键扰动（不是差分隐私）；人数分档、比率保留两位、p 值分档。
4. 地图只收 JSON；掌握状态 CSV 的元数据行为本工具自定格式。

## 待人确认
1. **“掌握”口径**：沿用星亮门槛（transfer / retain、星亮层次规则），请确认适用于地图校准。
2. **阈值**：最小格 20、公开门槛 22、扰动 ±2 与分布、置信水平 0.95、FDR 0.05、效应量 0.1（绝对差，基础率极端时含义不同）、min_phi 0.3、节点对上限、误报上限——均为占位。
3. **扰动机制**：表键扰动能挡住删一人的差分，但不是差分隐私；残余风险：学生总数分档跨档会透露“少了一人”（不透露其掌握情况），观测率未纳入差分枚举。是否改用差分隐私并设隐私预算。
4. **导出函数**：SECURITY DEFINER 只读函数属权限变更，须另起 `[NEEDS-HUMAN]` PR；谁执行导出、何时放开 `synthetic=false` 守卫、同意用途是否覆盖“内容改进 / 聚合回流”、试点库是否属规则 9 的“生产”，由人定。
5. **总体能力混杂**：前置检验靠效应量上界缓解，隐藏依赖只靠 min_phi；真实数据上同主题节点 phi 可能普遍偏高；是否改用分层（如 Mantel–Haenszel）留待下一步。
6. **选择偏差**：编排可能因前置未掌握而少给 B 出题，“A 未掌握组”在 B 上的观测会自选；报告已给各组观测率供判断。
7. 隐藏前置会让某格天然偏小，最小格要求意味着试点规模需足够大。
8. 编号 KGE-09 为仓库排队号。
