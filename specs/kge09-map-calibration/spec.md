# KGE-09 地图数据校准 · 第一步：前置边经验检验与隐藏依赖候选（离线、只出聚合候选）

2026-10-16 起由 Claude 按用户授权自主推进（开发计划 v2.0 阶段 1 · 4 月“地图数据校准首个次版本”，KGE V1.1 S9–S13“地图数据校准（前置检验、隐藏依赖、易错聚类）”）。
编号 KGE-09 为仓库排队号。零迁移、不改契约、不改掌握计算、不调用模型、零新依赖。

## 依据
- KGE V1.1 第五章“地图迭代信号”：**前置不成立**（A 未掌握者在 B 上并不显著更差 → 削弱或删除前置边）；**隐藏依赖**（未连边的两节点掌握度高度相关 → 新增前置边候选）。
- 变更流程：系统生成带证据包的候选 → 教研在审核台确认、修改或驳回（结构性变更两人确认）→ 发布前影响分析 → 版本发布。
- 群体数据只以聚合统计回流，设最小人数门槛（同一格少于 20 人不出结论）；个人层永不进入公共层（规则 13）。

## 定位
离线计算工具，**在数据所在环境内运行**，输入是按学生、按节点的掌握状态（个人层，只在内存中），输出只有聚合统计与候选清单（无学生 ID、无可回推个人的格子）。
所有结论都是候选，不改地图、不写库；落到审核台与次版本发布另起任务。

## 范围
1. `tools/kge-calibrate`（Python，沿用 `tools/gate1-evidence` 的工程约定与解释器，不新增依赖）：
   - **输入**：
     - 地图快照（节点、强/弱前置边、所属主题），复用知识服务快照或导入器产物的现有格式；
     - 掌握状态表（学生伪名 × 节点 × 门槛状态或掌握概率），本步只接受合成样例文件，以及一份给人在试点环境运行的只读 SQL 说明（不在本仓库执行）。
   - **前置边检验**：对每条强前置 A→B，比较“A 已掌握”与“A 未掌握”两组在 B 上的掌握率；两组人数都 ≥ 门槛才检验；差值与置信区间（确定性方法，如 Wilson / Newcombe），多重比较用 Benjamini–Hochberg 控制；差值显著为正 → “成立”，区间包含 0 且样本充足 → “不成立候选”，样本不足 → “样本不足”。弱前置只报告不出候选。
   - **隐藏依赖**：同一主题内未连边的节点对，计算掌握状态的 phi 系数或对数优势比，超过阈值且四格最小格 ≥ 门槛 → “新增前置边候选”（方向不定，两向都列，交教研判断）；同时排除传递可达的对。
   - **门槛与阈值**集中在一份配置，标“待教研确认”；最小格人数默认 20。
   - **输出**：`calibration-report.json`（每条边/节点对的计数、比率、区间、校正后 p 值与结论，只含聚合数）与 `worklist.md`（教研勾选：确认 / 驳回 / 修改为弱前置，附证据包摘要）；同一输入逐字节一致。
   - **防泄露守卫**：任何输出格子人数 < 门槛一律不输出数值（只写“样本不足”）；输出中不得出现输入里的学生伪名；输入含姓名、学校、手机号等字段一律拒绝。
2. 合成队列生成器：按固定种子生成学生 × 节点掌握状态，埋入“真成立的前置”“不成立的前置”“隐藏依赖”三类结构与噪声，用于检验工具的召回与误报。
3. 测试与变异：统计函数正反例；埋入结构的召回（不成立前置与隐藏依赖都能找出）与误报上限；样本不足、最小格守卫、伪名不外泄、逐字节一致；变异接进 make 目标 `kge-calibrate-test`、`kge-calibrate-mutation`。

## 不做
- 易错聚类、节点内部分化（拆分节点）——另起；写库、改地图、审核台接入、次版本发布、影响分析；连接任何真实数据库；IRT；模型调用。

## 验收
- 合成队列上：埋入的不成立前置与隐藏依赖被找出，误报不超过配置上限；守卫与逐字节一致测试通过；变异全部发现；严格 `make check` 通过。

3. 在试点环境运行的流程与谁来执行（规则 9：不接触生产；规则 13：只回流聚合）。
