# KGE-09 地图数据校准 · 第二步：易错聚类与节点内部分化候选（离线、只出聚合候选）

2026-10-17 起由 Claude 按用户授权自主推进；沿用第一步（`spec.md`、`lessons.md`）的工具、口径、防泄露机制与用户决定。零迁移、不改契约、不改掌握计算与错因分类表、不调用模型、零新依赖。

## 依据
KGE V1.1“地图迭代信号”：
- **错因无法归类**：错题剖析反复出现的新错误模式 → 新增易错点；
- **节点内部分化**：同节点题目表现两极分化，或错因聚成两群 → 拆分节点。

## 范围（扩展 `tools/kge-calibrate`）
1. **输入**（只接受合成样例，导出另由第一步的函数草案扩展说明，不执行）：
   - 作答聚合行：学生伪名 × 题目 × 节点 × 对错（独立作答，按掌握口径取证据）；
   - 错因行：学生伪名 × 节点 × 学科错因编码 × 跨科大类 × 置信度（只取当前行，`superseded_by IS NULL`）；
   - 地图快照（第一步格式），含易错点节点及其与知识点的关联；错因分类表（`docs/mapping/error-taxonomy.md` 的机器可读部分，只读）。
2. **易错候选**：
   - 每个可计算节点上，学科错因编码的分布；某编码占比显著高（相对本主题基线，按族校正）且该节点没有关联的易错点覆盖这一编码 → “新增易错点”候选；
   - 低置信度错因在某节点聚集（占比高于阈值）→ “错因难归类”信号，列出供教研看（不自动提议新编码）。
3. **节点内部分化**：同一节点下各题的正确率分布做两群检验（如按题目正确率排序后的最佳二分 + 置换检验，或双峰性检验），显著且两群各自题目数与人数达门槛 → “拆分节点”候选，附两群题目 ID（题目 ID 属公共层，可以列出）。错因两群聚集（同节点错因编码明显分两类且与题目分群对应）作为加强证据。
4. 防泄露沿用第一步：无精确计数、取整与表键扰动、任一格不足只写“样本不足”、不出伪名、差分测试；题目级正确率只在题目作答人数 ≥ 20 时给出（同 KGE“同一题少于 20 人不展示得分率”）。
5. 合成队列扩展：埋入“未覆盖的高频错因”“难归类聚集”“应拆分节点”三类结构，测召回与误报；测试、变异与样例同第一步规格。

## 不做
- 自动生成新错因编码或易错点文本；改错因分类表、地图或掌握计算；写库；真实导出；模型调用。

## 验收
- 合成队列上三类结构被找出、误报不超过配置上限；防泄露与差分测试通过；变异全部发现；严格 `make check` 通过。

## 待人确认（实施中补充）
1. 错因证据取哪些来源（判分附带的错因、错题剖析），置信度阈值。
2. 两群检验方法与阈值；最少题目数。
3. 易错点与错因编码的关联从哪里取（地图里的易错点节点字段或教研另给对照表）。
