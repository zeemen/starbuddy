## 交付
- `services/learning/learning/mock_exam/`（纯函数，不引入数据库层，有子进程测试核对）：
  - `manifest.py` 卷清单校验：题目唯一、卷面分值（两位小数，按百分之一分整数运算）合计 = 满分、满分与限时与考情快照一致、题目在准入快照内且题型码一致、题型码属该科工程占位词表；学科码映射读 `config/mock_exam/subjects.json`。
  - `session.py` 限时状态机 `created → in_progress → submitted | expired`：截止 = 服务端开始时间 + 限时 + 宽限，时间由调用方注入；截止时刻本身算截止后；同题重复作答取最后一次；时钟回拨拒绝；票据 `me1.<kid>.<载荷>.<签名>`（HMAC-SHA256、常量时间比较、当前与上一把密钥按 kid 选、时序一致性校验、换卷换学生拒绝），密钥不合规抛配置错误（路由层应映射 500）。
  - `summary.py` 整卷汇总：判分须带溯源五字段与 `calibrated`，多余字段拒绝；判分方式复用 `practice.presenter.GRADING`；卷面得分 = 判分得分 / 判分满分 × 卷面分值（ROUND_HALF_UP 到 0.01）；`score` 为空或需人工复核或低置信的题列“待复核”、总分“暂定”；未校准单独标注；可选核对 rubric 版本；采分点完整覆盖时按采分点归节点，否则整题计入并列出。节点聚合只是证据汇总，不得落库、不得当掌握度用；不生成对学生的陈述。
- 配置与合成样例：`config/mock_exam/`（配置位、JSON Schema 草案、数学函数与道法法律两份合成卷、学科码映射）；测试夹具（考情、准入、题目→节点、采分点快照）均为合成。
- README“模考限时整卷”一节：计量与证据口径方案、票据安全。
- 测试 121 个 + 2 个 xfail(strict)（记录两种重放攻击）；变异 108 个全部发现；`make mock-exam-test`、`make mock-exam-mutation` 接进 check。

## 教训
- 写计量方案前先读迁移里的资源设计说明：`mock_exam` 的预留时点与时长在 0008 已有定义，方案与之相反未被实现者发现，靠契约审查拦下。
- 汇总接受“映射值”时必须校验容器类型：Python 字符串可迭代，会被静默拆成字符。
- 只签名不加密的票据，注释要写全载荷内容；“只有内部 ID”这类说法会掩盖行为数据（作答时刻）。
- 精度口径三处不一致（`kge.scoring_point` numeric(5,2)、`policy.subject_config.full_score` numeric(5,1)、契约 `ExamConfig.full_score` integer），非本次引入，记录在案。
