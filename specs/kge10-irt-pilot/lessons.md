# KGE-10 IRT 试点评估第一步 · 实现记录

2026-10-17 起由 Claude 按用户授权自主推进；零迁移、不改契约、不改掌握计算、不写库、不调用模型、零新依赖（纯标准库）。
提交首行 `[NEEDS-HUMAN]`：阈值与防泄露参数为占位值；基线引用学习服务掌握配置；按 IRT 结果改先验难度属必停，本步只给候选。

## 交付
- `tools/kge-irt`：MML-EM（Gauss–Hermite 固定节点）拟合 1PL / 2PL，按节点分块，确定性；输入守卫、表键扰动、人数取整、伪名出口检查与 0600 独占写出全部复用 `tools/kge-calibrate`，不另立口径（有测试核对无复制实现）。
- 时间切分评估（导出逐行标 fit / eval，工具核对时间序与比例）：对数损失、Brier、AUC 按“每生一个点”；对照 BKT 未校准、BKT + Platt、只用先验难度（按节点截距）、先验难度 + 能力、IRT 1PL、IRT 2PL；判定为每生配对差 + 配对自助法区间（200 次、固定种子），差值只扰动一次；冷启动学生与有拟合数据学生分组报告。
- BKT 基线对齐掌握计算口径：伪名 × 节点 × 认知层次；p_guess 按题型；合成基线强度按“权重 × 等级 × 来源 × 错因”，同族只计第一次；测试 import 学习服务 `replay` 在同一合成输入上逐单元核对（误差 < 2e-6）。仍简化：只重放掌握概率，不重放门槛状态机、复测、置信度与衰减。
- 防泄露：题目参数须作答人数与答对、答错两格都过扰动后门槛；难度格点按单人影响上界逐题加粗；AUC 占比门槛用扰动后的量；强攻击者差分测试（知道其余所有人、逐题翻转此人对错重拟合）。
- 输出 `irt-report.json` / `.md`：首段“合成，不是试点结论”；JSON 顶层 `not_a_source_of_truth: true`；“先验难度疑似标错”只作候选仅供教研参考（按节点 Theil–Sen，且 2PL 自助法区间不覆盖直线）。
- 测试 60 个、变异 120 个全部发现；`make kge-irt-test`、`make kge-irt-mutation` 接进 check。
- 合成队列（487 人）：2PL 难度恢复误差 0.14、区分度 0.16；对数损失 BKT 0.72、BKT + Platt 0.67、只用先验 0.65、先验 + 能力 0.62、IRT 0.56；埋入的 3 道先验标错全部找出、无误报。合成真值本身是静态 IRT，IRT 占优不能外推到真实数据。

## 审查意见的处理（按默认）
- 安全阻断：AUC 是否公开由精确正例占比决定，删一人即可定出此人对错 → 改用扰动后的量并留余量，补边界与差分测试、变异。
- 契约阻断 1：基线口径与掌握计算不一致却写“一致” → 全部对齐并以学习服务纯函数核对。
- 契约阻断 2：报告可能成为第二份难度来源 → README、JSON 标记、候选措辞三处写明不得回写或导入，改先验走 KGE-02 打标流程。
- 其余建议全部采纳：强攻击者差分、合成标记取自元数据、题目快照过个人信息检查、拟合比例只写配置范围、补齐变异；字段改名 `family_code`、主节点口径、无先验的题剔除并计数、Platt 对照、按节点截距、配对判定、冷启动分组、按节点标错、自助法偏窄标注、非合成输入时基线配置须已签字。
- **偏差（接受）**：安全建议“1PL 与 2PL 难度共用一个扰动”未照做——实测共用扰动会让两者之差精确公开，强攻击者 51 次检查中 20 次定出对错，独立扰动为 0 次；已用测试与变异固定独立扰动。
- 偏差：Platt 改为在后段按学生分两半交叉拟合（拟合段没有逐次作答前的掌握概率，在拟合段校准会用到看过答案的概率）。

## 教训
- 防泄露的门槛判断本身也是输出：任何“是否公开”的判断只能基于扰动后的量。
- 对相关的公开量“共用扰动”不一定更安全：共用会让差值精确公开。是否共用要用强攻击者实测决定，不能按先例照搬。
- 对照基线写“与服务一致”必须有逐值核对的测试，否则粒度、题型参数、证据权重都会悄悄分叉。
- 未校准的基线比瞎猜还差时，“新方法更好”几乎必然成立，对照须先校准。

## 待人确认
1. 最少作答人数 20、两格门槛、评估组 20、块门槛 50、切分比例 0.5–0.9、求积节点 15、参数界与先验、`prob_clip` 0.01 等占位值。
2. “IRT 更好”的判定：门槛 0.02 且配对区间不含 0；配对自助法 200 次；题目参数自助法 30 次（区间可能偏窄）。
3. 分块粒度（现只支持节点）与题目族内是否共享参数。
4. 真实导出函数与授权（必停，另起；可扩展 KGE-09 导出草案），放开合成守卫。
5. “独立作答”口径：KGE-09 导出与掌握计算有四处差异（取第一次符合条件而非首次接触；只剔除猜对保留猜错，难度系统性偏高；只收 A 级；旧证据 evidence_kind 为空与 transfer 被排除），需统一。
6. 先验难度方向（越大越难）在 0011 与契约中未定义；若先验只有少数几档，秩相关与 Theil–Sen 有大量同值。
7. “先验难度疑似标错”清单能否交给教研（按它改先验属必停）；“接近全对 / 全错”告警附题目 ID 与大致人数的同质性推断是否接受。
8. 基线 BKT 参数暂用学习服务合成测试配置（阿鸦正式配置 bkt 段为空），须换成已签字配置；基线口径简化是否可接受；导出能否提供逐次作答前的掌握概率（决定 Platt 校准位置）。
9. 难度格点加粗规则与 AUC 占比门槛 0.25；1PL / 2PL 独立扰动的偏差。
10. 表键扰动不是差分隐私；IRT 让同一人出现在多个相关公开量中，是否仍沿用 KGE-09“先用现值”的决定。
