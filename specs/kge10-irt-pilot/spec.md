# KGE-10 IRT 试点评估 · 第一步（离线拟合与对照，只出题目级聚合）

2026-10-17 起由 Claude 按用户授权自主推进（开发计划 v2.0 阶段 1 · 5 月“IRT 试点评估”；KGE V1.1“数据够时试点 IRT 校准难度与区分度”“先验难度 IRT 校准后替换”）。
编号 KGE-10 为仓库排队号。零迁移、不改契约、不改掌握计算（BKT 与五道门槛不动）、不写库、不调用模型、零新依赖（纯标准库，同 kge-calibrate）。

## 定位
离线评估工具：回答“在现有作答量下，IRT 题目参数是否比先验难度更好、IRT 预测是否比现行掌握估计更准”。结论只是评估报告；替换先验难度或改掌握计算另起必停任务。

## 范围（`tools/kge-irt`，Python 标准库，沿用 `tools/kge-calibrate` 的工程约定、输入守卫与输出写法）
1. **输入**（本步只接受合成样例，`synthetic=true` 才收；真实导出另起）：
   - 作答行：学生伪名 × 题目 × 节点 × 对错 × 作答时间序（独立作答口径同 KGE-09）；
   - 题目元数据快照：题目 ID、节点、先验难度（`kge.item_tag` 的分级先验）、题目族；
   - 掌握估计基线：同一时间切分点上的现行掌握概率（合成样例由 BKT 纯函数离线生成，复用 `services/learning` 掌握纯函数的口径说明，不 import 服务代码时以夹具提供）。
2. **拟合**：按节点或主题分块，1PL 与 2PL，边际最大似然 + EM（Gauss–Hermite 求积，固定节点数），区分度与难度设先验或界（防发散），收敛阈值与最大迭代集中在配置；确定性（无随机初始化或固定种子）。
3. **评估**（时间切分：前段拟合、后段评估；学生能力只在内存中估计，不输出）：
   - 后段作答的对数损失、Brier、AUC：IRT（1PL / 2PL）对比现行掌握估计基线与“只用先验难度”；
   - 题目参数稳定性：自助法（固定种子）给难度与区分度的区间；
   - 先验难度与 IRT 难度的秩相关；
   - 可识别性告警：作答人数不足、全对 / 全错、区分度接近边界的题目。
4. **防泄露**（规则 13，沿用 KGE-09）：只输出题目级与节点级聚合；题目参数只在作答人数 ≥ 20 时给出，否则“样本不足”；人数取整与表键扰动；不输出任何学生能力值或伪名；差分测试（删一人重跑无法定格）。
5. **输出**：`irt-report.json` 与 `irt-report.md`（首段“合成，不是试点结论”）；逐字节可复现；输出权限与写法同 kge-calibrate（0600、独占新建、目录须为空）。
6. **合成队列**：按已知真值参数（1PL / 2PL 混合，含少量“先验难度标错”的题）生成作答，固定种子；测试参数恢复误差、对照结论方向正确。
7. **测试与变异**：似然与梯度数值核对、EM 单调不降、参数恢复、评估指标手算、样本不足与取整守卫、伪名不外泄、逐字节一致；make 目标 `kge-irt-test`、`kge-irt-mutation` 接进 check。

## 不做
- 替换先验难度、改 BKT 或门槛、在线估计、写库、真实导出、多维 IRT、DKT。

## 验收
- 合成队列上参数恢复在配置误差内、对照结论与真值一致；守卫与差分测试通过；变异全部发现；严格 `make check` 通过。

## 待人确认（实施中补充）
1. 最少作答人数（默认 20）、时间切分比例、求积节点数与参数界。
2. “IRT 更好”的判定门槛（对数损失改善多少才建议试点替换）。
3. 分块粒度（节点 / 主题 / 学科）与题目族内是否共享参数。
4. 真实导出函数与授权（必停，另起；可复用 KGE-09 导出草案）。
