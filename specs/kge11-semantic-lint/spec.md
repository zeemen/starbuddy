# KGE-11 语义体检与事件驱动编入 · 第一步（规则式语义体检、文件式编入事件、分流纯函数）

2026-10-18 起由 Claude 按用户授权自主推进（开发计划 v2.0 阶段 1 · 3 月“语义体检与事件驱动编入”；KGE V1.1 S9–S13“语义体检；事件驱动自动编入；风险分级自动分流”）。
编号 KGE-11 为仓库排队号。零迁移、不改契约、不调用模型（真实供应商属必停）、不改现行审核级别（分流开关缺省关）、零新依赖。

## 依据（KGE V1.1）
- 体检两层：程序层（已有，KGE-03）先跑；语义层随后：与原子冲突、跨页矛盾、版本差异误判、超纲、适龄文风、角色语言混入。跨页矛盾只比骨架相邻页（前置、易混、同主题）与本次受影响页。
- 编入：新入库原子（考试说明、真题、审核通过的上传题、确认的易错模式）经“页面—原子”引用找出受影响页，进编译队列；兜底检索命中也作信号。
- 风险分级：低（程序体检过 → 每日合并窗口、事后抽检）；中（叙述段改写，语义体检过 → 抽检、小流量）；高（教研必审，结构性两人确认）。

## 现状
- 程序体检 16 项在 `services/knowledge/knowledge/lint/`，报告 `kge-lint-report/1`，条目 `layer:"program"`。
- 编入只能手动：`python -m knowledge.compiler --old-snapshot --new-snapshot`，`compiler/jobs.py` 的 `plan_jobs` 按 `atom_refs` 与骨架邻居找受影响页；无事件表、无调度接入。
- 审核台 `review_console/risk.py` 的 `review_level` 因“阶段 0 没有语义体检”把中风险按高风险审；编译器 `compiler/rebuild.py` 把叙述段改写判高、`risk.py` 判中，口径不一致（实际效果相同）。

## 范围
1. **规则式语义体检** `services/knowledge/knowledge/semantic/`（确定性、不调模型），报告沿用 `kge-lint-report/1`，条目 `layer:"semantic"`，检查类型并入现有枚举（代码内枚举，不是契约）：
   - 与原子冲突：页面中的数值、公式、结论性表述与所引原子（及采分点）对照；公式等价复用现有 SymPy 检查；
   - 跨页矛盾：相邻页对同一前置关系的表述方向与骨架边一致；同一术语（节点名、别名）在相邻页写法一致；
   - 版本差异误判：版次（edition）专属表述出现在未标该版次的段落；
   - 超纲：页面出现不在该节点适用学段 / 课标范围词表中的术语（词表为输入文件，合成样例，教研提供正式版）；
   - 适龄文风：沿用句长等现有规则之外，增加可配置的词表规则（合成占位）；角色语言混入复用现有人设词表。
   - 比对范围：骨架相邻页 + 本次受影响页，不做全量两两。
   - 每条检查有“阻断 / 提示”级别，集中在配置，标“待教研确认”。
2. **文件式编入事件**：读入原子变更清单（JSON，新增 / 修改 / 下架原子 ID 与来源类型），复用 `plan_jobs` 产出编译任务清单（受影响页、风险、优先级）；兜底检索命中信号（现 JSONL）可作为同一清单的另一来源。只产出清单，不常驻、不建表、不自动发布。
3. **风险分流纯函数**（审核台侧，开关缺省关；关时 `review_level` 行为逐字节不变）：中风险且程序体检与语义体检均零阻断 → “抽检”；否则仍按高风险。只返回建议级别，接入真实审核流另起。
4. 口径不一致只记录、不改行为：加测试固定两处现状，写进待人确认。
5. **测试与变异**：每类语义检查的正反例（合成页面与原子）；比对范围限制；报告格式；编入清单与 `plan_jobs` 一致；分流开关关时不变、开时按规则；make 目标 `knowledge-semantic-test`、`knowledge-semantic-mutation` 接进 check。

## 不做
- 模型调用、`compile_job` / `lint_issue` 入库、调度接入、自动发布、改审核人数与合并窗口、个人层档案页的陈述—判断一致性检查。

## 验收
- 合成样例上各类语义问题被找出、干净样例零误报；分流开关关时行为不变；变异全部发现；严格 `make check` 通过。

## 待人确认
1. 规则式语义体检能否作为中风险降为抽检的依据，还是必须等模型语义体检（必停：改审核级别）。
2. 超纲词表、适龄文风词表、阻断 / 提示分级由教研提供。
3. 叙述段改写判中还是判高（编译器与审核台口径统一）。
4. `compile_job`、`lint_issue` 入库与调度接入另起（迁移，必停）。
