# 指着元素提问（第一阶段）· 实现记录（lessons）

2026-11-25，用户确认第五节五条都按默认后实现第一阶段（只做“指”和“问什么”，不做“答”）。

## 做了什么
- **提问对象与校验**：新文件 `packages/stage/src/question.ts`，经 `src/index.ts` 导出。
  - `StageQuestion` 只含 `dsl_version`、`cursor`、`anchor { kind, id }`、`intent`，四个意图编码固定，不收自由文字。
  - `validateStageQuestion` 只收校验过的 DSL，规则是“只能指已经出现的东西”：
    - 元素必须此刻在白板上；
    - 高亮框、不存在的 id、未声明的槽位、不存在的步一律 `unknown_anchor`；
    - 未来的元素、已擦掉的元素、还没播放到的步一律 `not_visible`。
    通过时返回冻结的新对象，不保留调用方的引用。
  - `originsAt`：白板上每个元素是第几步写上去的。`askableAt`：此刻能指的全部锚点。`replayCursor`：“再讲一遍”要跳到的步数。
- **白板可提问模式**（`Whiteboard` 的 `askable` 属性，缺省关闭）：
  - 关闭时原有四张快照逐字节不变；
  - 打开时每个元素（高亮框除外）与槽位各一个透明点击区：`role="button"`、`tabindex="0"`、`aria-pressed`，回车或空格选中；
  - 选中的东西画虚线细框（线宽 2、虚线 4 4），与老师的聚光、激光笔只用形状与线宽区分；
  - 读屏标签由调用方给，组件不念 DSL 里的文字与公式。
- **样张页 `/dev/stage`**：
  - 打开可提问模式，字幕下方加了“问这一步”按钮；
  - 选中元素后：播放中先暂停，弹出四种问题加“取消”，焦点落在第一个问题上；
  - 取消：Esc 或点空白处都能取消，Esc 取消后焦点回到原来的元素；
  - 选“再讲一遍”：跳回那一步的开头重放；
  - 选另外三种：只显示合成占位“已收到：第 n 步 · …”。
  - 提问对象都经 `validateStageQuestion`；不发请求、不写存储。
- **文案**：`apps/web/src/shell/copy.ts` 的 `STAGE_ASK` 共 11 条，都是 `{{TODO_COPY:ask.*}}` 占位，并入 `ALL_SHELL_COPY` 的禁语与禁用推断扫描。已登记进 `specs/launch-test-2026/todo-by-owner.md` 的 W6 行。

## 与 spec 的差异与补充
1. **错误码多一个 `not_object`**：提问对象不是普通对象时用这个码，与 DSL 校验器同一口径。
2. **点击区的最小尺寸**：组件在服务端渲染时不知道实际的 CSS 尺寸，所以按“各套布局的舞台宽度 = 该类设备的名义 CSS 宽度”换算，最小边长取 52 个舞台单位（`ASK_MIN_STAGE_UNITS`）。
   - 按名义尺寸渲染约 52 像素，缩到名义宽度的 85% 时仍不小于 44。
   - 端到端在 1280 宽的桌面视口按实际像素再核了一遍，每个点击区都不小于 44。
   - 窄屏上若用了桌面布局，不保证 44，那时应当换手机布局。
3. **点击区会互相重叠**：相邻两行比较近时（例：f1 与下面的横线），补到最小边长后点击区会重叠，后写的元素在上层。
   键盘可以逐个 Tab，不受影响；鼠标点重叠处时选中后写的那个。真实讲评课的板书版式由教研出，到时再看是否要调间距。见待人确认 P2。
4. **“问这一步”的位置**：spec 写的是“指着字幕或步骤条问”。样张页没有步骤条，于是在字幕下方放了一个“问这一步”按钮，问的是当前这一步。
5. **槽位的“再讲一遍”**：槽位不属于哪一步，按 spec 重放当前这一步。
