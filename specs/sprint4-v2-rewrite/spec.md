# 冲刺 4 四份 spec 按开发计划 v2.0 改写

状态：**已确认（2026-09-28，用户“按默认建议，开始实现”）**，待人确认 #1–#3 按默认执行；改写结果见 lessons.md
任务：对照文档 `specs/plan-v2-alignment/spec.md` 第五节第 6 项（待决 #8）；前提“第 1–5 项的草案落地”已满足（KGE-00、SIE-00、kge / insight / policy schema、两份服务 OpenAPI、ADR 11–15、计量 v2、插件 API v1.0 候选版）。

## 目标
把四份冲刺 4 spec 的**设计正文**改成 v2.0 口径，使它们在 W9 开工前可以直接确认；不再依赖“正文按 v1.0、另附影响一节”的读法。

## 范围与改写要点
| spec | v2.0 任务包 | 改写要点 |
|---|---|---|
| 4-C `specs/mastery-estimate-sprint4/` | KGE-04 掌握 v0 | 计算单元改为“学生 × knowledge_node × 认知层次”；证据按 `evidence_kind` 四类（独立 / 提示后 / 迁移 / 延迟复测）与证据等级（只有 A 级推动星亮，B 级降权，C 级不进，ADR 15）计算；五道门槛与星亮口径引用 ADR 11；时间衰减只降置信度；待复核结果不推动门槛；学情档案页与陈述—判断一致性检查并入；门槛、权重、BKT 参数只列配置位，数值待教研签字（必停项） |
| 4-D `specs/adapter-aya-methods-sprint4/` | ADP-数学（plan / teach / generate_variation / report） | 按插件 API v1.0 候选版写：plan / diagnose / report 读编排层给的 `learner_context`、`node_path`、`exam_config`；teach 读 `knowledge_page`；generate_variation 从 `item_family` 选题；report 只给字段与证据引用，不写结论句，不再有 `forecast`；`verified_statements` 改名；覆盖率口径“阿鸦 6/6，英语搁置不计” |
| 4-G `specs/release-gate-sprint4/` | 发布流水线与审核台（冲刺 1 / 3 / 4 分段） | 审核对象加知识地图（节点、边、投影）与编译页面两条线；地图发布走 `kge.publish_map_version`、考情走 `policy.publish_scheme`（已在迁移 0011、0013）；页面仓库按 ADR 12；内容六段标识与 `kge.map_version` 对应；审核台 v0 的范围按 v2.0 冲刺 1 验收 |
| 4-H `specs/unified-shell-sprint4/` | 统一壳 MVP（H 流） | 星图数据来源按 ADR 11 改为知识节点、能力视图侧栏、待验证虚线（以 ADR 13 签字为准）；今日计划与家长端所有关于学生的文字引用判断（规则 11）；预留“为什么 / 我不同意 / 对账卡”入口；额度可见与拒绝提示按计量 v2（留存态、单日上限、宵禁、`curfew_soon`）；首发对外维度只展示数学知识掌握与迁移 |

每份的改法相同：
- 设计正文逐节改成 v2.0 口径，原“v2.0 的影响”一节改为“相对 v1.0 版本的变化”简表，便于评审对照；
- 引用改到现行依据（完整方案 v1.1、开发计划 v2.0、KGE / SIE V1.1、ADR 11–15、计量 v2、插件 API v1.0 候选版、迁移 0010–0015）；
- 验收标准重写为可测试的条目；待人确认只保留仍未决的项，已由用户决定或已由 ADR 起草的改为引用；
- 状态仍是“草稿，等人确认后才开始实现”——本任务只改文档，不改代码、迁移、契约。

## 不做
- 不实现任何一份 spec；不改已合并的 3-H 星图代码（ADR 11 过渡条款）。
- 不写门槛、权重、BKT 参数的具体数值（掌握计算属必停项，由教研签字）。
- 不改人设文档与话术。

- [ ] 每份的契约与表结构引用与仓库现状一致（插件 API v1.0 候选版、迁移 0010–0015）；用脚本核对引用的文件路径都存在。
- [ ] 每份的待人确认清单去重：已决项改为引用决定记录。
- [ ] `make check` 通过。
