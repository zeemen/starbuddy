# BFF 对“不是本人 / 不存在”统一回 404 · 实现记录

- 2026-11-22 用户“按建议，默认值都同意，开始实现”：只改 9 条路由；账号类型不对维持 403；前端本地拦截也改回 404。
- 改授权失败时的响应码，属权限策略一类（必停）：提交首行 `[NEEDS-HUMAN]`，请安全负责人过目。不改 RLS、库函数与授权判断本身。

## 做了什么
- **BFF**：
  - `src/diagnosis/service.ts`：原来的 `FORBIDDEN`（403）9 处改为 `NOT_FOUND`，响应体直接取 `P.NOT_FOUND`，与其他路由逐字节相同
    （本人核对、会话归属核对、宵禁检查里看不到学生、库端 42501、学习服务 404）；
  - `src/events/query.ts` 的 `forbidden` 改名 `not_found`；`src/http/feature-routes.ts` 的 `writeReply` 回 `P.NOT_FOUND`；
  - 接口定义 `openapi/diagnosis.v0.yaml`（6 条）、`events.v0.yaml`（3 条）的 `x-sb-not-self` 改为 404，头部说明同步。403 响应保留（家长会话：账号类型不对）。
- **前端**：`src/lib/diagnosis.ts`、`src/lib/events.ts` 本地拦下的非法 ID 改回 404；行为事件的写入计数单独计 404（原 403）。页面行为不变。
- **测试**：
  - H6 授权矩阵：拒绝码一律 `P.NOT_FOUND`；另加“只认学生本人且带学生 ID 的路由、以及任何写了 `x-sb-not-self` 的路由，只能是 404”；
  - 诊断、事件集成测试：家长 403（账号类型不对）保留；其他学生、不存在改 404 并断言与 `P.NOT_FOUND` 逐字节相同；
  - 端到端 `behavior-events.spec.ts`：学生给别的学生写事件 404，家长直接写仍 403；
  - 前端 `tests/behavior.test.ts` 的计数分档断言同步；
  - BFF 变异 2 条“不是本人：”（诊断开始退回 403、事件写入退回 403），全部被发现。
- `docs/gates/w13-debt-and-decisions.md` 的 T26：403 / 404 口径标为已做。
