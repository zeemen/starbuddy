## 与 spec 的偏离与发现
1. **核心节点标注用单独清单，不用快照里的 `tags`**。spec 写“沿用导入模板的 tags 字段”，但导入模板、`knowledge.atoms` 的快照白名单、
   迁移 0011 都没有 `tags`。初版从快照节点上剥 `tags`；契约审查后改为单独输入 `core-nodes.yaml`（`kge-m2-core-nodes/1`：学科、
   `map_version`、`node_ids`），地图快照保持白名单格式不动（快照里写 `tags` 按未知字段拒收）。清单的地图版本必须与快照一致、
   节点必须都在快照里；已撤下的节点不进分母。没有清单报“不可计算：核心节点未标注”（spec 原文），不是“待填”。
2. **C 级标记已存在（#4 的前提不成立）**。契约 `learning-internal.v1.yaml` / `plugin-api.v1.0.yaml` 已有 `evidence_level: A|B|C`，
   学习服务对 C 级不写能力观察与错因，已有测试（`services/learning/tests/test_evidence_attributes.py`）。报表里 C 级是一条准入记录项，
   只收 `passed / failed` + 证据文件，缺记录报待填；说明固定为“学习服务侧 C 级约束已有测试；洞察服务侧约束测试待补（A3）”。
   洞察服务侧的约束测试没有加（services/insight 不在本任务可改范围）。
3. **道法 viewpoint 节点挂不了页面**。首期页面层只有知识点页（`page_type = kp`）；体检对 `kind = viewpoint` 节点的页面报孤立页（阻断），
   快照导出会拒绝，所以按现状道法核心节点的页面项达不到。M1 的“知识点页发布率”只数 `kind = kp`。报表对非 kp 的核心节点在两项说明里点出；
   合成道法夹具的节点 `kind` 写 `kp`（夹具注释写明），viewpoint 情形另有单测。见 A1。
4. Top-1 报告里的 `unplaceable_rate`（金标集上的无处可标率）不进报表；Gate 的“留出集无处可标率”只收执行人填的留出集汇总数字。
5. kappa、Top-1 的判定沿用来源脚本（来源 JSON 只有 6 位小数，报表不重新比门槛），只核对门槛常量一致、数值与判定不矛盾。
   道法一致率用整数分子分母按精确分数判定。
6. 影子评审拆两项：“就位”（准入记录里的人数与排班周数）与“比对流程可用”（有 `compare-shadow.json` 且可比项 > 0；只取汇总数字，
   `student_ref` 不进报表）。`sample: true` 报不可计算（与道法一致率的“流程样例”同一口径）。
7. `make kge-m2` 需要三个变量，缺了或不合白名单打印用法退出 2；不进 `make check`（真实输入由执行人给）。

## 审查修复（2026-09-30，按审查默认建议）
- 安全 M1：证据文件每段白名单 `^[A-Za-z0-9][A-Za-z0-9_.-]{0,63}$`；任何一段是符号链接即拒；`resolve(strict=True)` 后必须在准入记录目录内；
  ≤ 10 MB；读取 OSError 转输入错误（L5）。有符号链接（文件、指向目录内、中间段）、非法段名、超限、读不了的用例。
- 安全 M2：`holdout.executor_role` 只收枚举（“教研负责人”），其他退出 2。
- 安全 L1：Top-1 报告与核心节点清单的 `map_version` 按知识服务契约 MapVersion（`^\d{1,3}\.\d{1,3}\.\d{1,4}$`）校验，不合退出 2；
  地图快照的版本也按同一正则校验。M1 的“不可计算”说明只转引 `knowledge.m1` 的固定文案，其他一律写“不可计算（见 M1 报告）”，不回显输入。
- 安全 L3：影子评审比对 `sample: true` → 不可计算。L4：Makefile 在 make 层白名单学科、路径单引号包裹，拒收含空格或单引号的值。
- 契约 1：核心节点清单改为单独文件（见偏离 1）；README 改说“与 M1 用同一个快照文件、白名单格式不加字段”。
- 契约 2：M1 报告的页面快照提交号与本报表读的不一致 → 知识点页发布率、核心节点页面发布率两项报不可计算（完整率照算，用的是本报表读的快照）。
- 契约 3：C 级去掉 `not_applicable`（见偏离 2）。
- 契约 4：M1 的 `met` 必须与数值一致（比率 `met == (分子 == 分母)`，阻断 `met == (blocks == 0)`），不一致退出 2；`snapshot_commit` 须是 40 位提交号。
- 契约 5：M1 说明以“不可计算：没有给”开头（M1 运行时没给页面快照或体检 JSON）→ 待填。
- 契约 6：已发布题目的层次不在节点声明层次里时不计入，只在说明里计数。
