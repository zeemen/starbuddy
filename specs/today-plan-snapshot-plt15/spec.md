# PLT-15 今日计划快照落库与“完成 / 跳过”接入 · 第一步

2026-10-14 起由 Claude 按用户授权自主推进。编号 PLT-15 为仓库排队号。
来源：SIE-05 PR2 契约审查阻断与用户决定（`specs/sie05-silent-metrics/lessons.md` PR2 待人确认第 6 条：计划完成/跳过另起任务，需计划任务表与迁移，接入前统一周报与指标口径）；
PLT-11 “不做”中的“落库（计划完成率、学生调整计划、ADR 03 任务表）”。
涉及迁移、RLS、删除覆盖：**必停**，提交首行 `[NEEDS-HUMAN]`；迁移只出草稿，由人执行。

## 问题
今日计划读时现算、没有任务 ID；复测、再练条目的 `entry_id` 跨天不变，拿来当 `plan_task_id` 会把多天合并成一个任务，且把复测、再练算成“计划任务”。
`plan_task_id` 目前只校验 UUID 格式，不核对是否属于该生当天的计划。周报“只要有完成就算完成”与指标“同一任务取最后一次”口径不一致。

## 范围
### PR1 迁移草稿与快照写入（学习服务）
1. 迁移草稿（编号顺延）：`platform.today_plan_item`
   - 列：`id uuid`（任务 ID）、`student_id`、`plan_date`（北京时间日期）、`seq`、`subject`、`kind`、`source`（plan / practice / retest / verify）、`node_id`、`estimated_minutes`、`entry_ref`（复测、再练条目的引用，可空）、`created_at`。
   - 唯一：（student_id, plan_date, seq）；同一天同一来源条目只出现一次。
   - 当天首次读取今日计划时冻结快照，同一天再读返回同一批 ID；不存掌握、置信度、证据 ID、理由文本。
   - 写入方只有学习服务（规则 2、11）；BFF 只读本人当天行；RLS：学生本人、经 `guardian_student_link` 授权的家长只读；删除覆盖加进 0035 的清单；保留期写配置（合成值 90 天），到期由已有删除作业清理。
   - `insight.behavior_event` 写入函数对 `plan_done` / `plan_skip` 加校验：`plan_task_id` 必须是该生、且 `plan_date` 在事件发生日 ±1 天内的快照行，否则拒绝。
   - 附 DB 测试、变异、攻击面快照、删除覆盖测试；先在副本演练。
2. 学习服务 `POST /internal/v1/today`：开关 `LEARNING_TODAY_SNAPSHOT`（缺省关）打开时按上述规则冻结并返回 `task_id`；关闭时行为与现状逐字段一致。

### PR2 接入与口径统一（BFF、前端、洞察服务）
3. BFF today 透出 `task_id`；前端今日计划每条任务提供“完成”“先跳过”（文案 `{{TODO_COPY:today.*}}`，中性短语），写 `plan_done` / `plan_skip`，幂等键按（任务 ID, 动作）固定，刷新后不重复记；只在学生本人会话显示。
4. 口径统一：计划完成率与周报都按“同一任务以最后一次记录为准”；只计 `source = plan` 的任务还是全部来源，写进配置并标“待人确认”（默认：全部来源，按来源分项也给出）。
5. `plan_done` 表示学生自报完成，不是核实过的完成；复测、再练是否真的完成仍以判分记录为准，指标与周报文案不得把它说成“已掌握”（规则 6、11）。

## 不做
- ADR 03 的编排状态机与持久化任务表（本表只是当天快照）；学生调整计划；家长端跨科列表；改指标效度门槛与 Gate 1 计数；任何人设话术。

## 验收
- PR1：迁移草稿可在副本 up/down；RLS 与删除覆盖测试、变异全部发现；开关关时学习服务响应不变；严格 `make check` 通过。
- PR2：本人能标记完成/跳过且刷新不重复；他人、家长、越日任务 ID 被拒；周报与指标口径一致的测试；严格 `make check` 通过。

## 待人确认（实施中补充）
1. 快照保留期（默认 90 天）。
2. 计划完成率是否只计 `source = plan`。
3. 家长能否看到孩子当天的计划快照（默认只读、只在已授权档案内）。
