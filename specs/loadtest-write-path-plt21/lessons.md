## 审查意见的处理（按默认）
- 安全（无阻断）：护栏前移、登记段加守卫、staff 不重新启用、`--require-write-path`、计次限定合成题、README 写明候选版开关副作用。
- 契约（无阻断）：绑内容版本不用管理员身份；准入摘要如实标占位；种子核对判分结论；一致性口径与文案改准；“预期”说明加限定；锁池说明；样例撤掉手工改动、由 JSON 重渲染逐字节一致；手工种任务与种子不计量如实标注。

## 教训
- 样例必须由工具生成且可逐字节复现；任何手工改动都会让“样例即证据”失效——渲染须由落盘的 JSON 决定、与字典顺序无关。
- 子代理不应在主仓库跑全量 `make check`：既干扰并行任务，也会因解释器缺依赖误报；严格检查只在独立工作树里做。
- “经 indexPack 校验”只证明格式与条数，不证明准入依据真实；占位必须明说。
