## 设计要点
### 1. 题库导入（`tools/kge-import` 扩展，只生成 SQL，不连库）
- 输入 legacy 阿鸦题目（只读）与 KGE-01 已导入的地图版本；输出 `db/seeds/kge/aya-items-<版本>/`：
  - `items.sql`：
    - `kge.item_family`（按 legacy 题组）；
    - `kge.item_tag`：题目 ID，六段标识用章节推出的年级与教材；主考点与 node_ids 来自下面的打标结果；认知层次；来源 `legacy_aya`；
      版权状态 `unverified`；审核状态 `draft`；
    - 题干、答案、解析不进库（0011）；
  - `worklist.md`：教研工作单，列无法定年级或教材的 28 题、落在未导入主题上的题、自然语言引用对不上节点的题；
  - 同一输入两次产出逐字节相同。
- 六段标识：章节 → 年级、册次、教材的映射表放在 `tools/kge-import/config/`，由教研核对（待人确认 #2）。
  一题对应多个年级的六段版本时，默认只登记它首次出现的年级。

### 2. 打标服务（三层，离线批处理，产出候选而不是结论）
- **规则层**（确定性，本任务完整实现）：
  - legacy 题目里的自然语言节点引用（97 处）、章节 → 主题映射、题目 ID 前缀规则；
  - 每条候选带 `source = rule`、规则版本、置信度（规则直接命中 0.9，推断 0.6）。
- **向量层**（本任务只做接口与假实现）：`Embedder` 接口与假供应商，按节点“包含 / 题例”文本与题目文本做相似度排序，输出候选与相似度。
  真实嵌入模型要登记境内供应商或自托管（待人确认 #4），并开放 T7 路由；在此之前 `make` 目标只跑假实现。
- **模型层**（本任务只做接口与假实现）：经模型路由（T8、L0）让模型在 Top-K 候选里选主考点与 1–3 个节点，只能从候选里选。
  输出候选、理由码（不存自由文本）与 `model_version`。数据不出境，“离线构建可用 Claude”与此冲突，待人确认 #5。
- **合并与分级**：三层候选合并、去重，按置信度分 A 级（≥ 0.85 且规则层与另一层一致）和 B 级。
  A 级也只写成 `draft`，要经审核才能发布（KGE V1.1 :343）；B 级与“无处可标”的进低置信队列。

### 3. 低置信队列（迁移 0024，草稿，由人执行）
- `kge.item_tag` 加列：`tag_confidence`（0–1）、`tag_source`（rule / vector / model / human）、`tagger_version`、`model_version`（可空）。
- 新表 `kge.tag_candidate`：公共层，没有 student_id；题目 ID、候选节点、层、置信度、版本、状态（open / accepted / rejected）、处理人（staff）与时间。
  只有知识服务角色能写候选；只有 staff 经审核台函数能接受或驳回，接受时写回 item_tag 并记审核。RLS、快照、变异、攻击面同 0019 的做法。
- 审核台页面不在本任务（沿用复核队列的领取、结案模式，另起任务）；本任务提供库函数与测试。

### 4. 覆盖矩阵报表（`tools/kge-coverage`，只读）
- 输入地图版本与打标结果，输出 `report/coverage-<版本>.md` 与 csv：
  - 节点 × 认知层次的题数；没有主考点题的节点；
  - 题目 × 节点数分布，标出小题超过 3 个节点的；
  - 各层候选占比，A、B 级占比；
- 门槛按 KGE :747（覆盖矩阵 100%）标红，不作为本任务的通过条件（内容缺口靠教研补题）。

### 5. 评测（评测即代码；金标与留出集由教研提供，构建方不接触留出集）
- `evals/kge-tagging/`：
  - `kappa.py`：两名教师独立标注的 Cohen's kappa，按主考点算；另算节点集合的 Jaccard 一致率；
  - `top1.py`：打标结果对金标集的 Top-1 准确率，以及 Top-3 召回；
  - 夹具只用合成题。
- **金标集**：约 100 题，两位教师独立标注，分歧转为节点描述后定稿，放 `evals/kge-tagging/gold/`（只读，教研提交）。
  构建方只用它算指标，不用来调规则或阈值（调参用单独的开发集）。
- **留出集**由教研负责人封存盲测（规则 14）；本任务提供运行脚本，由教研负责人执行。
- 验收的 kappa ≥ 0.7、Top-1 ≥ 90% 要等教研标注到位、真实模型接入后才能测。本任务交付工具，并在合成夹具上证明计算正确。

### 6. 扩至九年级全册
- 依赖 KGE-01 待人确认 #8（一次构建多个专题）与教研给出其他主题的骨架，本任务不虚构节点。
- 本任务先让导入与打标支持多主题：题目按章节归到主题；主题未导入的题记入工作单，不打标。
