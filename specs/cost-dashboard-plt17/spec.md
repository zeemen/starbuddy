# PLT-17 成本仪表盘 · 第一步（离线汇总、实测分布替换假设、只出聚合）

2026-10-17 起由 Claude 按用户授权自主推进（开发计划 v2.0 阶段 1 · 5 月“成本仪表盘”、商业轨“成本仪表盘指标 / 单位经济首版”）。
编号 PLT-17 为仓库排队号。零迁移、不改计量逻辑与权限、不接真实价格与供应商、零新依赖。

## 现状（只读摸底）
- 计量表（`usage_ledger`、`usage_reservation`、`entitlement`）没有学科列；学科只能经 `source_idempotency_key` → `platform.ingest_request.subject` 关联（grade / diagnose），teach、bff_only 资源与分钟类资源归不到学科。档位经 `entitlement → subscription.tier` 取。跨学生汇总现有角色都读不到（运营只读身份 `starbuddy_report` 无计量表权限）。
- 模型调用记录只在结构化日志（`event=model_call`），有任务、学科、token，没有费用；价格表只有示例价。
- `tools/loadtest` 的成本模块已有：额度解析、价格与敏感性计算、加权分位数、报表格式；使用率是“三档等权”的假设。

## 范围
1. 扩展 `tools/loadtest` 成本模块（或同仓新子模块，复用其函数，不另立口径）：
   - **输入**（只收合成样例；真实导出另起）：
     - 学生 × 月 × 资源 × 档位 × 学科（可为“未归因”）的消耗聚合行（伪名，守卫同 kge-calibrate：拒绝个人字段、`synthetic=true` 才收）；
     - 模型调用记录 jsonl（沿用 loadtest 的 `call-records` 格式：任务、学科、token、结果，不含模型标识）。
   - **指标**（只出聚合，任一组学生数 < 20 写“样本不足”，人数取整到 10）：
     - 各档 × 各科（含“未归因”）月人均消耗与额度使用率的 P50 / P90；
     - 各档月人均模型成本 P50 / P90（价格表沿用示例价，标“示例价”）；
     - 每次调用平均成本按任务分解、失败重试占比（如记录可得）、回退（备选供应商）占比；
     - 学科分摊口径并列两种（按调用次数、按 token），标“D5 待产品确认”。
   - **输出**：`cost-dashboard.json` 与 `cost-dashboard.md`（表格），逐字节可复现；首段标注“合成，不是试点结论；价格为示例价”。
2. 合成队列生成器：按档位与学科生成消耗分布（含未归因份额）与调用记录，固定种子。
3. `RUNBOOK` 与 SQL **草案**（不是迁移）：给人在试点环境运行的只读聚合函数说明——经 `ingest_request` 归因学科、经 `subscription` 取档位、只输出伪名化的月度聚合行；函数落迁移与授权须另起 `[NEEDS-HUMAN]` PR。模型调用日志的落库（`model_call_log`）另起。
4. 测试与变异：分位数与分摊计算、样本不足与取整守卫、未归因份额、示例价标注、逐字节一致；make 目标 `cost-dashboard`、`cost-dashboard-test`、`cost-dashboard-mutation` 接进 check（数据生成目标不进 check）。

## 不做
- 迁移、授权、改计量函数与扣次规则；真实价格表与供应商；`model_call_log` 落库；前端页面；连接任何真实库。

## 验收
- 合成队列上各指标可复现且与手算一致；守卫与标注测试通过；变异全部发现；严格 `make check` 通过。
