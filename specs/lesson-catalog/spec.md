- 状态：**已确认（2026-11-28，用户“按建议，默认值都同意，从 PR A 开始实现”）**：第五节七条都按默认。按第三节第 5 条四个 PR 走，实现记录见 lessons.md。
- 来源：`specs/stage-lesson-session` 第三节把“讲评课目录与推荐（哪节课给谁）”另起；讲评课页面（③b-5、L10）至今只能按地址打开。
  用户 2026-11-28 在三个候选里选了这一项。
- 依据：
  - 插件契约：v1.0 的 `PlanTask.kind` 已有 `lesson`，但没有字段指出是哪一节；v1.1 草稿有只读方法 `present_item`（不计量、不产生证据），可以照它定义只读方法；
  - 错题再练：BFF 有意不把题目引用（`item_ref`）转给前端（`services/bff/src/practice/service.ts`），再练条目上显示的是 KGE 知识节点；
  - 阿鸦的讲评课挂在阿鸦自己的节点与题上（`aya:` 本地编号），“阿鸦节点 → KGE 知识节点”的对应表（`skill_links`）在 KGE-01 之前是空的；
  - CLAUDE.md 规则 1（插件 API 是唯一硬接口）、规则 11（对学生可见的关于学生的陈述必须引用判断账本）、规则 13。

## 一、现状（2026-11-28 核对）
- **平台不知道有哪些讲评课**：讲评课只在阿鸦的内容包里（`content/lessons.json`，PR 1），插件契约里没有列出讲评课的方法，学习服务与 BFF 都没有讲评课目录。
- **讲评课页面只能按地址打开**：地址带讲评课编号、版本、阿鸦节点与题（`?v=&node=&item=`）。
  - 地址里的 `item` 就是阿鸦的题号，与错题再练“不把题目引用给前端”的口径不一致；
  - 打开时 BFF 把节点与题原样转给学习服务，由阿鸦核对它们与讲评课是否一致。
- **没有任何入口**：科目页、错题再练、今日计划都没有链接到讲评课。今日编排不处理 `lesson` 类任务，阿鸦的 `plan` 也不产出它。

## 二、哪些入口要判断、哪些不要
| 入口 | 说的是什么 | 要不要判断账本（规则 11） |
|---|---|---|
| E1 科目页“讲评课”列表：列出这一科已发布的全部讲评课 | 内容本身，与学生无关 | 不要 |
| E2 错题再练、复测条目上的“这道题有讲评课” | 这道题有讲评课；学生做错这道题是再练页面本来就显示的 | 不要 |
| E3 今日计划或首页推荐“你可以看看这节讲评课” | 按学生的掌握情况挑课，是关于学生的陈述 | 要：必须引用一条成立或假设状态的判断 |

## 三、默认做法：先做 E1、E2，E3 另起
1. **目录从阿鸦来（契约只读方法）**：
   - 插件契约 v1.1 草稿内追加只读方法 `list_lessons`：
     - 请求带学科与内容版本；
     - 返回这一科已发布的讲评课：讲评课引用（编号、版本）、节点、题（可选）、标题、步数；
     - 不计量、不产生证据、不含讲解 DSL、台词与答疑。
   - 与 `present_item` 同口径：只读、可按（适配器、内容包版本）缓存。阿鸦从已发布的讲评课内容包投影。
2. **学习服务**：
   - 新增内部接口 `POST /internal/v1/lesson/catalog`，写在服务本地的 `lesson-internal.v0.yaml`：按学科调适配器 `list_lessons`，进程内缓存 5 分钟；只认 BFF 会话令牌。
   - 打开讲评课改为只收讲评课引用：节点与题由学习服务按目录补全，再交给阿鸦核对。这样地址里不再带题号，与错题再练的口径一致。
   - 错题再练与复测的条目视图加可选的 `lesson_ref`：学习服务按条目的题目引用，在目录里找讲评课这道题的那一节，题目引用本身仍不出学习服务。
3. **BFF**：
   - 新增学生端路由 `GET /bff/v0/students/{student_id}/lessons?subject=`，转学习服务目录；只回编号、版本、标题与步数，不回节点与题；
   - 打开讲评课的请求体只收讲评课引用与幂等键，计量不变；
   - 再练与复测条目转出 `lesson_ref`；
   - 开关仍是 `STARBUDDY_LESSON`，关时这些都不出现。
4. **前端**：
   - 科目页加“讲评课”一节（E1），每节课一行：标题与步数，点进讲评课页面；
   - 再练与复测作答页在判分结果之后显示“看这道题的讲评课”（E2）；
   - 讲评课地址改为 `/s/{学生}/learn/{学科}/lesson/{编号}?v={版本}`；
   - 文案全是占位（W6）；开关关时这些都不出现。
5. **按四个 PR 走**，每个都是 `[NEEDS-HUMAN]`：
   - A：契约 `list_lessons` 与阿鸦实现；
   - B：学习服务目录、打开改为按目录补全、条目视图的 `lesson_ref`；
   - C：BFF 路由；
   - D：前端与端到端。
