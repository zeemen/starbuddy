密级内部
一摘要

三个判断，一条主线

判断一：四款产品已经长出了同一副骨架。文砺、阿鸦、知行、开口成章各自独立立项，却不约而同收敛到同一套方法论——能力坐标 + 错因分类 + 三层信号采集 + 自适应诊断 + 人机协同审核 + 学科人设 + 家长报告 + 南京本地化。平台不是"把四个 App 合并"，而是把这副共享骨架显性化、标准化，让第五到第七科用一半的成本长出来。

判断二：七科恰好是南京中考的全部笔试学科。语文 120、数学 120、英语 120、物理 100、化学 80、道法 60、历史 60，合计 660 分（体育 40 分另计）。做完七科，产品的承诺就从"帮一科"变成"帮这场考试"——这是平台化最硬的商业理由，也是"全科稀释壁垒"担忧的解法：平台负责共享基座，每科仍然窄而深。

判断三：两大目标统一于一个"学习者模型"。一对一辅导（目标一）与家长学生共成长（目标二）不是两条业务线，而是同一个学生模型的两个读写方。学科包向内写入能力数据，通识层读取"学习动力、压力、自律、家庭陪读方式"这些跨学科维度并做干预。没有这个统一模型，通识内容只是又一个公众号。

主线：先抽基座（3 个月），再接四科与跨学科搭子并上线通识 MVP（至 9 个月），然后用基座长出物理、化学、历史（至 18 个月），最后向高中与学校端延伸（18–36 个月）。高考是第四阶段的事，不是现在的事。

已经收敛的共性方法论（平台基座的来源）

  • 三层信号采集：结果信号（判分）/ 过程信号（耗时、路径、修改轨迹）/ 行为信号（使用节律）——四份文档均采用，英语把语音信号列为第一层。
  • 自适应诊断：IRT / BKT / 遗忘曲线 + 规则引擎 + LLM 分析学生表述，四科同构。
  • 人机协同审核：AI 起草、教研门禁、发布，四科都把它写成"合规即护城河"。
  • 人设治理：备考搭子规格书定义的双层人格架构、禁语表、AI 身份披露、漂移检测、回归测试集——v1.0 时只在知行落地、其余三科各自为政；v1.2 已提升为平台组件，覆盖七位老师与点点。
  • 三视角报告：学生 / 家长 / 教师，家长端"不排名、不焦虑、可行动"。
  • 南京本地化：真题语料、命题风格、评分口径，是四科共同的地域壁垒。

需要正视的一处矛盾：知行 PRD 明确写了"不做全学科覆盖，全科化会稀释学科专属壁垒，且是巨头的战场"。这句话在单科立项时是对的，今天仍然对——平台的答案不是"做一个全科 App"，而是"一个基座 + 七个窄而深的学科包"。壁垒仍然在每科的采分点语料、验证引擎和本地教研里；平台只是让这些壁垒共享同一个学生、同一个家长、同一套引擎。

三平台定位

一句话定位与六条原则

面向南京初中家庭的"一个学生、七位一对一老师、一位学习搭子、一位家庭成长顾问"的 AI 学习平台：以跨学科学习者模型为核心资产，以学科包为可插拔单元，以通识成长内容为家庭入口。

平台命名与核心隐喻（v1.1 新增）

平台定名点斗 StarBuddy（英文连写；中文正式名"点斗"，学生口语"点点"；家长端副标题"点斗 StarBuddy · 中考七科 AI 一对一"）。典出"魁星点斗"，取其"点亮"这一个动作，避开"金榜"的排名意象。定名同时把平台的核心隐喻定为"点亮星图"，把此前各产品分散的说法收拢为一件事：

此前各自的说法统一后

六条平台原则

  1. 基座共享，学科窄深。能共享的（学生模型、诊断、审核、人设治理、报告、舞台）全部下沉到平台；不能共享的（考情、图谱、Rubric、验证器、教研）留在学科包，不为"统一"牺牲学科深度。
  2. 前台角色克制，后台 Agent 自由。学生面前只有"这科的老师"和"一个搭子"，后台可以有十几个 Agent。这是知行架构的原则，也是 OpenMAIC 多智能体的正确用法。
  3. 先有学情，再有通识。通识内容不按栏目推，按学情触发：报告里出现"审题过快"，家长端才收到对应陪读方法课。
  4. 可信优先于可爱。任何判分必须能追溯到 Rubric 或验证器；人设只包装依据的呈现，不能覆写依据。
  5. 不做治疗，做转介。学生心理相关内容止于"学习动力与压力管理教育"，出现危机信号一律引导至学校心理老师、班主任与家长。
  6. 数据是长期资产，模型是可替换零件。Anthropic、Gemini、国产模型都经统一路由层接入；学生模型与教研语料才是不可替换的。

学科考试特征独有支点验证器可复用

排序建议：历史最先（引擎复用率最高、教研成本最低，方圆与春秋同批出稿即成"开卷双科"）；物理其次（分值高、实验模拟是差异化亮点，也是舞台层的验证场）；化学最后（复用物理的模拟框架）。

六学习者模型

平台的核心资产：跨学科学习者模型

单科产品各有自己的学生画像，平台化后需要一个三层的统一模型。内层是各科能力坐标（由学科包写入），中层是跨学科学习力（多科共同观测到的模式），外层是家庭与环境（由家长端与通识层维护）。目标一主要读写内层，目标二主要读写中外层；两者在同一条记录上。内层对学生与家长可见的形态是星图：每科一片星空，每个能力点一颗星，通过掌握门槛即点亮；中层与外层不以星呈现，避免把学习力与家庭状况做成可"攒"的东西。

图 2 · 三层学习者模型。目标一（一对一辅导）主要读写内层，目标二（家庭共成长）主要读写中层与外层。中层是平台独有的价值：单科产品看不见"审题力"这种跨科模式。

两个只有平台能回答的问题

  • 跨科时间预算。一个初三学生每天 40 分钟，该给数学还是道法？答案取决于七科的 ROI（板块权重 × 当前失分 × 可提升系数）在同一个表里比较——这就是文砺 ROI 算法的跨科版本。
  • 共性根因。语文"审题性错因"、数学"审题错误"、道法"审题错"在三个产品里各自统计；平台把它们并成一条学习力指标，家长端只需读一句话："本周三科失分都有审题过快的成分。"

两种模式是刻意保留的差异：道法与英语的第一障碍是说教感与开口意愿，由同辈带着练，权威退到判分时刻；语文与数学需要能讲、能演算的权威常驻。规范统一的是结构与合同，不是教学风格。

三条平台级的角色红线

  • 前台克制。学生在任一学科里最多看到两张脸（本科老师 + 点点），加场景角色不超过三种；后台 Agent 数量不限。
  • IP 边界。老师的来历只能来自公版内容；借原型不借造型；形象定稿前做相似性自查。
  • 一个品牌级 IP。阿鸦是唯一做周边与品牌运营的角色；其余老师是"有一张脸的学科功能"；点点是"有一张脸的平台功能"。

"AI 同学"仍是 OpenMAIC 最值得移植的机制，落地在点点身上：数学课上扮演算错的同学，道法课上扮演漏了主体的同学，英语课上以费曼机制让学生"教"它；错误剧本来自各科错因清单，调用哪条由学生模型决定。一个角色覆盖七科。

八通识成长层

目标二的产品化：由学情触发的家庭教育

通识内容的失败模式是做成"又一个家庭教育公众号"。平台的做法是把它接在学习者模型上：内容按"学情信号 → 推送课程 → 家长践行 → 状态回流"运转，而不是按栏目陈列。

三条红线

  1. 不做心理治疗，不做诊断。学生端所有内容限定为"学习动力与压力管理教育"；出现超出学习范畴的情绪困扰，按备考搭子 4.9 节话术转介学校心理老师、班主任与家长，不承接倾诉。
  2. 不用学情制造焦虑。通识推送只带"可做的一件事"，不带"孩子落后了"的判断；家长端不出现排名与同伴对比。
  3. 家长自身的内容不进入学生模型。家长学习了什么课、认知如何变化，只用于给家长推荐，不作为评价学生的依据。

商业与合规上的位置：通识层属于非学科类内容，是"双减"环境下最安全的获客前门——家长可以先免费学家长学院，再为孩子订阅学科包。它也是七科共享成本最低的内容：一次教研，七科复用。

十演进路线

四个阶段

  • 阶段 0 · 抽基座（0–3 个月）不动四款产品的功能，只做三件事：定义学习者模型 Schema 与学科包八件套规格；把人设治理（规格书、禁语表、回归测试）从知行提升为平台组件；搭模型路由层，让 Gemini 与 Anthropic 走同一接口。验收：四科任一产品能把能力数据写进统一学生模型。
  • 阶段 1 · 四科接入 + 点点 + 通识 MVP（3–9 个月）统一账号与家庭关系；学生端"今日任务"跨四科，星图为主视图；点点上线（记忆 + 日程 + 跨科复盘，AI 同学先只做数学）；知行接入方圆、开口成章的学伴并入点点并接入雅典娜、文砺改为妙笔（按规范第九章顺序）；家长端跨科周报 + 家长学院前 20 课；舞台层先做"白板演算"一个场景。验收：多科渗透率、家长周报打开率、跨科时间预算被采纳率、七科"不恰当直接给答案比例"趋零。
  • 阶段 2 · 新三科（9–18 个月）历史包"知行·史"最先上线：春秋出场、独立 Rubric、合场结算与"换卷"、点点的合场时间分配；物理包上线：阿基、交互实验模板库作为舞台层的第二个场景；化学包：X 博士，复用物理的模拟框架。验收：新科按八件套规格交付的周期 ≤ 既有科的一半；三位考官型老师共用基线、只写角色卡。
  • 阶段 3 · 高中与学校端（18–36 个月）用同一基座向高一至高三延伸（江苏新高考 3+1+2，内容全新、引擎复用）；开放教师 / 学校端；向苏州、无锡复制中考版。前提：中考七科的北极星指标达标，且至少两科有一届完整的中考提分证据。

关于高考：四款产品的全部内容资产都建立在南京中考上，高中是另一场考试、另一套教材、另一种用户自主性（家长权重下降）。基座可以复用，内容与教研必须重来。建议明确写进规划：高考是阶段 3 的目标，在中考线验证 PMF 之前不投入内容生产。

十二商业与指标

家庭订阅 + 学科包 + 冲刺包

十四待决问题

已决与待决

v1.0 的五项待决已关闭三项：平台命名与 IP 世界观（点斗 StarBuddy、点点、阿鸦唯一品牌 IP）；历史独立学科包并有自己的老师春秋，对外仍可与道法打包为"开卷双科"；高考启动条件写死为"中考两科有完整一届提分证据"。仍需拍板：

  1. 英语产品是否迁移技术栈。建议不迁移，通过模型路由接入；但点点的人设层要跨 Gemini 与 Anthropic 保持一致，需模型路由层先做一致性验证——这一项现在同时是角色规范的待决。
  2. 通识层的免费边界。家长学院全免费作为前门，还是部分课程随家庭订阅解锁。
  3. 七位老师的形象出稿顺序与预算。建议与迁移顺序一致：方圆 + 春秋同批、雅典娜、妙笔、阿基、X 博士；阿鸦母版先定稿作为家族锚。
  4. 知行 Rubric 的道法 / 历史分库，方圆与春秋角色卡定稿前完成。
