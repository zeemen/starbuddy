# ADR 04 · 模型路由接口与供应商优先级

- 状态：**草稿，待签字**
- 日期：2026-09-25
- 决策人：待定（建议：技术负责人 + 产品负责人）
- 关联：完整方案 v1.0 第六章“模型与语音”；开发计划 冲刺 1-F（模型路由骨架）、冲刺 2–3-I（点点跨模型一致性）；ADR 08、09
- 来源：ADR 09 §4 第 2 条；四份盘点 §4（模型调用）

> [NEEDS-HUMAN] 本 ADR 决定模型供应商与数据出境路径，属于 CLAUDE.md 规定的必停项。

---

## 1. 背景

### 1.1 原来的口径
完整方案第六章：“国内可商用模型首选，通过模型路由接既有 Anthropic / Gemini 开发链……个人信息跨境另行评估，不默认调用境外 API。”开发计划冲刺 1-F：“三类供应商适配（国内首选 / Anthropic / Gemini）、超时与熔断。”

### 1.2 ADR 09 改变了前提
ADR 09 建议：L2 及以上的数据只能在境内处理，模型路由必须按请求的数据级别选择供应商。“首选”变成了“强制”。

### 1.3 盘点发现

| 学科 | 路由现状 | 问题 |
|---|---|---|
| 文砺、知行（共用一套 `llm/index.ts`） | 用户所选 → 全局 active → `app_settings` → env；env 默认 `claude-opus-4-8` / `claude-sonnet-4-6`，**默认是境外** | 学生可以自选模型；`model_version` 写死 `"routed"`；Anthropic 路径没有超时和重试；OCR 的兜底读错了变量 |
| 阿鸦 | DeepSeek `deepseek-chat`（默认），可切 DashScope；视觉用 `qwen-vl-max` | 模型在境内，但 `OPENAI_BASE_URL` 可覆盖；提示等级由客户端决定 |
| 开口成章 | Anthropic Messages API，`ANTHROPIC_BASE_URL` 可覆盖 | 学生原话出境；没有超时和重试 |

四科共同的缺口：没有计量、没有幂等键、`model_version` 不可追溯、Prompt 没有版本号。

---

## 2. 选项

### 选项 A：按数据级别强制路由
- 路由接口的输入包括 `task`（例如 grade / teach / ocr / embed）、`data_class`（L0–L3，定义见 ADR 09 §2）、`subject`。
- 路由表只允许把 L2、L3 请求发给**境内供应商**；境外供应商只接 L0、L1，或者有单独出境评估记录的请求。
- 违反规则的请求在路由层直接拒绝，而不是降级。

**优点**：合规边界落在一个地方，可测试；与 ADR 09 一致。
**缺点**：点点、老师人设在境内模型上的表现需要重新验证；某些任务（例如长文作文批改）境内模型的质量需要评测。

### 选项 B：国内首选，失败时回落境外
**缺点**：回落时 L2 数据就出境了，违反 ADR 09。**不推荐。**

### 选项 C：每科自己选模型，平台不管
违反总纲，也无法统一计量和审计。**不推荐。**

---

## 3. 决定

**待签字。**

**建议采纳选项 A**，路由接口的规则如下：

1. **统一入口**：所有模型调用（文本、视觉、嵌入、ASR、TTS、发音评测）都经过平台的模型路由。适配器和原产品不能自己持有供应商 Key 或 BaseURL。
2. **按数据级别路由**：
   - L2、L3：只能路由到境内供应商。
   - L0、L1：可以路由到境外供应商（例如用合成数据做 dev 评测、生成题库草稿）。
   - `data_class` 由调用方声明，路由层按字段做校验；声明的级别低于实际级别时拒绝（与契约 spec 待人确认 #7 一致）。
3. **供应商白名单**：每个供应商登记在 `docs/compliance/vendors.md`（ADR 09 第 6 条），数据处理协议签完才能进白名单。路由表只能引用白名单里的供应商。
4. **学生不能自选模型**：去掉文砺、知行现有的“学生自选模型”功能。
5. **可追溯**：每次调用返回并记录真实的 `model_version`（供应商/模型/版本），不允许写死 `"routed"`。Prompt 模板要带版本号，写进 `source_version`。
6. **超时、重试、熔断**：每个 `task` 配置超时和最大重试次数；同一供应商连续失败时熔断，切换到**同一数据级别允许的**另一家供应商；没有可切换的就返回错误，不回落到不允许的供应商。
7. **计量**：每次调用带 `usage_id` 与 `idempotency_key`，记录 token 或分钟数（ADR 06）。
8. **验收测试**（写进契约测试）：构造 L2 请求，断言它永远不会被路由到境外供应商，包括熔断切换的情况。

---

## 4. 后果

### 正面
- 出境控制是架构层面的保证，不依赖各科开发者自觉。
- `model_version` 可追溯，满足判分溯源（CLAUDE.md 第 3 条）。

### 代价
- 开发计划冲刺 1-F 的“三类供应商适配”要改：境内至少接两家（保证熔断时有备选），境外只用于 L0/L1。
- 点点跨模型一致性验证（冲刺 2–3-I）的对象从“Gemini ↔ Anthropic ↔ 国内”改为“境内模型之间”（ADR 08、09）。
- 文砺、知行的作文、阅读、道法主观题批改，要在境内模型上重新测一致率。
