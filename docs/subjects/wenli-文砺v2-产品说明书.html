第一部 · 产品说明书
01

立意与教育理念

文砺不是题库 App，也不是作文代写器，而是一位被产品化的特级语文教师。它回应一个真实判断：南京中考语文是排位的胜负手，而语文提分难，难在它不是知识点的堆叠，而是能力系统的竞争——刷题能换来达标，换不来高分。

三条底层判断

CONVICTION 01

考的是能力系统，不是知识堆叠

120 分表面考字词、默写、阅读、作文，底层考的是真实情境中的理解、判断、表达与审美。所以产品做"能力建模"，不做"题目搬运"。

CONVICTION 02

提分关键不是多写，是写后知道为何丢分

很多学生长期低效，因为练完只得到一个分数，不知失分机制。文砺把失分拆成可诊断、可训练、可复盘的细颗粒能力点。

CONVICTION 03

AI 是过程型老师，不是答案贩卖机

AI 承担四个角色：诊断师 · 陪练教练 · 批改助教 · 复盘导师。它把隐性的语文思维显性化，但不代写、不套作、不押题、不背模板。

命题在变，思路也要变

近年南京卷走向清晰：取消单项选择、阅读量加大、整卷以"游""味"等大情境串联、跨学科命题渐增，整体向高考靠拢。命题组反复传递"授人以渔"。这意味着以"套路 + 题海"为内核的产品方向上就站错了队。文砺把训练重心放在关键能力与思维品质上，套路只是脚手架，不是终点。

立在课程标准的四根柱子上

《义务教育语文课程标准（2022 年版）》把核心素养凝练为四维：文化自信、语言运用、思维能力、审美创造。文砺的每一个能力维度、每一道生成题、每一条提分建议，都向这四维回溯——既是教育正当性，也是与南京"素养立意"命题趋势的对齐。

五条设计原则

PRINCIPLE 01 · 本于教材

课本为本，绝不超纲

南京卷"以书为本"。知识底座以七至九年级统编课本为根，讲解与命题可溯源到具体课文、单元、页码；85 篇必背、120 实词、18 虚词全部入库。

PRINCIPLE 02 · 情境为纲

真实任务驱动

对齐南京"基于单题/板块/整卷"的情境命题。训练以真实任务展开——办寿宴、为卫星命名、写洗手说明——在动态情境中综合调用能力。

PRINCIPLE 03 · 读写一体

读什么喂养写什么

阅读与写作不拆两张皮。名著整本书、现代文精读与作文素材在同一脉络上流动：写不顺，回溯读得不深。

PRINCIPLE 04 · 诊断驱动

一生一案

不预设通用进度，先读懂"这一个学生"的失分结构，再开"这一个学生"的方子。这是"一对一"的实质，也是"日参省"的算法化。

PRINCIPLE 05 · 南京在地

带着这座城的呼吸

"世界文学之都"是南京卷底色：文学踪迹、金陵文脉、城市记忆频频入题。内置南京文化语料，供情境命题与写作素材调用。

PRINCIPLE 06 · 人机协同

AI 起草，教师把关

诊断、命题、批改的产物，关键处必经教研规则与人工审核。AI 加速，但语文内容的最终品控是人——这是质量的根，不是点缀。

ROI 的来源

这张分值地图直接喂给"提分 ROI"算法（见 §4）。举两个对照：作文从基准约 35 分提到 42 分（+7），其性价比相当于数学多对一道大题；而积累板块的默写、字形属"满分区"，补满见效快、确定性高。优先级 = 板块权重 × 当前失分 × 可提升系数——让有限的复习时间落在回报最高的格子上。

03

D6、D7 是本版相较初稿的关键补全——它们正是南京卷最爱考、又最难靠刷题解决的两块（情境化综合表达、考场稳定性）。贯穿七域之上还有一层思维与素养主线（逻辑、批判、审美、文化自信），不单独成题，却是 L3–L4 高分区的隐性门槛，也是"刷题到不了高分"的真正原因。

错因分类学：把"做错了"翻译成"为什么错"

诊断的价值不在指出"错了"，而在归因。每处失分映射到六类错因，处方因错因而异——审题性的错，练再多知识点也无效。

错因典型表现处方方向
知识性字词记错、实词义项不清、默写错字、文学常识混淆知识微课 + 间隔复现
审题性答非所问、漏答分点、未抓限定词、作文立意漂移审题四步法 + 题干圈画
定位性文本区域找错、信息筛选遗漏、依据缺失圈点勾画 + 回归文本训练
思维性概括不全、推断无据、赏析无层次、论证断裂思维支架 + 同类变式
表达规范性要点对但表述乱、术语缺失、语言平淡、书写潦草、字数不足答题范式 + 升格 + 卷面专项
策略时间性时间分配失衡、难题死磕、阅读量大读不完整卷节奏 + 取舍策略训练
04

核心闭环

文砺的运转是一个不断收紧的螺旋：诊断 → 规划 → 学习 → 训练 → 批改 → 复盘 → 再诊断。每一轮都让能力坐标上的薄弱格更亮一点。这是"日参省"的产品形态。

四条可落地的子闭环

主闭环之下，是四条针对具体场景、可直接编码实现的回路。它们让"闭环"从概念变成产品里看得见的流程。

闭环流程
试卷闭环上传试卷 → 识别得分与错题 → 失分报告 → 圈出 3 个最关键薄弱点 → 推送对应微课 → 变式训练 → 3 天后复测 → 更新画像
作文闭环上传作文 → 五维诊断 → 给出 3 条最关键修改建议 → 学生二次修改 → 对比修改前后 → 收录优秀句段 → 推送下一篇针对性训练
阅读闭环完成阅读题 → 判断错因 → AI 引导回到文本找依据 → 学生重答 → 展示标准答题结构 → 同类变式 → 沉淀为题型方法卡
考前闭环模拟卷训练 → 分模块失分统计 → 生成考前失分清单 → 一周内集中修复高频失分 → 限时组合训练 → 形成个人考场策略
提分 ROI 优先级算法并非"哪里弱补哪里"，而是按 板块权重 × 当前失分 × 可提升系数 排序：默写补满（高确定、快见效）排在作文深度立意（慢周期）之前同等失分下优先处理。这让有限时间花在回报最高的格子——"顶层系统设计"在学习路径上的落点。
05

功能模块

六大引擎支撑完整闭环。每个模块都以学生能感知的语言命名，而非系统内部术语。

M1

学情诊断引擎

DIAGNOSTIC · 入口与地基

学生拍下作业本、月考卷、作文、错题、老师批改稿，系统十几秒还原一张可读的"语文体检报告"。它解决最痛的盲区：知道分低，不知道低在哪、为什么低。

  • 多源采集：日常作业、单元/期中期末卷、模拟卷、作文原稿、批改后作文、错题本、课堂笔记；手写与印刷混排
  • 首次诊断卷：历史材料不足时，提供 30–45 分钟、少量高区分度题的 AI 诊断卷，快速判定能力层级（不追求覆盖全考点）
  • 归因引擎：每处失分落到「能力坐标 × 六类错因」，而非只判对错
  • 三件套输出：七域能力雷达图、失分热力图、全市位次预估区间（对齐南京不公开排名、只给位次的口径）
失分画像的语言系统不说"阅读差"，而说——"信息筛选有遗漏 + 概括语言不够抽象 + 缺少作用分析的答题角度"；不说"作文不好"，而说——"审题能扣住，但材料普通、叙事没有转折、结尾升华空泛"。可诊断，才可训练。
M2

处方与学习计划引擎

PRESCRIPTION · 一对一的实质

把诊断翻译成可执行的方子。不是发通用大纲，而是为"这一个学生"给出排好优先级的提分路径与个人化方法建议。

  • 三层计划：长期路线（按年级设年度目标）→ 阶段计划（4 周一周期）→ 每日任务（20–40 分钟，避免无效堆量）
  • ROI 排序：高权重×高失分×高可提升的格子排在最前，标注"预计提分区间"（明示为预测非承诺）
  • 方法处方：针对个体错因画像，推送对应学习心法（审题四步、文言断句、阅读答题范式、碎片时间古诗文循环记忆）
  • 动态调整：同一能力点连续三次出错自动降阶讲解，连续三次稳定正确自动升阶训练
M3

内容与学霸方法库

CONTENT · 把暗知识显性化

两类内容：体系化的知识微课（对齐每一个能力格，3–6 分钟），与历年高分生的方法心法——那些"学霸会、老师懂、却很少被结构化写下来"的暗知识。课程按基础/专题/冲刺三类、初一/初二/初三三阶组织。

  • 基础课：统编六册字词、古诗文逐句讲解与默写坑点、文言实虚词、课文精读、名著导读
  • 专题课：现代文按概括/含义/作用/赏析/形象/主旨/探究/非连分型突破；古诗文意象情感手法；作文审题/选材/结构/语言
  • 冲刺课：复杂文本、跨文本比较、文学类深度赏析、思辨写作、南京地方文化素材库、限时模拟、考场失误清单
  • 学霸方法库：默写记忆法、五步精读法、"一材通吃六类主题"的素材活用、卷面提分术——经脱敏提炼自真实高分生
M4

命题与测评引擎

ASSESSMENT · "验"的核心

验证学习成果的发动机。按能力维度与难度层仿南京命题风格生成新题——情境化、本于教材、带"文学之都"气息、跨学科——再自动批改、复测、回流。所有 AI 生成题必经教研审核方可入库，不直接推给学生。

  • 定向生成：指定「维度×难度×错因」出变式题或全新题，绝不题海
  • 题目标签体系：每题至少标注 年级·册别·知识点·能力点·题型·难度·预计用时·区分度·常见错因·解析层级·对应课程
  • 自适应出题：基于知识追踪（BKT/DKT）实时调难度，使训练落在"最近发展区"；薄弱生先做低难度高反馈题
  • 测评分级：每日小测（5–10 分）· 周测（20–30 分）· 月测（接近中考结构）· 考前全真限时模拟
M5

作文批改与升格引擎

WRITING · 决胜高地

作文占全卷约 45%，是"想拿高分却最难"之处。文砺以五维量表批改，逐句朱批，给可操作的升格路径，而非一句"语言再优美些"。严禁一键生成整篇作文作为学生作品——只做诊断、局部修改、句段润色示范、素材追问与二次修改任务。

  • 五维量表：审题立意 · 内容材料 · 结构层次 · 语言表达 · 书写卷面（小作文另设任务完成度、格式规范、对象意识、语言得体）
  • 对齐南京评分：基础等级 + 发展等级双轨，参照基准分约 35 给"起步分 + 加分项"
  • 五阶训练路径：写清楚（中心结构）→ 写具体（细节场景）→ 写深刻（升华思辨）→ 写有文采（语言节奏修辞）→ 写稳定（限时构思成文）
  • 作文成长档案：常用题材、常见问题、优秀句段、修改前后对比、二次成文质量留痕
能力诚实声明作文"立意深刻 / 发展等级"判断是当前 AI 最难稳定对齐人工阅卷之处。策略：客观维度（结构、规范、语言硬伤）AI 主判；主观高分维度给"参考分 + 依据"并显式标注不确定度，引入人工复核抽样校准——不向学生承诺"AI 判分等于中考阅卷"。
M6

AI 陪练与错题复盘

COACHING · 过程型老师

做题时 AI 不直接给答案，而以苏格拉底式追问引导；错题不进收藏夹，而进"错因数据库"。这是"过程型老师"定位最实的落点，也是反代写的护栏。

  • 三级提示：一级提醒审题方向 → 二级定位文本区域 → 三级给出答题结构 → 多次无法推进才展示完整解析
  • 苏格拉底追问："题干要你分析人物形象，文中哪些动作、语言、心理可作依据？""你只写了性格词，能从第 3 段找一句话支撑吗？"
  • 错题=错因库：每道错题关联同能力点训练题；三次复盘机制——当天理解错因、3 天后做变式、14 天后混合检测
  • 复发预警："你不是不会这道题，而是'句段作用题'的答题结构没有稳定形成。"

08

数据与合规边界

面向未成年人、涉及教育、易碰提分承诺——三条高压线同时存在。下面不是免责声明，而是立项阶段就必须纳入设计的硬约束。诚实摆上台面，比事后补救成本低得多。

边界 01 · 未成年人保护用户是初中生，受《个人信息保护法》《未成年人网络保护条例》约束。需求：监护人知情同意（不满 14 周岁需家长授权）、最小必要采集、试卷作文图像加密存储与一键删除、不做超范围画像、每日学习时长提醒与夜间使用限制、过度依赖提示。这一条决定数据架构，不能后置。
边界 02 · 教培政策定位"双减"对义务教育阶段学科类校外培训有明确限制。文砺须定位为面向学生自主学习的 AI 工具/软件，而非学科类校外培训机构或直播授课。该定位合规性需法务在立项期专项评估，并据此约束功能边界（是否做真人直播授课、C/B 端口径差异）。此为立项级风险，不可含糊。
边界 03 · 不当宣传红线《广告法》禁止"保过""提分 X 分""效果保证""全额退款"等绝对化用语；亦不宣传"押题""预测全市排名""状元模型"。"预计提分区间"必须明示为基于数据的预测而非承诺。各头脑风暴稿中出现的"60 天明显提升 / 三个月未达标退款 / 稳定提分 10–20 分"等表述，本版一律剔除。
边界 04 · 不诱导代写 + 内容审核作文模块禁止一键生成整篇作品供学生提交，只提供启发、局部修改、范例片段与二次修改指导。所有 AI 生成的题目、范文、批改语经内容安全审核与教研把关，建立人工抽检与快速纠错回路；训练模型不得直接使用可识别学生身份的数据。

09

研发路线图

原则：先用最小闭环证明诊断价值，再逐层加厚。最危险的做法是先囤大题库——文砺的命脉是"诊断—处方—复测"链路跑通，而非内容规模。四阶段递进，每阶段有可独立验收的产物。

P0≈ M0–M2

诊断闭环 MVP

证明"上传一张试卷，就能得到有用的诊断 + 一条该补什么的建议"。

范围：单板块切入（建议先做 D1 基础积累 + D2 古诗文默写——OCR 与判分最可控、最快见效）。打通：上传 → OCR/解析 → 能力归因 → 诊断报告 → 单题测验。

验收：对真实月考卷，板块定位与人工判读一致率 ≥ 85%；学生/家长看完能说出"该补哪"。

P1≈ M2–M5

处方 · 训练 · 命题

从"看懂问题"走到"给出并执行方案"，闭环首次完整运转。

范围：补齐七域能力坐标；上线处方引擎（ROI + 三层计划）、知识微课与方法库 V1、命题引擎（客观题 + 简单主观题量表）、AI 陪练分层提示、错题库与三次复盘。现代文与名著维度接入。

验收："诊—断—方—练—验"跑通；定向生成题能力标签与难度准确率达标；连续使用两周后薄弱格复测可见改善。

P2≈ M5–M8

作文批改 · 整卷模考 · 家长端

啃下最难、最值钱的作文，并让价值对家长可见。

范围：作文五维批改 + 逐句升格 + 五阶路径 + 范文对照；整卷限时模考与位次预估；成长追踪时间轴；家长端周报。引入人工复核抽样校准作文判分。

验收：作文客观维度判分与教师一致性达标、主观维度提供可信参考分 + 依据；家长端报告可读性获正反馈。

P3≈ M8 起

规模化 · 风格精调 · 教研端

从"能用"到"好用、可信、可放大"。

范围：题库与微课扩容；用真实数据精调命题风格与批改一致性；上线教研/教师端（班级看板、一键组卷、审核后台）；持续 A/B 验证提分有效性。

验收：北极星指标（§13）达成；规模化下诊断与批改质量不衰减；形成"口碑—数据—精调"正循环。

内容生产计划（并行轨）

内容是文砺的"教材级护城河"，也是冷启动最大工程，须与研发并行、由教研专家主导。AI 能加速生产，但教育内容的最终品控必须是人——尤其评分细则与范文这类"标准件"。所有 AI 生成内容只能作初稿，必经教研审核方可发布。

成功度量与 MVP 优先级

一个产品若不能证明"用了就提分"，再精巧的架构也是自娱自乐。度量围绕一个北极星，分层支撑。

北极星指标 · North Star持续使用 8 周以上学生的"薄弱能力格复测提升率"。它同时锁住三件事：留存（用得久）、有效（真提分）、闭环（复测可证）——而非单纯的活跃或题量。
层级关键指标
诊断质量板块定位准确率、错因归因与人工一致率、位次预估命中率、AI 误判率
提分有效性薄弱格复测提升率、错题复发率下降、作文二改提升幅度、阶段模考分数/位次轨迹
命题与批改生成题教研采纳率、作文客观维度判分一致性、批改被采信度、解析满意度
使用与体验任务完成率、复盘完成率、作文提交率、学生/家长满意度、教师可用性评价
