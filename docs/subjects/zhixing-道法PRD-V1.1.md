## 一、问题陈述（Problem Statement）

南京中考道德与法治满分60分、开卷考试、与历史合场合卷（共100分钟），目标用户需考到56分以上，容错率仅约6.7%。当前学生的核心困境有二，且相互加固：

1. **能力困境**：开卷考试不考记忆，考的是"审题→定位→转化→规范表达"的过程能力；但学生的日常训练（刷题、背诵）仍停留在闭卷逻辑，练习方式与考试要求的能力错位。多份独立分析一致指向同一个根因：**56分与48分的学生知识量差异不大，差在能否在30秒内看透材料、精准定位教材、把大白话转化为踩分的学科术语**。
2. **接受度困境**：道法学科天然带有说教语感，青春期学生的心理防御机制使其对"被教育感"高度抗拒，这是比知识缺口更前置的障碍——学生首先要"愿意学"，才谈得上"学得会"。

不解决这两个困境，学生的学习时间会持续投入在低效的记忆型努力上，56分成为难以突破的天花板；对产品而言，不解决这两个问题，就无法与市场上已充分军备竞赛的"讲题型"竞品形成差异化。

## 二、目标与非目标

### 2.1 产品目标（Goals）

| 目标 | 度量方式 |
|---|---|
| G1 · 学生真实提分 | 种子用户群一个学期内道法模考平均分 +3 分以上 |
| G2 · 学科接受度转正 | 学生自愿使用（非家长强制打开）比例、"说教感"负反馈率降至可接受阈值以下 |
| G3 · 主观题批改建立公信力 | AI判分与一线教师判分一致率 ≥ 90%，作为整个产品可信度的基石 |
| G4 · 建立不可复制的本地数据资产 | 沉淀南京地区采分点标注语料库与开卷应试过程数据集，形成12–18个月的竞争窗口 |
| G5 · 商业验证 | 免费诊断→付费训练闭环转化率达到可持续获客成本（CAC）以内 |

### 2.2 非目标（Non-Goals，本版本明确不做）

| 非目标 | 理由 |
|---|---|
| 不做全学科覆盖 | 与文砺（语文）分属独立单科深耕产品，全科化会稀释"学科专属"的核心壁垒，且是巨头的战场 |
| 不做纯题库/搜题功能 | 红海功能，全行业已同质化，不构成差异化投入优先级 |
| 不做任何线下场景（展馆、研学基地、线下硬件联动） | 明确定位为纯线上服务产品，线下场景涉及额外的资源整合、运营与硬件成本，超出本产品边界，不予考虑 |
| 不做AR/VR相关功能 | 同上，产品形态限定于线上软件（Web/App/PWA），不涉及AR/VR技术栈 |
| 不做开放式情感陪伴/社交功能 | 未成年人陪伴类产品监管与伦理风险高，人设严格锚定学习任务，不做泛化陪聊 |
| 不支持非南京地区中考的其他省市命题风格（V1） | 本地化是核心壁垒来源，优先把一地做深，而非广撒地域摊薄数据资产 |

## 三、用户画像与用户故事

### 3.1 用户分层（与竞品报告一致，此处细化为故事）

- **冲优生（P0）**：其他科目强，道法是唯一拖分项，目标56+。
- **稳定生（P1）**：48–54分区间波动，缺乏稳定的答题过程习惯。
- **后进生（P1）**：45分以下，学科排斥感强，人设机制的价值最大化层。
- **家长（P0，付费方）**：需要看得懂的诊断证据，而非"孩子又在玩手机"的疑虑。
- **教研顾问（内部角色）**：南京本地一线/特级教师，承担human-in-the-loop审核。

### 3.2 核心用户故事

- 作为**冲优生**，我希望知道自己那4分具体丢在审题、定位、转化还是表达，而不是笼统地"多刷题"，这样我能把有限时间花在刀刃上。
- 作为**后进生**，我希望学习工具不像老师一样评价我，而是像一个"过来人"陪我一起搞定考试，这样我才愿意打开它。
- 作为**任意层级学生**，我希望上传自己写的主观题答案后，能像真实阅卷一样被逐点打分并说明依据，而不是被泛泛地说"写得不错但要加油"。
- 作为**任意层级学生**，我希望每天花10分钟就能把最新时政和考点对上，而不是考前才临时抱佛脚。
- 作为**家长**，我希望每周收到一份看得懂的报告，知道孩子的进步具体发生在哪个维度。
- 作为**学生**，当我质疑AI给的分数时，我希望能看到判分依据的评分标准原文，而不是与"AI人设"发生关系性的对抗。

## 四、竞品结论摘要（详见《竞品分析报告》V1.0）

多轮独立分析高度收敛于同一结论：

- 市场分为**题库工具型**（作业帮、小猿搜题）、**全科AI辅助型**（学而思九章爱学、猿辅导/小猿超级学练智能体、讯飞AI学、夸克老师）、**大厂流量型**（豆包爱学、有道小P）、**垂直内容型**（妙懂德与法）四类；
- 全部竞品对道法学科要么是"全科标签之一、无学科深度"，要么是"内容数字化、无AI智能化"；
- **无一家产品针对开卷考试形态做过原生设计**（无采分点级批改、无限时定位训练、无时政动态挂接）；
- 道法学科是全国性大厂的结构性ROI盲区（用户规模小、需专项微调投入），这个盲区是本产品最大的护城河来源，且不易被短期复制。

## 五、产品战略：断代定位的三层结构

1. **范式层**：从"讲题的老师"变为"练过程的考场教练 + 陪练学长"，直接对应能力困境与接受度困境两个根因；
2. **数据层**：采分点标注语料库（内容资产）+ 开卷应试过程数据（学生审题耗时/定位路径/修改轨迹，行为资产）双轮驱动，形成对手难以复制的数据飞轮；
3. **本地层**：南京命题风格、合场合卷时间分配、本地教研合作，构成全国性产品无法快速复制的地域壁垒。

一句话定位：**不是"政治学习APP"，而是"开卷考试策略教练"**——工具用完即走，教练陪伴到考场。

## 六、人设系统 PRD

> 本节承接《知行产品计划书》人设章节，并吸收多方对"学长学姐"人设的补充论证与批判性意见，形成最终方案。

### 6.1 设计依据

心理抗拒理论：青春期学生对"被教育感"高度防御，对"过来人经验"高度开放。人设将产品话语从**训导**重定义为**攻略**，是解决"接受度困境"的第一机制，而非营销包装。

### 6.2 人设命名与老化问题的解决

多方讨论中出现一个值得重视的批评：固定"学长/学姐"人设长期运营会出现"为什么AI一直是初三/一直不毕业"的认知违和。综合处理方案：

- **主人设采用"备考搭子"（Study Buddy）而非固定年级的学长学姐**——不设定"现在读高几"，弱化年级绑定；
- **"过来人经验"以内容资产形式存在，而非人设身份**：设立"学长笔记"栏目承载经验分享类内容，人设本身保持"这场考试我很熟"的模糊胜任感，不强调具体届别；
- 允许用户在多个语言风格间选择（见6.3），但人设的核心叙事保持长期一致，避免逐年重塑成本。

### 6.3 人设矩阵（多风格可选）

采用多风格并行策略，供学生按自己的接受偏好选择，而非强加单一人设：

| 风格 | 特征 | 适配学生 |
|---|---|---|
| 稳健技术流 | 冷静理性，擅长拆逻辑、做结构化归纳，讲"命题人挖坑"视角 | 逻辑思维强、反感煽情的学生 |
| 轻松吐槽流 | 网感强、擅长用生活化类比讲时政，语言接近B站学习区UP主 | 对学科有抵触、需要祛魅的学生 |
| 温和陪伴流 | 共情为主，主打"我当年也丢过分"式的鼓励与拆解 | 基础薄弱、易焦虑、需要情绪兜底的学生 |

三种风格共享同一套双层人格架构与安全护栏（见6.4–6.5），仅在表层语言风格上区分，工程上作为同一Persona规格的三套语料变体，而非三套独立系统。

### 6.4 双层人格架构（核心设计约束，不可妥协）

```
外层：陪练人设 —— 负责关系、动机、学科祛魅、复盘叙事、语言风格
内层：采分点引擎 —— 负责判分、归因、数据（权威所在，人设不可覆写）
```

判分永远引用评分标准原文，不由人设的"个人意见"给出；学生对分数的质疑被导向标准依据本身，而非与陪练人设发生关系性对抗。这一约束贯穿所有功能模块的输出设计。

### 6.5 三条安全设计（合规即护城河）

1. **任务锚定**：闲聊具备温和收口机制，会话目标持续回到训练任务，不做无边界的自由聊天；
2. **推回真实关系**：定期主动引导学生倚重真实的师生、同伴与家庭关系，明确产品是陪练而非替代性关系；
3. **未成年人保护红线**：不承接深度情感倾诉与恋爱/暧昧话术；使用时长设有节律提醒；遇到超出学习范畴的心理信号，引导求助学校心理老师、家长或专业资源，绝不在人设内自行"消化"。

### 6.6 语言设计规范

- **鼓励**：短句、真实经验叙事、适度自嘲、生活化类比讲抽象概念（如用"班级选举"类比"全过程人民民主"的协商与选举维度）；从生活情境切入教材概念，而非从教材定义切入生活，即"生活先行、教材归位"的对话顺序；
- **禁止**：居高临下的评价性语言（"你应该""你必须"）；对课程价值内核的消解性调侃（反说教，不反价值——吐槽枯燥可以，消解法治/价值观内核不可以）；制造情感依赖的表达。

### 6.7 人设工程化管理

Persona规格书 + 三套风格语料库 + 统一禁语表 + 一致性回归测试集，作为版本化代码资产管理，全部语料经human-in-the-loop审核后发布；长对话中做人设漂移检测。

## 七、功能需求

> 需求分级遵循 MoSCoW：P0（Must，无此不成立）/ P1（Should，重要但不阻塞首发）/ P2（Could/未来，架构预留）。每项含验收标准（Given/When/Then或checklist）。

### 7.0 系统总览：多智能体编排架构

综合多方对"多Agent协同"的一致建议，后台采用多角色智能体分工、前端统一呈现为"一个陪练搭子"的架构，而非把多个AI身份暴露给学生：

```
学生（多模态输入：文字/拍照/语音）
        │
        ▼
   总调度层（Orchestrator）── 感知当前任务类型，路由到对应能力
        │
   ┌────┼────────┬────────────┬────────────┬────────────┐
   ▼    ▼         ▼            ▼            ▼            ▼
拆题Agent  阅卷Agent   特级教师Agent   学情Agent    时政Agent   语言润色Agent
(命题人   (采分点     (苏格拉底式    (薄弱点画像  (热点-考点   (大白话→
 视角逆向  逐点批改)    引导，不直    诊断路径     动态挂接)    学科术语)
 拆题)                 接给答案)     规划)
        │
        ▼
   人设表达层（Persona Layer）── 将各Agent的结构化输出，统一转译为陪练人设的语气与话术
        │
        ▼
   学生看到的：一个连贯的"备考搭子"，而非多个AI身份
```

设计原则：每个后台Agent独立优化、独立评测、独立版本迭代，可控性优于单一大模型直接承接全部任务；学生侧体验保持人设的统一性，多Agent对学生不可见。

### 7.1 F1 · 逆向拆题训练器（命题人视角）（P0）

**用户价值**：训练"看透命题陷阱"而非"背对答案"的能力，直接对应命题人视角的教研共识。

- 功能点：
  - AI对给定设问自动标注三要素（设问类型：是什么/为什么/怎么办/辨析；主体：国家/社会/个人等；限定词：如"根本""主要"）；
  - 学生先自行拆题，AI再展示拆题结果，差异即教学点；
  - 针对选择题，AI生成高质量干扰项并标注干扰类型（偷换概念、绝对化表述、以偏概全等），训练"排雷"能力；
  - 人设融合：以"命题人想在这里挖坑"的攻略口吻呈现，而非纠错口吻。

- 验收标准（checklist）：
  - [ ] 给定任意历年真题设问，系统能正确标注设问类型、主体、限定词，与教研标注一致率 ≥ 90%
  - [ ] 学生提交自己的拆题结果后，系统展示差异对比而非直接给对错判断
  - [ ] 干扰项标注需说明干扰类型，不能仅标"错误"

### 7.2 F2 · 开卷定位引擎 + 限时模拟器（P0）

**用户价值**：开卷考试的核心差异化能力——检索速度，是竞品矩阵中的完全空白项。

- 功能点：
  - 教材知识图谱：六册教材重组为四大领域（心理与道德/法律/国情国策/责任担当）约30个大概念节点，每节点挂接页码索引、高频设问方式、答题话术库、真题回链，SVG交互式可视化呈现；
  - 限时翻书模拟：给出一句设问，倒计时内要求学生说出册数/课名/页码区间；
  - "材料解构器"：AI自动标注时政材料中的关键词到知识点的映射路径；
  - 人设融合：设置"你 vs 搭子的历史最佳用时"的对抗赛制，而非单纯计时器。

- 验收标准：
  - Given 学生进入限时定位模式，When 系统给出一条设问，Then 系统在学生作答后立即反馈实际定位是否正确、用时对比历史基准
  - [ ] 知识图谱覆盖四大领域全部约30个大概念节点，每节点信息完整（页码/设问/话术/真题）

### 7.3 F3 · 采分点批改引擎（阅卷Agent）（P0，技术含金量最高）

**用户价值**：全部竞品分析一致认定的核心壁垒——把"给标准答案"升级为"像阅卷人一样按点判分"。

- 功能点：
  - 拍照/键入上传主观题作答，OCR/文本识别后进入批改流程；
  - 每道题维护机器可读的采分点结构（要点/关键词族/主体维度/分值），逐点输出judgment（命中/部分命中/未命中）+ 证据句引用；
  - 失分归因分类为四类：审题错（未看清设问要求）/定位错（知识点定位错误）/转化错（照抄材料未转化为学科语言）/规范错（表达不符合学科术语规范）；
  - 判分结果可申诉，申诉进入教研审核队列；
  - 人设融合：批改报告以陪练搭子的复盘口吻呈现，但扣分依据必须逐条引用评分标准原文，不含糊。

- 验收标准：
  - [ ] AI判分与教师判分一致率 ≥ 90%（抽样双盲测试）
  - [ ] 每个失分点必须标注四类归因中的一类，不允许"未说明原因"的扣分
  - [ ] 申诉通道可用，且申诉记录进入教研审核队列供人工复核

### 7.4 F4 · 学科语言润色（大白话翻译）（P0）

**用户价值**：多方分析高度一致指出的失分环节——学生"想得到但写不出"，是56分与48分之间最常见的差距来源。

- 功能点：
  - 学生输入口语化答案，AI输出对照润色版本，逐句高亮修改点并说明修改理由（如"多花钱搞研发"→"落实创新驱动发展战略"）；
  - 提供该考点的"高频学科术语簇"供积累；
  - 人设融合：以"帮你把这句话的分数捞回来"的实用口吻呈现，而非单纯的语法纠正。

- 验收标准：
  - [ ] 润色输出必须逐句对照原文，不能只给最终版本
  - [ ] 每处修改需说明对应的采分点或术语规范依据

### 7.5 F5 · 时政—教材动态挂接流（P0/P1）

**用户价值**：道法学科相对其他学科的独特考试特征——时政强关联，是静态题库型竞品的结构性弱项。

- 功能点：
  - 每日抓取官方时政小册子与白名单权威媒体源，AI自动锚接教材知识点，进入教研审核队列后发布；
  - 按南京卷命题风格生成变式题（材料替换、设问角度变化，同考点不同情境）；
  - 考前8周聚合为时政冲刺专题包，形成季节性内容高峰；
  - 人设融合：以"今日份考点情报"的攻略口吻呈现，而非新闻播报口吻。

- 验收标准：
  - [ ] 时政内容仅采信官方小册子与白名单源，杜绝未审核来源
  - [ ] 每条时政素材必须完成教材锚点标注后才可发布给学生
  - [ ] 全链路（抓取→标注→审核→发布）周级节拍，考前提频至日级

### 7.6 F6 · 苏格拉底式答疑（特级教师Agent）（P1）

**用户价值**：多方一致认为，直接给答案会削弱学生自主构建知识网络的能力，尤其是价值判断类问题需要学生自己"走到结论"。

- 功能点：
  - 学生提问时，AI默认不直接给出完整答案，通过2–3轮追问引导学生自己组织回答；
  - 连续多次仍无法自主得出结论时，切换为直接讲解模式（避免过度追问造成挫败感）；
  - 从生活情境切入教材概念（"如果你最好的朋友考试作弊，你会怎么做"），再回归教材语言，而非从定义出发。

- 验收标准：
  - [ ] 默认追问轮次上限为3轮，超过后自动切换讲解模式，避免死循环挫败学生
  - [ ] 追问内容需与学生上一轮回答直接相关，不可使用通用模板化提问

### 7.7 F7 · 错题变式与个人知识图谱（P1）

**用户价值**：错题本从"抄题"升级为"归因驱动的针对性强化"。

- 功能点：
  - 错题自动归入四类归因（审题/定位/转化/规范），聚合成个人薄弱点画像；
  - 针对薄弱点，AI生成同考点、不同情境背景的变式题（如把"环保案例"替换为"航天案例"）持续强化；
  - 五维能力坐标可视化（审题力/定位力/转化力/规范力/时政敏感度），复用文砺能力坐标系建模方法。

- 验收标准：
  - [ ] 每道错题必须归入四类归因之一，禁止无归因入库
  - [ ] 变式题需保持同考点、同难度，仅替换情境素材

### 7.8 F8 · 语音抽背与碎片化闪卡（P1）

**用户价值**：满足碎片时间学习场景，同时避免"学习=大段刷题"的负担感。

- 功能点：
  - 语音背诵实时核对，卡壳时给出渐进式提示（先给首字提示，而非直接念出答案）；
  - 基于遗忘曲线的知识闪卡推送，仅在遗忘临界点触达，避免打扰。

- 验收标准：
  - [ ] 语音识别与核对延迟 ≤ 2秒
  - [ ] 提示为渐进式（首字→半句→完整提示三级），不可一次性给出完整答案

### 7.9 F9 · 家长门户与学情报告（P0）

**用户价值**：付费决策者需要可信、可读的进步证据。

- 功能点：
  - 周报呈现五维能力雷达变化、本周训练记录、一条具体可执行的家庭配合建议；
  - 报告语言面向家长，呈现数据与评分标准依据，语气严肃专业（与学生端人设语言双轨）。

- 验收标准：
  - [ ] 周报生成后48小时内推送
  - [ ] 报告内容需包含至少一条可执行建议，不能只有数据展示

### 7.10 F10 · 全真合场模拟（P1/P2）

**用户价值**：南京特有的道法+历史合场100分钟考试场景，训练跨科时间分配，竞品完全空白。

- 验收标准：
  - [ ] 模拟考试时长、题型比例与官方合场卷结构一致
  - [ ] 交卷后生成分科用时分析，标注是否存在时间分配失衡

### 7.11 F11 · 分支决策情境卡（P1）

**用户价值**：把情境材料从"事后分析"改为"事中决策"，训练强度高于常规材料分析题，同时是F5时政素材的一种轻量呈现形态，适配碎片时间高频触达。

**设计依据**：情境的价值来自"目标—角色—情境—互动—反馈"的对话化训练机制，而非任何空间或硬件载体；本功能完全基于文字/网页交互实现，不涉及AR/VR或线下场景，符合第二章非目标约束。

- 功能点：
  - 每张情境卡呈现一个具体的两难或多难处境（真实合理的多方立场，而非有绝对对错的选择题），学生选择后AI说明该选择对应的教材知识体系分析角度；
  - 选择后追加一轮条件变化追问（"如果情境条件变了，你的判断会变吗"），训练知识迁移而非单点记忆；
  - 情境卡内容纳入F5时政—教材挂接流水线统一生产，将时政素材改写为决策卡形态，经human-in-the-loop审核后发布；
  - 每张卡片明确标注对应考点与知识图谱节点，与F2知识地图打通；
  - 人设融合：由陪练人设主持"我们来试试这个场景"的开场与"这道题在考卷上大概能拿几分"的收尾，情境本身不引入独立于陪练人设之外的角色人格。

- 验收标准：
  - [ ] 每张情境卡须标注对应考点、知识图谱节点、来源时政素材（如有）
  - [ ] 选项须为真实合理的多方立场，不含明显唯一正确答案的诱导性选择
  - [ ] 学生选择后必须触发至少一轮条件变化追问，不可选完即结束
  - [ ] 情境卡内容经human-in-the-loop审核后方可发布，审核记录可追溯
  - [ ] 情境卡开场与收尾统一由陪练人设主持，不引入独立角色人格

> 说明：F11为纯线上、无AR/VR、无线下场景的情境化学习功能，源自对"具身认知"理念的重新设计——保留"情境驱动决策"的学习机制，剔除展馆/硬件等载体（详见《线上虚拟情境设计研究》V1.0）。更复杂的"对话驱动多角色情境剧场"范式暂不纳入本版本，留作P2阶段视教研资产储备情况评估。

## 八、技术架构

### 8.1 总体架构（文砺架构的第二学科实例化）

```
客户端  Next.js 14 + TypeScript + Tailwind + Shadcn/ui（Web优先，PWA适配移动）
服务层  Supabase（Auth/DB/RLS/Storage） + Railway（长任务：批改流水线、时政抓取、语音处理）
模型层  Anthropic API
        ├─ Orchestrator（总调度，任务路由）
        ├─ 拆题/阅卷/学情/时政/语言润色 Agent（各自独立System Prompt与评测集）
        └─ 人设表达层（统一转译为陪练人设语气，三套风格语料可切换）
内容层  教材知识图谱（四领域/30大概念/页码索引）+ 采分点标注语料库 + 时政源（官方小册子+白名单媒体）
审核层  Human-in-the-loop：AI产出 → 教研审核队列 → 发布（人设语料/生成题目/时政挂接/批改抽查四线覆盖）
数据层  三层信号采集（复用文砺）：结果信号（判分）/ 过程信号（审题耗时、定位路径、修改轨迹）/ 行为信号（使用节律）
```

### 8.2 关键技术设计

1. **Rubric结构化批改**：每题维护机器可读采分点结构，批改输出可解释、可申诉、可被教研抽查，是F3的实现基础；
2. **多Agent可控性**：各后台Agent独立优化与评测，比单一大模型端到端承接更可控，学情Agent的诊断输入直接来自阅卷Agent的采分点输出，形成"评测→诊断→教学→再评测"内部数据闭环；
3. **人设一致性守护**：系统提示分层（安全层/任务层/人设层），长对话滑动窗口检测人设漂移，版本发布前跑一致性回归测试集；
4. **时政流水线**：抓取→AI锚点标注→教研审核→发布，全链路周级节拍、考前提频。

## 九、内容与数据策略（核心壁垒）

- **采分点标注语料库**：以近3–5年南京卷及权威模拟卷为基础，逐题结构化拆解采分点（关键词族/分值/主体维度），这是批改公信力与AI准确性的命脉，也是全国性大厂不会为单一地区单一小学科专项投入的"窄而深"资产；
- **教材知识图谱**：首版由AI辅助生成，特级教师标准审校；
- **情境卡内容资产**：F11情境卡复用F5时政—教材挂接流水线统一生产（抓取→锚点标注→改写为决策卡→教研审核→发布），不单独新增内容生产链路，控制内容边际成本；
- **教研合作**：签约1–2名南京一线道法教师作为审核顾问，兼具内容质量保障与本地化壁垒双重作用；
- **过程数据飞轮**：每轮对话采集的审题耗时、定位路径、修改轨迹，反哺诊断模型精度，形成竞品无法购买、只能靠时间积累的独占数据集。

## 十、合规与安全

| 域 | 要求 | 落地 |
|---|---|---|
| 未成年人保护 | 防沉迷、防情感依赖 | 使用时长节律提示、任务锚定人设、推回真实关系机制、严禁恋爱/暧昧话术 |
| 价值观合规 | 道法为意识形态敏感学科，零幻觉容忍 | 全语料/全生成内容经human-in-the-loop审核；时政仅采信官方与白名单源；核心政治判断类内容调用受限RAG白名单，禁止大模型自由发挥 |
| 生成式AI合规 | 备案与内容审核义务 | 审核层前置，四线全覆盖（人设/命题/时政/批改抽查） |
| 数据合规 | 未成年人个人信息保护 | 最小化采集、家长知情授权、Supabase RLS行级隔离 |
| 学术诚信 | 防止学生把AI当抄作业工具 | 主观题批改默认要求学生先提交自己的作答，AI不在未作答前直接生成完整范文 |

## 十一、成功指标

**先导指标（上线数周内可观察）**：
- 学生自发对话轮次、周活训练次数（目标 ≥3次/周）
- 人设"说教感"负反馈率
- AI批改与教师判分一致率（目标 ≥90%）
- 免费诊断→订阅转化率

**滞后指标（一学期尺度）**：
- 种子用户群模考道法平均分变化（目标 +3分以上）
- 四类失分归因的周环比下降曲线
- 家长满意度与续订率
- 双学科（语文+道法）打包渗透率

## 十三、风险与未决问题

### 13.1 风险登记

| 风险 | 应对 |
|---|---|
| 人设长对话漂移、语料翻车外流 | 一致性守护 + 回归测试 + 全语料审核 + 发布前红队测试 |
| 人设被质疑"AI装学生"引发信任反噬 | 不隐瞒AI身份，首次使用明示"这是AI扮演的陪练角色"；真诚是唯一不会穿帮的设定 |
| 家长误读为"陪聊玩具" | 家长门户以数据与评分标准呈现严肃面，学生端与家长端语言双轨 |
| 判分公信力事故 | rubric可解释输出 + 申诉通道 + 教研抽查机制 |
| 竞品跟进人设化 | 人设可抄，人设+rubric库+本地过程数据三位一体不可抄，窗口期内加速数据飞轮 |
| 小学科付费意愿不足 | 与文砺打包为双学科订阅，共享家长门户与获客渠道 |
| 政策风险（开卷改闭卷、教材改版） | 架构上开卷训练模块与知识图谱模块解耦，保留闭卷模式快速切换能力 |
