### 0.1 一页纸摘要

**开口成章**是一款面向江苏（首期南京）初中生的AI英语听说学习产品。它以译林牛津教材为知识图谱底座，把每个Unit重构为一个可探索的虚拟场景；学生在场景中与具有记忆、性格和剧情的AI NPC进行**真实语音对话**，通过任务与通关机制自然完成词汇、句型、语法、听力、口语的训练；所有游戏行为在后台被隐性测评引擎转译为学情数据，并最终收敛到**江苏省初中英语听力口语自动化考试（满分30分，计入中考总分）**的题型模拟与能力达成。

产品的根本命题只有一句话：

> **江苏中考听说考试本身就是"人机对话"。用AI NPC练口语，不是"游戏化的学习方式"，而是考试形式本身的原生训练。**

### 0.2 产品命名释义

**中文名：开口成章 ｜ 英文名：Echo Quest**

命名逻辑四层，音、义、痛点、题型合一：

1. **音译对位**："开口"（kāi kǒu）与 Echo（/ˈekoʊ/）音型高度近似，中英文名构成谐音互文，无需解释即可双向记忆。
2. **痛点即名**："开口"是本产品要解决的第一痛点（P1画像：不敢开口）。产品名本身就是对目标用户的行动召唤。
3. **题型精确对位**：化用成语"出口成章"。2025年考试改革后"话题简述"的要求即"自行组织语言、成段表达不少于7句话"——**从开口到成章，正是这道5分开放题的字面描述**。产品承诺内嵌于名。
4. **成长弧光**："开口"为起点（敢说），"成章"为终点（成段表达），四字装下等级线 Silent Beginner → English Ambassador 的完整叙事；Echo Quest 的 Quest 则承载通关机制与"寻找自己声音"的旅程隐喻（Follow the echo, find your voice）。

产品线排布：文砺（语文）、知行（道法）为二字典雅系；开口成章为四字，产品线内部对齐场合可用二字简称"**开章**"。

历轮候选留档（决策可追溯）：辞达（《论语》"辞达而已矣"，文脉最深但学生端感知抽象）、寻声（《琵琶行》"寻声暗问弹者谁"，未能承载echo音译）、言境、声临、开口生花、开口如流、开口有戏、开口即达、开口万里、开口即通、开口能言。其中**开口生花**保留为视觉动效资产（见14.1）。

> 定名后置事项：商标与应用商店检索（"开口成章"及"Echo Quest"教育类目），结果记入附录B。

## 1. 产品定位与战略

### 1.1 战略支点：2025年考试改革创造的时间窗口

2025年是江苏省初中英语听力口语自动化考试的改革元年，改革要点构成本产品全部战略逻辑的地基：

| 维度 | 改革后形态（2025起） | 对本产品的意义 |
| --- | --- | --- |
| 考试形式 | 全程人机对话，学生对计算机作答，机器自动评分 | 产品的AI语音对话=考试形式的原生同构训练 |
| 分值结构 | 满分30分计入中考：听对话回答问题10分、听对话和短文回答问题10分、朗读短文5分、话题简述5分 | 30分是明确、可感知、家长高度关注的分值锚点 |
| 关键变化 | **话题简述改为开放性试题**：不再提供要点提示与范文，学生须围绕话题自行组织语言，不少于7句话 | 开放性口语表达无法靠背范文应对，必须依赖真实表达能力——这正是大模型陪练相对传统跟读软件的代际优势所在 |
| 话题来源 | 话题选自译林版教材七上至九上 | 教材知识图谱直接决定训练内容的命中率 |
| 考试时长 | 全程约30分钟，实际作答22分钟（听力12分钟+口语10分钟） | 产品内模考需精确复刻节奏、间隔与作答时限 |

**定位表述（与产品线同构）**：

- 知行 = 第一个为"开卷考试"原生设计的道法教练；
- 开口成章 = 第一个为"人机对话考试"原生设计的英语听说陪练。

传统竞品需要论证"游戏化学习能提分"；开口成章只需要陈述一个事实：**考试就长这样**。

> ⚠️ 待核实（附录B-1）：南京市当年度实施细则（考试日期、模拟考安排、免试政策、题量微调）须以南京市教育局与省教研室（jys.jsies.cn）当年文件为准，产品内考试说明文案上线前须逐条核对。

### 1.2 双层飞轮模型（产品总架构观）

产品由两个互相驱动的飞轮构成：

- **表层飞轮（体验层）**：虚拟场景 + AI NPC角色扮演 + 游戏化通关。职责：激发兴趣、制造沉浸语境、支撑高频开口、拉长有效学习时间。
- **底层飞轮（学科层）**：教材知识图谱 + 隐性测评 + 自适应诊断 + 考试迁移。职责：保证每一次对话都有明确的知识点归属，保证游戏行为可转译为学情证据，保证能力最终收敛到考试题型。

两个飞轮的耦合原则（本产品第一设计铁律）：

> **游戏服务学习，学习不服务游戏。** 任何一个游戏机制，如果说不出它训练的是图谱上的哪个节点、对应考试的哪个能力，即予删除。

### 1.3 与文砺、知行的产品线关系

| 维度 | 文砺（语文） | 知行（道法） | 开口成章（英语听说） |
| --- | --- | --- | --- |
| 考试支点 | 三大板块全卷 | 开卷考·过程技能 | 人机对话·30分听说 |
| 核心方法论 | 感知飞轮、读法体系 | 检索-迁移-规范表达 | 场景习得、任务驱动交际 |
| 信号采集 | 三层信号（应用内测评为主） | 三层信号 | 三层信号（**语音信号为第一层**，客观度最高） |
| 诊断引擎 | 自适应诊断 | 自适应诊断 | 自适应诊断（复用） |
| 审核管线 | Human-in-the-loop | Human-in-the-loop | Human-in-the-loop（复用） |
| 技术栈 | Next.js 14 / TS / Supabase / Railway / Anthropic API | 同左 | 同左 + ASR/TTS/发音评测第三方引擎 |

开口成章是产品线中**信号最客观**的一品：语音的流利度、准确度、完整度可被音素级量化，比作文批改和主观题评分的置信度更高；同时也是**交互形态最重**的一品：实时语音链路、NPC状态机、场景资产都是文砺/知行没有的新模块。共享与新建的模块划分见第13章。

## 2. 用户与需求

### 2.1 目标用户

**首期**：南京市初一至初三学生（译林牛津教材使用区），以初一、初二为主力获取层（听说习惯养成期），初三为模考冲刺层。

**三类典型画像**：

| 画像 | 特征 | 核心诉求 | 产品对位 |
| --- | --- | --- | --- |
| P1 "哑巴英语"型 | 笔试中上，听说薄弱，不敢开口，课堂一节课开口不足3次 | 零社交压力的开口环境、具体温和的纠错 | AI NPC无评判对话 + 三档口语脚手架 |
| P2 兴趣缺失型 | 整体成绩中下，视英语为纯考试科目，抵触背单词刷语法 | 有趣、有剧情、有成就感的学习动机 | 场景任务驱动 + 通关成长体系 |
| P3 冲刺提分型（初三） | 目标30分满分或接近满分，需要精准模考与查漏 | 与真实考试同题型、同节奏、同口径的模拟 | 试炼之塔模考系统 + 错因诊断 |

**间接用户**：家长（学情报告的主要阅读者与付费决策者）、教师（可选的班级端，P2阶段）。

### 2.2 传统模式痛点 → 产品转化

| 传统痛点 | 根因 | 开口成章的转化方式 |
| --- | --- | --- |
| 背单词枯燥、遗忘快 | 词汇脱离语境孤立记忆 | 单词是场景中的"任务材料"，在对话中使用即点亮收集；遗忘曲线驱动旧词在后续NPC对话中自动"埋伏"复现 |
| 语法=刷选择题 | 规则先行、脱离表达 | 语法是任务的"通行条件"：不用出正确时态，NPC就无法理解你、剧情无法推进；先在表达中撞见问题，再由学伴总结规则 |
| 听力=听录音做题 | 材料是死的、单向的 | 听力是生存条件：听不懂NPC的指令就找不到路、买不到东西；支持回溯重听（有代价）与降速脚手架 |
| 不敢开口、说错没人纠 | 课堂开口机会稀缺、纠错有社交压力 | AI NPC可让学生每天开口几十次；纠错全部采用"鼓励+具体建议+再试一次"话术，绝不出红叉 |
| 学了不考、考了没练 | 学习内容与考试题型脱节 | 每个场景任务都标注考试能力映射；单元Boss关=考试题型的场景化预演；试炼之塔=全真模考 |

核心体验转变一句话：**从"今天学习Unit 3的重点句型"，变成"你来到国际学校，需要用英语认识新同学、找到教室、完成社团报名"。** 学生不是在背句子，而是在完成任务。

## 3. 合规与设计红线（P0，先于一切功能）

> ⚠️ **本章为一票否决项。以下所有条目在MVP上线前须经专业法律意见确认，本PRD仅做产品侧风险识别与预设计，不构成合规结论。**

### 3.1 "双减"政策风险（最高优先级法律风险）

本产品属于面向义务教育阶段学生的学科类学习产品，与文砺、知行面临同一政策环境。沿用产品线既定口径：

1. 本PRD及所有对外物料**不出现**：定价与收费模式、提分承诺（如"提高X分""保证满分"）、超前超纲教学表述、贩卖焦虑类文案。
2. 产品形态设计向"工具属性"收敛：自主练习工具、教材同步训练工具，而非"课程""培训"。
3. 运营时段、时长管控预留开关（见3.3防沉迷），以备监管口径变化。
4. 商业化路径（含前期方案中出现的Freemium、订阅、校端授权等）**全部移出本PRD**，另行形成商业备忘录并先行获取法律意见。

### 3.2 未成年人个人信息与语音数据（个保法/未保法）

- 语音是敏感个人信息且用户全部为未成年人：注册须监护人同意流程；语音数据加密存储、明确保留期限与删除通道；发音评测若调用第三方引擎，数据出境与第三方共享条款须专项审查。
- 学情报告仅向绑定监护人开放；不做任何形式的对外排名、成绩公示。
- 不采集与学习无关的信息；不做用户画像广告。

### 3.3 防沉迷与青少年模式

- 单日建议使用时长提示与强提醒（默认设计锚点：日常任务5-15分钟可完成一轮完整学习闭环，产品结构上不制造"肝"的必要性）。
- 22:00后进入静默模式（可配置）；连续使用45分钟强制休息提示。
- 游戏化奖励全部为学习成长型资产（徽章、称号、场景解锁、角色服装），**无抽卡、无概率性奖励、无任何形式的充值消费点**。

### 3.4 虚拟角色情感边界（本产品特有红线）

虚拟学伴与NPC面向未成年人，须预设硬边界：

1. 学伴角色定位为"学长学姐/冒险伙伴/徒弟"，**禁止**任何拟恋爱化设定、暧昧话术、排他性情感依附表述（如"你只属于我""不要理别人"）。
2. 好感度系统封顶且奖励全部为学习内容（隐藏剧情=更高阶语言任务），好感度不与使用时长挂钩，只与任务完成质量挂钩，从机制上杜绝"为刷好感而挂机"。
3. NPC对学生的一切评价话术经过审核话术库约束：不贬损、不施压、不制造愧疚感（如"你三天没来我好难过"属禁用模式；正确模式为"欢迎回来，我们从上次的地方继续"）。
4. 学生向NPC倾诉学习外情绪困扰时，NPC温和承接但不扮演心理咨询角色，超出预设范围即引导"和爸爸妈妈或老师聊聊"，相关对话进入人工审核队列。
5. 大模型输出全链路挂内容安全过滤（政治、色情、暴力、价值观），教育场景采用最严格档位；NPC人设Prompt注入防越狱约束，防止学生把NPC"带偏"。

### 3.5 内容导向

- 场景与剧情融入"讲好中国故事"要素（用英语介绍中国节日、美食、家乡南京），既符合新课标文化意识目标，也是内容导向的正向资产。
- 所有UGC性质的开放表达（学生的话题简述录音等）不进入公开社区，仅用于本人学情与错题本。

### 3.6 家校双层话语体系（V1.2新增）

虚拟场景、角色陪伴、通关机制是激发这代初中生学习兴趣的正当且有效的新型思路，产品内部按设计语言全力建设；同时，面向学校与家长的一切沟通（产品介绍、家长端文案、报告、商务与教研材料）**统一切换为教育话语**——这不是包装：产品的教学法本体（情境创设、任务型语言教学、做中学）正是2022版义务教育英语课程标准的原生要求，双层话语说的是同一件事。

| 内部设计语言 | 家校沟通语言 | 教育学锚点（新课标/公认教学法） |
| --- | --- | --- |
| 虚拟偶像 / 角色偶像化 | **AI学伴**（智能学伴、成长语伴） | 同伴学习、学习共同体 |
| NPC角色扮演 | **情境角色对话** | 情境创设、任务型语言教学（TBLT） |
| 游戏化通关 / RPG | **闯关式任务学习 / 剧情化情境学习** | 做中学、学用结合 |
| 世界观 / 游戏地图 | **学习地图 / 情境地图** | 大单元整体教学 |
| Boss关 | **单元综合挑战** | 单元综合性评价 |
| XP / 等级 | **成长值 / 能力等级** | 过程性评价 |
| 技能树 | **能力图谱** | 核心素养可视化 |
| 好感度 / 羁绊剧情 | **学伴默契度 / 进阶陪伴任务** | 学习动机的关系性支持 |
| 隐藏剧情 / 彩蛋 | **进阶学习内容** | 分层教学 |
| 词汇背包 / 图鉴 | **词汇积累册** | 语言积累与运用 |

执行规则：① 全部对外物料上线前过"话语体系检查"（禁用左列词汇）；② 家长端报告只使用右列语言（11.3双语报告的既有机制扩展为全物料规范）；③ "偶像"一词**全渠道禁用**（含产品内），角色体系对外统称"AI学伴与情境角色"；④ 学生端产品内保留游戏化表达（学生是设计语言的原生受众），双层话语的分界线是"屏幕面向谁"。

## 4. 竞品与差异化

| 竞品类型 | 代表 | 能力 | 缺口 |
| --- | --- | --- | --- |
| 游戏化词句练习 | 多邻国类 | 强游戏化、强习惯养成 | 无教材对齐、无真实对话、与中考无关 |
| AI口语陪练 | Praktika/Gliglish/国内AI口语类 | 自由对话、发音反馈 | 无教材知识图谱约束、无剧情通关体系、面向成人泛场景 |
| 跟读测评工具 | 各类"人机对话模拟"软件、E听说类 | 题型模拟、跟读打分 | 内容是死题库：只能跟读与答题，无法开放对话；恰好覆盖不了2025改革后开放性话题简述的训练需求 |
| 教辅数字化 | 各出版社配套APP | 教材同步 | 练习题搬上线，无交互习得 |

**开口成章的差异化定位**：市场上同时做到以下四点的产品为空集——

1. 教材知识图谱驱动（每轮对话有明确知识点归属，非自由闲聊）；
2. 真实开放语音对话（大模型NPC，非固定录音与死题库）；
3. 完整RPG通关体系（世界观、剧情、成长，非积分皮肤）；
4. 中考听说考试原生对齐（题型、节奏、评分口径同构，直指2025改革后的开放性表达）。

尤其第2+4的组合是时间窗口：改革后"话题简述"的开放性使死题库类产品结构性失效，而大模型产品的自然优势恰好落在此处。

## 5. 知识图谱：产品的学科大脑

知识图谱是底层飞轮的地基。原则：**大模型负责生成与交互，图谱负责边界与目标**——每一次NPC对话在生成前，都由图谱确定"本轮该练什么、能用什么词、不能超什么纲"。

### 5.1 图谱七层结构

以译林牛津初中英语（七上至九下）为唯一首期蓝本，每个Unit拆解为七层：

| 层 | 名称 | 内容 | 在产品中的角色 |
| --- | --- | --- | --- |
| L1 | 单元图谱 | Unit主题、话题域、功能意念（问路/点餐/邀请/建议/表达观点等） | 决定场景与剧情主题 |
| L2 | 词汇图谱 | 核心词/短语/固定搭配，及其主题归属、常见搭配、场景应用、句型嵌入、听力易混对、音标发音要点 | 决定NPC可用词表与"单词收集"任务物 |
| L3 | 语法图谱 | 语法项目绑定真实表达任务（一般过去时↔讲述昨天经历；情态动词↔给出建议） | 决定任务的"通行条件" |
| L4 | 句型图谱 | 教材句型的可替换表达模板族（一句→一组：肯定/否定/疑问/特殊疑问/第三人称变体） | 决定变式练习的生成空间 |
| L5 | 听力能力图谱 | 听关键词/数字/主旨/细节/语气/连读弱读六项子能力 | 决定听力任务的靶向设计 |
| L6 | 口语能力图谱 | 发音准确度/表达完整度/语法准确度/词汇丰富度/流畅度/交际策略六项子能力 | 决定评测引擎的打分维度 |
| L7 | 考试映射图谱 | 每个知识点↔听说考试题型（听对话、听短文、朗读、话题简述）与笔试题型（情景交际、完形、书面表达）的映射 | 决定Boss关与试炼之塔的出题依据 |

词汇图谱条目示例（apple）：主题归属 food/fruit｜搭配 eat an apple, apple juice｜场景 restaurant/supermarket/picnic｜句型嵌入 I'd like an apple.｜听力易混 apple/April｜发音 /ˈæpəl/。学生学到的不是中文释义，而是"这个词在什么场景里怎么用、怎么听、怎么说"。

### 5.2 超纲控制机制（图谱的另一半价值）

大模型天然"会说太多"。图谱同时是**约束器**：

- **词表白名单+灰名单**：NPC台词生成时注入当前进度的累积词表（白名单）；允许少量高频超纲词（灰名单，带即时释义气泡），比例上限10%；灰名单命中率作为NPC生成质量的监控指标。
- **语法复杂度阈值**：按学生当前诊断水平限定NPC句式复杂度（如初一上限：并列句；禁用三层从句嵌套）。
- **动态降维**：学生连续两轮无法理解时，NPC自动改用更短句式+更慢语速+关键词重读复述同一意思（脚手架式降级，不是换话题）。
- **RAG注入**：对话Prompt动态检索当前Unit的目标词汇、句型、语法与功能意念，确保"练的都是该练的"；目标知识点在本轮对话中的出现率为核心质量指标（设计锚点：目标句型每任务至少自然出现3次）。

### 5.3 图谱生产管线（复用产品线方法论）

沿用文砺的图谱生产流程：教材结构化拆解（LLM辅助抽取）→ 学科编辑人工校验（human-in-the-loop）→ 版本化入库（Supabase，图谱表与文砺/知行同构）→ 抽检评估。**图谱数据的每一条目须可追溯到教材页码**，这是后续学情报告"建议复习教材第X页"能力的数据前提。

> ⚠️ 待核实（附录B-2）：译林牛津教材内容的版权边界——图谱中存储教材原句、课文文本的合规方式（改编重述 vs 原文引用的比例与授权路径）须专项法律意见；MVP阶段图谱以"知识点元数据+自研例句"为主，避免大段复制课文原文。

## 6. 世界观与场景体系

### 6.1 世界观设定

**世界观不采用架空魔法设定，采用"半写实近未来"设定**——理由：(a) 中考听说与教材话题全部是现实生活语域（校园、家庭、购物、旅行、环保、科技），魔法世界的语料域与考试语域错位；(b) 半写实场景中习得的表达可直接迁移到考试与真实交流；(c) 与"讲好中国故事"要素兼容。奇幻感通过美术风格与轻科幻要素（全息导览、AI机器人NPC）实现，而非语料域的架空。

**主设定**：学生受邀进入"临江国际学园"（Lingjiang International Academy）——一座坐落于近未来滨江城市的国际学校及其所在街区。学园与街区构成开放地图：教学楼、餐厅、社团中心、图书馆、体育馆、街区商店、地铁站、博物馆、江畔公园……随教材进度逐区解锁。学生的长线身份是"国际交流生"，长线目标是从"沉默新生"成长为能主持学园国际文化节、向世界介绍中国的"金牌交流大使"——这条成长线的终点能力，恰好就是话题简述所要求的开放性成段表达。

### 6.2 Unit→场景推导公式（内容生产的固定管线）

每个Unit的场景化遵循固定八步公式，保证内容生产可流水线化：

## 7. 角色系统

### 7.1 角色三类型

**① AI学伴（唯一贯穿全程的陪伴角色；对外统称见3.6）**

- 人设：学园学长/学姐（男女各一可选），性格温和幽默，英语好但"不说教"。
- 职能：任务引导、卡壳时"心电感应"提示（中文提示/降维句型参考）、温和纠错、任务复盘、错题本讲解。
- **费曼机制（吸收自智谱方案）**：学伴同时是学生的"徒弟"——设定其中文极好但英语某些点"总是搞混"，定期请学生"教"它（如"为什么这里用went不用go？"）。学生用自己的话解释知识点=最高阶的掌握度信号，进入三层信号采集的第二层。
- 红线约束见3.4。

**② 剧情NPC（每场景配置，语料的载体）**

- 每个NPC有固定人设卡：性格、职业、口音（英音/美音，MVP阶段仅用清晰标准音，口音多样性P1再引入）、**词汇量与语速上限**（匹配学生学力）、对学生的记忆（上次对话说过喜欢篮球，本次会问"How was your basketball game?"）。
- NPC记忆是"活的听力材料"与死录音的本质区别：学生说错，NPC能追问；听不懂，NPC能换说法；沉默，NPC能提示；水平高，NPC能加难度。
- 任务型交际设计（Info-gap为主力题型）：学生与NPC各掌握一半信息，必须真实交换才能完成目标（如：学生有地图但不知开门时间，NPC知道时间但需要学生指路）。

**③ 考官角色（试炼之塔专用）**

- 语气中性、节奏严格按真实考试指令语速——刻意与陪伴型角色形成反差，训练考试临场感。

### 7.2 好感度系统（学习成就的情感包装）

- 好感度仅由任务完成质量驱动（表达准确度、任务达成度），与在线时长零相关。
- 好感度解锁物全部是学习内容：NPC隐藏剧情=更高阶语言任务；特殊语音=地道表达彩蛋；"一起创作"=合写英文短文/歌词（书面表达迁移）。
- 好感度封顶，到顶后转化为"羁绊任务"（周期性高质量对话任务），不再数值增长。

### 7.3 NPC反馈话术规范（全局强制）

沿用知行Rubric方法论，为NPC纠错建立话术Rubric，全部话术遵循三段式：

> **肯定具体亮点 → 指出一个（且仅一个）改进点+示范 → 邀请再试一次**

示例（禁止 vs 正确）：

- ✗ "发音错误，得分62。"
- ✓ "你把整句话完整说出来了，很好！只改一个小地方：thirteen和thirty容易混，跟我读两遍——thir-TEEN。再来一次？"

每轮反馈只纠一个主错误（错误优先级：影响达意的语法/词汇 > 影响得分的发音 > 润色级表达升级），避免多点轰炸摧毁开口意愿。

## 8. 游戏化通关机制

### 8.1 任务体系四层

| 层 | 定位 | 节奏 | 设计要点 |
| --- | --- | --- | --- |
| 主线任务 | 与教材单元同步的剧情链 | 每Unit一章，5-7个任务节 | 任务链即知识点链（例：U1入学日→选英文名→向接待员问好→自我介绍→找班级→填信息卡→入学采访→新生徽章） |
| 支线任务 | 补弱专项，由诊断引擎推送 | 按需 | 听力弱→"校园广播站"任务；语法弱→"语法修复站"（NPC机器人说错话，学生修复：He play basketball→He plays）；词汇弱→"超市寻物"收集任务 |
| 日常任务 | 习惯养成 | 每日5-15分钟 | 跟读3句+NPC对话2轮+30秒听力+复习5个到期词汇（遗忘曲线驱动）；启动成本压到最低 |
| Boss关 | 单元综合验收 | 每Unit一关 | 不是打怪，是综合语言挑战，题型即考试迁移（完整点餐对话链/听懂校园广播/3分钟话题简述） |

### 8.2 词汇：收集与埋伏（替代死记硬背）

- 单词是场景中的"材料"：学生在对话中**主动使用**某词，该词点亮进入词汇背包（听懂≠点亮，说出才点亮——强制输出）。
- **遗忘曲线埋伏**：到达复习节点的旧词，由系统自动注入后续NPC对话的生成Prompt，让旧词在新剧情里"自然再现"；学生再次正确使用则巩固度升级。这是"艾宾浩斯"在对话式产品中的原生实现，学生无感知、零复习负担。

### 8.3 语法：任务通行条件（替代选择题）

- 语法点包装为任务的达成条件：向侦探NPC汇报线索必须用一般过去时，NPC（人设限定"只能听懂过去时"）才会推进剧情并交出道具。
- 学生说出"I finded his diary"→NPC困惑追问→学伴提示→学生自我修正"I found..."→剧情推进。**自我修正行为单独计为高价值信号**（掌握度权重高于一次说对）。
- 规则总结后置：先在表达中撞见问题，任务后由学伴用一张卡片总结规则（可入错题本）。

### 8.4 成长体系

- **等级线**（能力叙事而非数字）：Silent Beginner → Word Collector → Sentence Builder → Dialogue Starter → Story Explorer → Fluent Challenger → English Ambassador（对应长线剧情"金牌交流大使"）。
- **技能树五维**：口语流利度 / 听力敏锐度 / 词汇力量 / 语法精准度 / 交际策略。每个节点点开可见对应的教材知识点与掌握度，技能树即学生可视化的自我学情。
- **成就体系**（奖励真实能力而非数量）：First Talker（首次完成英语对话）/ Good Listener（连续听懂5段对话）/ Grammar Fixer（自我修正10次）/ Brave Speaker（连续7天开口）/ Exam Fighter（模考达标）。
- 奖励物：徽章、称号、场景解锁、角色服装、NPC隐藏剧情。**无货币化奖励**（见3.3）。

### 8.5 反模式清单（设计负面约束，评审用）

1. ✗ 只做"英语版游戏"——游戏好玩但学习目标不清晰 → 每个机制须通过1.2的铁律测试；
2. ✗ 只做"AI聊天"——自由闲聊对基础生无效 → 一切对话有任务、有目标知识点、有反馈闭环；
3. ✗ 只奖励数量——做了多少题、说了多少句 → 奖励掌握、修正、迁移；
4. ✗ 冷冰冰打分——"错误，62分" → 全局话术Rubric（7.3）；
5. ✗ 偶像喧宾夺主——纯卖萌、纯换装、情感绑架 → 3.4红线+好感度只挂学习质量。

## 9. 核心学习闭环

### 9.1 五步闭环（单元级）

> **① 教材知识导入**（图谱确定本周目标：词汇/句型/语法/听说目标）→ **② 场景任务激活**（NPC发起真实任务："I lost my schoolbag. Can you help me find it?"）→ **③ AI即时反馈**（发音/语法/词汇/听力/表达五维，话术Rubric三段式）→ **④ 变式练习**（图谱句型族驱动换场景换人物换物品：Where is my schoolbag? → Where are my keys? → The cat is under the sofa.——此步决定学生掌握的是"表达能力"还是"教材原句"）→ **⑤ 考试题型迁移**（同一知识点回到听力选择/朗读/话题简述题型，Boss关验收）

### 9.2 口语三档脚手架（同一任务，三档参与方式）

| 档位 | 适合学生 | 形态 | 示例（点餐任务） |
| --- | --- | --- | --- |
| 跟读模式 | 基础薄弱（P1画像入门期） | AI示范→学生模仿→音素级对比 | Repeat: I'd like a hamburger. |
| 半开放模式 | 中等 | 给关键词，学生自组句子 | Use: hamburger, juice, please |
| 自由模式 | 较强 | 与NPC自然交流完成任务 | Order your lunch by yourself. |

档位由诊断引擎按任务动态推荐，学生可手动上调（鼓励挑战）；连续成功自动建议升档。**同一套场景内容服务三档学生**，内容生产成本不随分层翻倍。

### 9.3 听力三模式

| 模式 | 定位 | 形态 |
| --- | --- | --- |
| 生存听力 | 场景内置，听懂才能行动 | "Go straight and turn left."→学生在地图上选路线；听不懂可用"回溯"重听（消耗道具/轻代价）或降速 |
| 任务听力 | 指令执行 | "Buy two apples and a bottle of milk."→在虚拟商店选对商品 |
| 考试听力 | 题型迁移 | 同语料改造为标准听对话/听短文选择题，按考试节奏播放（一遍/两遍、5秒读题、5秒作答，与真实考试口径一致） |

顺序设计：先在真实语境中听懂（生存/任务），再迁移到考试形式——与"先习得后应试"的总原则一致。

### 9.4 脚手架式失败恢复（产品线共享方法论）

失败不扣分、不红叉、不终止。失败触发的是**降级序列**：NPC换说法复述 → 学伴给关键词提示 → 学伴给中文提示 → 切至跟读模式完成本句 → 记入诊断，后续支线任务自动补弱。学生永远能"走完"任务，差别只在获得的掌握度评级（金/银/铜），且可随时重打关卡刷新评级——重打即复习，复习被包装为"追求金牌"。

## 10. 中考听说模拟系统（试炼之塔）

产品的"最严肃模块"，视觉与话术风格刻意与冒险世界区隔（进入试炼之塔=切换到考试心态）。

### 10.1 题型全真复刻（以2025改革后题型为基准）

| 考试题型 | 分值 | 模拟要点 | 平时训练的对应来源 |
| --- | --- | --- | --- |
| 听对话回答问题 | 10 | 短对话+选择，复刻读题5秒/作答5秒节奏 | 生存听力、任务听力语料迁移 |
| 听对话和短文回答问题 | 10 | 长对话/短文+多题，信息记录能力 | 听力图谱L5的数字/时间/事件靶向训练 |
| 朗读短文 | 5 | 屏显短文+限时准备+录音，音素/重音/语调/流利度四维评分 | 日常跟读任务、U7类朗读专项 |
| 话题简述 | 5 | 教材话题域抽取话题，限时准备，开放作答不少于7句 | **全产品口语训练的总收敛点**：Boss关话题简述、好感度羁绊对话、"金牌交流大使"主线 |

- 全流程复刻：设备试音→指令语音→限时准备→限时作答→自动收卷；总时长、分段时长与真实考试一致。
- 话题简述评分采用"完整度优先"口径（与真实评分中完整度占大头的特征一致）：产品反馈首先鼓励"说满、说完整"，再优化准确与语调——这直接对抗学生"怕错不敢说"的最大失分因素。

### 10.2 评分同源策略

- 发音与朗读评测接入音素级评测引擎（候选：科大讯飞/腾讯云/声通等，均支持音素级与篇章朗读评分）。**选型原则：优先与省考试评分引擎同源或口径最接近的供应商**，使产品模考分与真实考分建立强相关性——"模考分可信"是冲刺层（P3画像）的核心价值。
- 话题简述的内容维度（相关性、连贯性、句式丰富度）由LLM按自研Rubric评分（复用知行Rubric构建标准的方法论），与引擎的语音维度分加权合成。
- LLM评分的稳定性通过双评+抽样人工校准保障（human-in-the-loop复用）。

> ⚠️ 待核实（附录B-3）：省考试实际使用的评测引擎供应商与评分细则未公开部分，须通过教研渠道调研；产品对外表述统一为"参照考试评分维度"，**禁止宣称"与中考评分系统相同"**。

### 10.3 错题本与考前冲刺

- 听错的词对（thirteen/thirty）、说错的句式自动入错题本；错题由LLM变形再生成（换语境同考点），支持"再练一次"与导出打印。
- 考前6周解锁"冲刺日历"：按官方模拟考与正式考时间倒排，每日一组靶向任务（由错题本与诊断数据驱动）。

## 11. 评测与诊断引擎

### 11.1 三层信号采集（产品线架构的英语实例化）

| 层 | 信号 | 采集方式 | 特点 |
| --- | --- | --- | --- |
| L1 语音表现信号 | 音素准确度、流利度、语速、停顿、完整度、自我修正行为 | 每次开口自动采集（引擎+ASR对齐） | **客观、高频、无感**——本产品信噪比最高的信号层，也是相对文砺/知行的独特优势 |
| L2 交互行为信号 | 任务达成度、听力重听次数、提示使用档位、费曼解释质量、剧情选择 | 游戏行为埋点 | 隐性测评（Stealth Assessment）：学生无"被考试"感 |
| L3 结构化测评信号 | Boss关评级、试炼之塔模考分、错题本数据 | 显性测评节点 | 低频、高置信，用于校准L1/L2 |

### 11.2 诊断与自适应

- 每个学生维护一张**动态能力图谱**（与知识图谱同构的掌握度覆盖层）：每个词汇/句型/语法/听说子能力节点有掌握度评分与遗忘衰减。
- 诊断输出驱动四件事：NPC难度参数（词表/句长/语速）、口语档位推荐、支线任务推送、错题本生成。
- 冷启动：新用户首个场景即入学剧情"分班测试"（包装为剧情的摸底诊断，5分钟，听说各半）。

### 11.3 双语报告（吸收自Gemini方案的关键设计）

同一份学情，两套叙事：

- **学生端（游戏语言）**："你在'创客工坊'的'过去时魔法'熟练度还差一点，Bolt有个新任务想找你帮忙。"
- **家长/教师端（学术语言）**："该生在八上Unit 4核心语法'一般过去时'掌握度65%，主要错因为不规则动词过去式（find→found类）；对应教材第X页；建议本周完成2次针对性口语任务。"

家长端报告固定四栏：本周开口次数与时长 / 听说能力五维雷达与变化 / 教材进度同步度 / 下周建议。**报告只呈现成长与建议，不做同伴对比排名**（见3.2）。

### 13.3 实时语音链路设计要点（技术风险第一项）

- 延迟预算：学生说完→NPC开始出声 **目标≤2.0s，上限3.0s**（超过3秒对话感崩塌）。手段：流式ASR（边说边转）、LLM流式输出、TTS流式合成、NPC"思考动作"动效遮蔽尾延迟。
- ASR选型须对**中国青少年英语口音**有优化（这是刚性要求，标准英文ASR对初一学生带口音、有停顿的语音识别率不可接受）；MVP前须做3家引擎的真实学生语音盲测。
- 弱网降级：语音失败自动降级为"录音-上传-回复"异步模式，不阻断任务。
- 录音数据处理遵循3.2：端侧压缩、传输加密、评测完成后原始音频按保留策略处理（默认保留错题相关片段供回放，其余N天后删除，N待法务确认）。

### 13.4 LLM中控的四个子职责

1. **剧情推进判定**：结构化输出（JSON mode）——本轮学生表达是否达成任务条件、触发哪条剧情分支；
2. **语言生成**：NPC台词（受人设卡+词表白名单+句式阈值约束）；
3. **即时评估**：语法/词汇/达意三维快评（供反馈与信号采集）；
4. **防跑偏**：学生偏题时以角色身份自然拉回任务（"That's interesting! But first, could you help me find my schoolbag?"）。

## 14. 视觉与体验方向

### 14.1 风格决策（V1.2修订：机制守红线，美学放开手）

**设计立场修订**。V1.0曾以"双减环境下游戏感过重是风险"为由主张视觉克制——此判断混淆了两类不同的风险：**监管与家长真正敏感的是游戏机制（充值消费、概率奖励、无节制时长、情感操纵），而非美术风格本身**。机制红线已由第3章完整覆盖；在此前提下，视觉与交互层应当充分游戏化——明亮高品质的游戏美学是这一代初中生的默认审美语言，也是"激发兴趣"这一产品第一使命在视觉层的直接兑现。UI/UX的克制不是稳妥，是放弃兴趣战场。

**采用方向：明亮系高品质游戏风"日光学园"**（参照系：蛋仔派对/光遇/摩尔庄园的明亮度与亲和力，而非成人向暗黑系）。全量游戏化组件：**可漫游的学园世界地图**（区域随进度解锁、云雾渐开）、**游戏HUD**（等级/XP条/任务追踪器常驻）、**角色立绘与服装收集**、**词汇图鉴**（收集册式翻页）、**季节与节日限时场景装扮**（呼应U8文化节等运营节点）、开场与Boss关的**剧情演出镜头**。Kimi方案资产全部启用：正向反馈光效（翡翠绿扩散替代红叉）、XP漂浮动效、卡片式悬浮布局、字体规范；其Canvas粒子氛围特效以"性能分级开关"引入（高端机全开、低端机降级为CSS动效）。深色魔法系全局风格仍不采用，但理由收敛为一条：与6.1半写实世界观的语料域错位——这是教学论证，不是观感防守。**试炼之塔单独采用冷灰蓝"考场风"**，用视觉切换建立考试心态——游戏世界越生动，这个切换的心理效果越强。

**品牌动效"开口生花"**（源自命名候选留档，见0.2）：学生每次正确说出/点亮一个目标词汇或句型时，场景对应位置绽开一朵轻量花形光效——词汇背包"使用即点亮"机制（8.2）的可视化外化。花形光效替代通用的对勾/星星，成为产品的标志性正向反馈语言；单元地图上累计的"花"同时构成进度的环境化呈现（花开满园=单元掌握度可视化）。实现层面为Lottie轻量动效，与"日光学园"风格同源。

### 14.2 体验基调三关键词

**安全感**（永远可以说错、永远有台阶下）、**掌控感**（地图/技能树/进度全部可视）、**惊喜感**（NPC记得你、旧词在新剧情里重逢、隐藏剧情）。
