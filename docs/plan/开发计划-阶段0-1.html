〇摘要

这份计划回答什么

完整方案定了"做什么"；这份计划定"接下来 13 周每周做什么、谁做、做到什么程度算完"，以及之后半年如何踩准南京的学年节奏。

三个排期判断

  1. 先盘点，再写接口。四科"初步开发"到底开发到哪一步，是所有适配器设计的前提；W1–W2 只做盘点与契约冻结，不写平台代码。
  2. 数学先接、英语后接。阿鸦是模板科、适配最轻，用它跑通"写入学生模型 → 星图渲染"的第一条端到端链路；英语的语音与跨模型人设一致性是最大技术风险，单独成轨、提前验证、最后接入。
  3. 学年倒排。Gate 1 要求"试点用户 8 周延迟复测改善"，要在 2027 年 6 月中考前拿到数据，试点最迟 3 月底开始；最自然的封闭试点窗口是 2027 年寒假。因此阶段 0 必须在 1 月上旬收口，不能拖。

关键日期倒推：2027 年寒假封闭试点（约 100 户，数学 + 道法）→ 3 月春季学期四科内测（约 1,000 户）→ 5–6 月 Gate 1 评审 → 2027 年暑假扩到约 1 万注册 → 2027 年 9 月新初三开学作为首个商业化窗口。上述学校日历以南京市当年校历为准，日期为规划锚点。

三冲刺 0

这两周不写平台代码。目标是把"初步开发"变成一张可以对账的清单，并据此冻结接口。

盘点项要回答的问题产出

2 真实可用状态方案里的每个模块（文砺 M1–M6、阿鸦 12 Agent、知行 F1–F11、开口成章 F01–F24）：已上线 / 可演示 / 半成品 / 仅方案——逐项打标模块状态表（最重要）

4 模型调用调用了哪些模型与端点、System Prompt 位置与版本、每类请求平均 token、是否有流式调用清单 + 成本样本
5 评测资产评测集、回归用例、人工标注数据、与教师一致率的已有测量评测资产清单

盘点纪律：状态只按"学生今天能不能真的用"打标，不按"方案里写了"打标。英语产品额外盘点（盘点结论：没有 Gemini 链路，见 specs/inventory-echo）：实时语音链的端到端延迟实测、所用 ASR / TTS / 评测供应商及数据流向（是否跨境）。

W2 · 契约冻结与架构决策

  • 学科插件 API OpenAPI v0.9：六方法的请求 / 响应模型、统一返回结构、错误码、超时与重试语义、human_review_required 的触发约定。W2 周五评审，W4 冻结为 v1.0。
  • 学习者 Schema v0.9：ERD 与迁移脚本草稿；skill_node 的学科命名空间；证据 / 推断 / 家长自述三分存；推断记录算法版本与置信度。
  • 错因跨科大类映射表 v0.9：文砺六类、阿鸦十二类、知行四类、英语三维 → 审题 / 定位信息 / 思维方法 / 运算语法 / 表达规范 / 策略时间 / 知识 七大类；教研顾问逐条签字。
  • 架构决策记录（ADR）：01 BFF（TS）与学科服务（FastAPI）分工；02 Supabase 共库分 schema（platform.* / wenli.* / aya.* / zhixing.* / echo.*）；03 编排用显式状态机，LangGraph 仅限复杂多步；04 模型路由接口与供应商优先级（国内首选）；05 事件表分区策略；06 计量账本的一致性模型；07 讲解 DSL 采用 OpenMAIC 子包的范围与许可证；08 英语模型与语音链路的接入方式（原题“英语保留 Gemini 链路”，盘点后改写）。盘点后又新增 09 数据驻留、10 境内托管选型，02 改为 Postgres 共库分 schema，见 docs/adr/README.md。
  • 七项待拍板决策会：产品负责人主持，至少关闭第 1、2、5 项（首发地区与教材版本、四科真实状态、英语技术栈）；第 3 项（监管分类）启动外部顾问；第 4、6、7 项给出决策日期。

冲刺 0 验收：四份盘点文档与模块状态表经各科负责人确认；OpenAPI 与 Schema 通过评审进入 v0.9；八份 ADR 合并；映射表教研签字。

月份学年节点产品与工程人设迁移用户与验证
M4 · 1 月期末考试；寒假开始今日计划跨科编排；错题再练闭环；家长端 v1（周报、额度、授权）知行 → 点点主持 + 方圆出场上线寒假封闭试点启动：约 100 户，数学 + 道法，签同意书
M5 · 2 月寒假；春季开学会员四级在试点内以虚拟额度运行（不收费）；数学白板讲评课上线开口成章：学伴并入点点、考官改为雅典娜（仅在一致性结论通过后）试点首轮延迟复测；家长访谈 20 户
M6 · 3 月春季学期；初三二轮复习四科统一壳正式版；跨科周报与"本周一件事"；家长学院前 20 课文砺 → 妙笔上线（盖笔帽、五色批注）四科内测扩到约 1,000 户；8 周延迟复测起算的最晚时点
M7 · 4 月初三一模模考限时整卷（数学、道法）；模考诊断报告方圆 / 春秋 / 雅典娜形象定稿一模前后能力变化对照
M8 · 5 月初三二模增长阶段工程：队列、缓存、分学科限流、成本仪表盘；2 倍峰值压测家族级回归全量8 周延迟复测数据收齐；续用率
M9 · 6 月中考支付与退款流程（视合规结论）；Gate 1 证据包—Gate 1 评审：批改可靠、延迟复测改善且续用、合规路径明确
7 月暑假历史包启动（阶段 2 开始）春秋上线准备扩到约 1 万注册；9 月新初三为首个商业化窗口

一个取舍：2027 届初三学生（6 月中考）在阶段 1 只能获得冲刺期的部分服务；产品真正完整服务的第一届是 2028 届。因此阶段 1 的冲刺专项以"验证"而非"交付"为目的，对外不做提分承诺，内部重点看延迟复测与续用。

阶段 0–1 的主要风险

风险等级信号应对

十本周就做

国庆前可以完成的十件事

  • 确认团队配置（标准或精简），指定技术负责人与四科盘点负责人；
  • 向四科负责人下发盘点模板（第三章 W1 表），约定 W1 周五交稿；
  • 开通平台单仓与三套环境；集中四科仓库的只读访问权限；
  • 联系外部合规顾问，发出"学科类 AI 一对一业务形态"的咨询需求；
  • 排定 W2 周三的七项待拍板决策会；
  • 起草 ADR 01–08 的标题与决策人；
  • 教研顾问开始逐条审阅错因跨科映射草稿；
  • 视觉开始阿鸦母版定稿；
  • 语音工程整理开口成章实时语音链的供应商与数据流向；
  • 产品负责人确认寒假试点的目标人数、学科与招募渠道。
