〇摘要

v2.0 调整了什么

v1.0 排的是平台基座与四科适配。两个基础核心——知识与成长引擎（KGE）和学生洞察引擎（SIE）——定稿后各带一份 30 周计划。v2.0 把三份计划合成一张：同一个 W1、同一套冲刺、同一组门，并据此调整范围、人员和试点。

三个排期判断

  1. 先盘点，再写接口——这次也盘知识资产。四科"初步开发"到了哪一步、三科知识图谱与题库实际录入了多少，是适配器与知识切片的共同前提。W1–W2 只盘点与冻结契约。
  2. 切片先行，数学与道法先过门。数学结构性最强、道法 Rubric 最成熟，两科切片支撑寒假封测；语文切片随后在 1–2 月完成，英语走能力视图接入。
  3. 学年倒排，对账跟着学校考试走。Gate 1 的延迟复测数据须在 2027 年 6 月中考前拿到，试点最迟 3 月底开始。对账节奏由学校考试决定：1 月期末成绩作基线，3 月月考首次对账，4 月一模、5 月二模再对两轮。

任务包与人审点

每个 Claude Code 任务包写明目标、输入契约、验收测试、禁止修改的范围，编号沿用分册：PLT-xx（平台）、KGE-xx、SIE-xx、ADP-科目-xx（适配器）。以下变更必须人审后合并：Schema 与迁移、权限与 RLS 策略、判分与掌握计算逻辑、判断模板与禁用词表、计量扣次规则、任何 Prompt 与人设语料。数据迁移先在副本演练。

人审不足时的精简方案：寒假封测只保留数学；道法切片与知行人设迁移移到 2 月；英语阶段 0 只做异步批改接入。Gate 0 的五条硬条件中，"知识切片过门"降为"数学切片过门"，其余不降。
