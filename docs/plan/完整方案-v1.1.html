一执行摘要

定位、承诺与核心资产

定位。面向初中生及家长，以南京中考为首个深耕地区，把"识别现有水平 → 定位失分根因 → 个性化教学 → 迁移练习 → 延迟复测 → 调整计划"做成一套长期服务。一个家庭账号下学生按需选科；七科共享学习者模型与点点，保留每科独立的教研、知识图谱、评测和 AI 老师。已初步开发的语文、数学、道法、英语四科优先融合；历史、物理、化学依次建设。

承诺。让学生清楚"我会什么、为何失分、下一步练什么、练后是否真的会了"；让家长看到可追溯的进步证据和本周一件可以做的事。不承诺提分数值、不押题、不预测排名；星图只展示自己的进展，不做同伴比较。

核心资产。两个基础核心沉淀的东西：版本化的知识地图与本地考情、经教研审核的原子与讲解页面、经验证的批改体系（知识与成长引擎）；学生长期学习事件与一本可查账的判断账本（学生洞察引擎）；以及让两者持续变准的教研审核流程。大模型是可替换的推理与交互能力，不是资产。

四个基本判断

  1. 四款产品已经长出了同一副骨架。能力坐标 + 错因分类 + 三层信号采集 + 自适应诊断 + 人机协同审核 + 学科人设 + 家长报告 + 南京本地化。平台不是合并四个 App，而是把这副骨架显性化为共享引擎，让后三科用一半成本长出来。
  2. 七科是南京中考的全部笔试学科（660 分）。做完七科，承诺从"帮一科"变成"帮这场考试"。平台负责共享基座，每科仍窄而深——壁垒锁在采分点语料、验证引擎与本地教研里。
  3. 用户信任来自可检验的认识。画像越准、越可解释、越可纠正，学生和家长越相信这是真正的一对一。所以每一条对学生的判断都要有证据、会被质疑、会被学校考试对账，并让人看见它在变准。
  4. 两大目标统一于一个学习者模型。一对一辅导写入内层学科能力，家庭共成长读取中层学习力与外层家庭环境。没有这个统一模型，通识内容只是又一个公众号。

主线：阶段 0 抽基座、建两个核心的数学与道法切片、做四科适配器原型（0–3 个月，2027 年 1 月上旬过门 0）；寒假封闭试点即两个核心的首轮封测；阶段 1 四科融合上线、点点、会员四级、通识 MVP（3–9 个月）；阶段 2 历史 → 物理 → 化学（9–18 个月）；阶段 3 按真实增长规模化并复制地区包。高考不在本方案范围内。

端首页与核心操作信息边界

典型学习旅程与三层诊断

家长建立家庭并授权 → 学生选科与目标 → 学段 / 教材 / 近期试卷录入 → 低门槛起点诊断 → 生成 2 周学习路径 → 每次 10–20 分钟微闭环 → 每周巩固与错题变式 → 2–4 周延迟复测 → 学生与家长分别看到星图和证据 → 系统更新路径。证据不足时显示"不确定 / 待验证"，一次答对不等于掌握。

诊断分三层：①免费 5–10 分钟入口筛查，给粗略薄弱方向；②分科 20–35 分钟适应性诊断，输出能力点与可信度；③针对试卷或阶段模考的深度诊断，结合错因、耗时与作答过程。关键诊断同等条件复测，避免把题目熟悉度当作学习增益。

六条平台原则

  1. 基座共享，学科窄深。能共享的（学生模型、诊断、审核、人设治理、报告、舞台、计量）下沉平台；不能共享的（考情、图谱、Rubric、验证器、教研）留在学科包。
  2. 前台角色克制，后台 Agent 自由。学生面前只有本科老师和点点；后台 Agent 负责出题、检索、验证、讲解、内容安全、评测。不以自发多角色对话消耗学生注意力。
  3. 先有学情，再有通识。通识内容按学情触发，不按栏目推。
  4. 可信优先于可爱。讲解不能覆盖验证器或 Rubric 的结果；置信度不足时提示复核或转人工。
  5. 不做治疗，做转介。学生心理相关内容止于学习动力与压力管理教育。
  6. 数据是资产，模型是零件。国内可商用模型为首选，通过模型路由接既有 Anthropic / Gemini 开发链；不默认调用境外 API 处理个人信息。

四两个基础核心

知识与成长引擎、学生洞察引擎

v1.1 的最大变化：平台的共享引擎层落定为两个基础核心，并各有一份定稿的方案与开发计划。知识与成长引擎（KGE）回答"教什么、依据什么"；学生洞察引擎（SIE）回答"这个学生是谁、平台凭什么这样认为、怎样让他和家长相信"。v1.0 的"学习者模型"一章由这两份方案取代并细化。

4.4 证据与判断规则

规则内容
信号通道平台内原生作答为主通道；结构化自报与成绩录入为次通道，只作先验；拍照上传为第三通道，C 级识别内容先请学生核对，确认前不生成薄弱结论
证据分级独立做对、变式与跨章题、间隔 ≥ 7 天的延迟复测为强证据；低级提示后做对为弱证据；高级提示或看过讲解后做对只记"辅导有进展"并自动安排无提示变式
掌握估计可解释规则 + 简化 BKT，提示等级调节证据权重；数据足够后试点 IRT；语文英语素材用 FSRS 记忆调度
数据分离事实、证据、推断三层分存；每条数据标明来源（客观记录、学生自述、家长观察、模型推断）；学生与家长说法不同时两边保存，落差作为信号，不取平均
判断账本任何对学生的陈述（星图、周报、老师与点点的"你最近……"）必须对应一条判断，判断带证据、置信度、模型版本、有效期与状态（假设 / 成立 / 待验证 / 推翻 / 撤回）
不推断不推断智力、人格、心理状态与家庭情况；不用摄像头、面部、眼动、声纹推断情绪与专注；不给学生贴层级标签；不用固定"学习风格"

设计学生端家长端

4.6 知识底座的产品化

知识地图按三种学科型建设：结构型（数学、物理、化学，前置依赖图）、能力阶梯 ＋ 素材型（语文、英语，能力点加独立素材网）、观点定位型（道法、历史，大概念 → 观点 → 教材原句投影）。讲解、方法、易错、考情预编译为经审核的页面，Agent 页面优先读取，原子补充事实，向量检索兜底；页面人设中立，人设话术在讲解生成时由各角色外层加上。每科知识切片以"课标承接 100%、留出集无处可标率 < 2%、教师标注一致 kappa ≥ 0.7"作为上线门槛。

五四科融合

已初步开发的四款产品如何接入平台

这是本方案的核心章节。原则只有一条：不重写，适配接入。四款产品各自继续迭代，接入平台的硬要求是"把信号写入统一学生模型、把判分走统一 Rubric 接口、把角色纳入统一治理、把消耗记入统一计量"。其余——各自的引擎、语料、界面、模型链路——按各科节奏逐步靠拢。

5.1 融合原则

  1. 学科插件 API 是唯一硬接口。四科通过适配器实现 diagnose / plan / teach / grade / generate_variation / report 六个方法；内部怎么实现平台不管。
  2. 学生模型是唯一硬数据。能力点、错因、掌握度、证据事件必须写入平台 Schema；各科可保留自己的私有表，但不得成为学生画像的第二真相源。
  3. 人设按规范迁移，不按产品迁移。备考搭子升格为点点，特级教师改为妙笔，英语学伴并入点点、考官定名雅典娜，阿鸦不动。
  4. 英语保留既有模型链路。Gemini 实时语音链是四科里技术风险最高、投入最重的模块，通过模型路由接入，不强制迁移；点点的人设层跨模型一致性是前提验证项。
  5. 前端合并壳，不合并页。统一学生端提供今日计划、星图、七科入口、点点、家长端；各科的课堂页面作为路由模块挂入，先共享舞台组件，再逐步统一。
  6. 计量前置。四科的每一次诊断、批改、讲评、语音都必须带 usage_id 与幂等键经过权益引擎，接入前不得上线付费。

商业策略

初期以免费筛查和已上线单科体验获客；四科稳定后推广"家庭 PLUS 两科""PRO 四科"；七科实装后再开放 MAX 七科。价格不在核算单位经济性与监管路径前给出。按科加购与初三冲刺专题可作附加权益，不形成无法理解的叠加扣费。通识层免费部分作为非学科类前门。模考与诊断保留可复核的交付记录及退款规则。

九通识成长层

由学情触发的家庭教育

内容按"学情信号 → 推送课程 → 家长践行 → 状态回流"运转。家长学院：教育常识与考情认知、陪读方法（"本周做一件事"卡片）、青春期心理与沟通、健康与作息、家校沟通；学生成长课：学习动力、压力疏解、情商与人际（情境决策卡）、自律与时间管理（跨科时间预算工具）。三条红线：不做心理治疗与诊断，出现超出学习范畴的情绪困扰按转介话术引导至学校心理老师、班主任与家长；不用学情制造焦虑；家长自身的学习内容不进入学生模型。v1.1：通识推送只由已上线的中圈指标、学生自述与家长观察触发，不由系统对情绪或压力的推断触发；家庭层数据属于 SIE 外圈，家长可见可删。特别防止点点被理解为现实中的同学、鼓励依赖或对心理健康作诊断。

十容量与经济

100 万用户容量与单位经济（待压测的规划假设）

"100 万用户"定义为累计注册学生上限：日活 15% = 15 万；高峰同时在线为日活 5% = 7,500；其中 10% 正在等待 AI 流式回答 = 750 模型并发；平均占用 20 秒，对应约 37.5 次新请求 / 秒；按两倍突发规划约 75 次 / 秒、1,500 模型并发。实时语音、OCR、模拟考试另建池。容量公式：新请求率 ≈ 模型并发 / 平均占用秒数。

首次性能目标：非 AI API p95 < 500 ms；文字首 token p95 < 3 s；诊断异步任务 p95 < 90 s；月可用性 ≥ 99.9%（目标，按预算与供应商 SLA 调整）。压测覆盖模考开考、支付回调、流式断线重连、队列积压及单模型失效。

单位经济：单月每位活跃学生成本 = 模型 token × 实际单价 + 语音分钟 + OCR 页数 + 存储 / 带宽 + 教研审核摊销 + 客服 / 支付；毛利 = 净收入 − 可变服务成本。每种会员分别观察 P50 / P90 / P99 成本与异常账户消耗；上线前用真实会话测算。降本手段：题库复用、预生成、短上下文、任务模型路由、缓存（不缓存跨学生隐私输出）、讲解态 / 对话态分离。

十一合规与安全

未成年人、安全与上线前决策

上线前必须取得的判断：面向境内初中生销售前，对"学科类 AI 一对一服务是否构成线上学科培训"取得具体业务形态的专业判断；"自主学习工具"宣传口径不能代替分类认定。同步梳理属地教育、电信与网信要求、收费 / 退费规则和已备案模型调用的应用登记适用性。

设计输入：支付主体为家长；监护人同意（不满 14 周岁需家长授权）；年龄适配；AI 身份显著提示（七位老师与点点首次对话均声明 AI 扮演）；时长控制与夜间限制；危机转介；学习对话删除 / 导出；未成年人数据最小化；供应商数据协议；语音为敏感个人信息，发音评测若调用第三方引擎须专项审查出境与共享条款。

审核指标：各科评分与人工教师一致率、错误判分率、可追溯证据覆盖率、低置信度转人工率、身份 / 角色漂移与禁语率；有造成系统性误判的故障时可一键停用该评分版本并重新计算受影响报告。有造成系统性误判的画像模型版本同样可一键停用并重算受影响判断。

v1.1 新增：不推断清单（智力、人格、心理状态、家庭情况；摄像头、面部、眼动、声纹推断；群体到个人的预期）在判断账本层即禁止，并作为自动化测试阻断发布。用途分项授权：个人辅导为必要用途；去标识统计用于服务改进须单独同意；模型训练默认不用，另行设计合法依据与同意。上传原图解析核对完成后按保留期限删除。参考法规：《全国校外教育培训监管与服务综合平台应用管理办法》《未成年人网络保护条例》《个人信息保护法》《生成式人工智能服务管理暂行办法》《人工智能拟人化互动服务管理暂行办法》。
