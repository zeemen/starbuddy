## 常用术语（首次出现时的一句话解释）

- **ADR**（架构决策记录）：把一个技术选择的背景、选项、决定、代价写下来，由负责人签字后生效。目前 01–15 全部是“草稿，待签字”（`W13:22`）。
- **必停项**：CLAUDE.md 规定的、必须由人确认才能合并的改动类别（迁移、权限、计量、契约、判分口径、人设、第三方服务等）。
- **schema**：数据库里的“分区目录”，例如 `platform.*` 放平台数据，`kge.*` 放公共知识。
- **迁移**（migration）：修改数据库结构的脚本；本仓的迁移都还是草稿，由人执行（`W13:55`）。
- **RLS**（行级安全）：数据库按“谁在查”自动过滤能看到哪些行，例如家长只能看到自己孩子的数据。
- **BFF**：面向前端的后端服务（TypeScript），负责账号、权益、计量入口。
- **数据级别 L0–L3**：ADR 09 的分级。L0 非个人数据（题库、代码、合成数据）；L1 去标识化数据；L2 个人信息；L3 敏感个人信息（语音、手写照片、监护关系等）（`adr09:61-66`）。
- **dev / staging / pilot / 生产**：开发、预发布、试点（寒假封测）、正式环境。
- **幂等**：同一个请求重复发送，结果只算一次（例如不重复扣次）。
- **判断账本**：平台对学生所做的每一条“推断性结论”的唯一存放处，带证据、状态与有效期（ADR 13）。
- **星 / 星亮**：星 = 知识节点；星亮 = 该节点的掌握进入“迁移”门槛（CLAUDE.md 术语）。
- **插件 API / 契约**：平台与各科适配器之间唯一的硬接口（`packages/contracts`）。
- **渗透测试**：模拟攻击者检验家长隔离等安全边界；第二轮依赖 ADR 01、10 签字（`PT2:213`）。
