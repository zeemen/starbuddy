# docs 目录说明

- plan/       总纲与计划（2026-09-27 更新）：
  - 完整方案-v1.1.html：总纲，最高依据；
  - 开发计划-v2.0.html：阶段 0 逐冲刺、阶段 1 月度的执行依据（W1 约为 10 月 8 日，Gate 0 约 2027 年 1 月上旬）；
  - KGE-知识与成长引擎-V1.1.html、SIE-学生洞察引擎-V1.1.html：两个基础核心的分册。知识结构、内容成长、掌握计算以 KGE 为准；画像、判断、呈现与异议以 SIE 为准；
  - ClaudeCode执行方案-v1.0.html、OpenMAIC借鉴分析-v1.0.html：仍有效的分册。执行方案里的排期按开发计划 v2.0 理解，任务包格式待 ADR 定稿；
  - 仓库现状与 v2.0 的对照、冲突与待决事项：`specs/plan-v2-alignment/spec.md`。
- personas/   角色规格。点点、七位老师、视觉家族。任何人设改动以此为准。
- design/     视觉与交互原型（单文件 HTML，仅作 apps/web 的视觉参考，不是实现依据）。
- subjects/   四款既有学科产品的原始方案/PRD，是盘点时核对"方案写了什么"的依据。
- archive/    已被取代或合并的旧版文档（含完整方案 v1.0、开发计划 v1.0），仅供追溯，不作为依据。
- security/   攻击面清单（attack-surface.md，引用由 check_attack_surface.py 核对）与渗透测试交接包、报告归档（pentest/）。

注意：方案里写了 ≠ 代码里有。盘点时以代码与可运行证据为准。
