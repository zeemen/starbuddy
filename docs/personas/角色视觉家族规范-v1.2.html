阿鸦、点点与七位老师如何在同一界面里像一家人，又各自住在不同的世界

密级内部
一定位

这份规范要解决什么

角色体系决策已定：点点（搭子）与阿鸦不共享叙事世界观，但共享视觉语言。这份规范定义"共享的部分"具体是什么，让三件事同时成立：放在一个界面里不打架；各自的世界观不被视觉混淆；两年后物理、化学老师能按同一套规则生成，而不用重新发明风格。

三条设计判断

  1. 家族性由四个共享层承载：线、形、色、动。个体性由三个槽位承载：物种与形态、个性色、设定元素。共享层不允许角色级例外；个体槽位不允许家族级统一。
  2. 阿鸦是家族的锚。它是唯一的品牌级 IP，家族的线宽、色板、比例都从它反推得出；后来者向它对齐，它不向后来者妥协。
  3. 导师是有来历的师者，同伴是没有来历的同学。家族内部有一条结构性的逻辑：七位学科老师都是精灵化的师者——可以是动物、器物成精、拟人化的卡通角色，但每位都从一个公版来历里来（伊索寓言、江淹梦笔、阿基米德、化学的 X、《孟子》、史官传统、希腊神话），并有不言而明的师者身份；点点是家族里唯一"像学生"的角色——半拟人、住在现实里、没有来历。这条逻辑让"不共享世界观"在视觉上一眼可读。（v1.2 由"导师是生灵"放开而来）

图 1 · 共享层与个体槽位。审核一个新角色时，先查四个共享层是否全部符合，再查三个槽位是否与既有角色拉开差异。

二线与形

家族基因 · 线

所有角色以描边为主、平涂为辅。线是家族里最先被感知的共性，也是与白板演算、SVG 舞台最协调的语言。

参数规定理由
基准线宽（1 线）角色身高的 1/48；主轮廓 = 1 线相对单位，任何尺寸下比例一致
内部线0.5 线；羽毛、衣纹、设定元素细节均用内部线两级线宽足够，三级以上会失去"简笔"感
讲话者加粗正在讲解的角色主轮廓临时加粗至 1.25 线讲解权的可视化，不用颜色、不用光晕
端点与转角圆角端点；转角半径 ≥ 1 线与阿鸦的圆规、函数曲线一致的"数学线条"
曲线构成只用圆弧与贝塞尔，不用手绘颤线、不用铅笔质感平台气质是理性与克制；颤线会低幼化
描边色浅色主题：鸦青；深色主题：宣白 60% 不透明保证两种主题下轮廓都清晰
禁止渐变描边、投影、外发光（星光金发光除外）、材质贴图家族的一致性主要靠"不做什么"

家族基因 · 形

每个角色的主体由不超过三个基本几何体构成，剪影在 24px 下可辨认并可与家族内其他角色区分。头身比控制在 2.0–2.6：比吉祥物略高，避免低幼；眼高不超过头高的五分之一，这是"七至九年级不排斥"的关键参数。

图 2 · 比例网格与几何构成示意（非定稿造型）。三个角色放在同一网格上，头身比接近但不相同：阿鸦最矮最圆，点点最高最直，视觉上就是"生灵"与"同学"的差别。

剪影测试：任何角色的定稿必须通过三关——24px 单色剪影能认出是谁；与家族其他角色并置时剪影不混淆；去掉设定元素后仍是同一个角色（设定元素是加分项，不是身份本身）。

三色

家族基因 · 色

色板从阿鸦反推：乌鸦羽毛的蓝黑色是家族的骨色，纸的颜色是家族的底色，"星光金"（v1.0 称规律金，随平台定名点斗 StarBuddy 更名）是整个平台唯一的奖励色——它只在能力点通过掌握门槛、星图上该星点亮时出现，任何角色、任何界面都不得把它用作装饰。角色色板固定，不随界面深浅主题变化。

骨色与底色

鸦青 #1F2A44主轮廓、主体平涂的暗部；所有角色共用
羽蓝 #3E5C9A羽光、高光形状；每角色最多一块
宣白 #F4F3EE角色主体平涂的亮部；深色主题下的描边
石灰 #8C9099阴影、静默态降饱和
星光金 #D9A441唯一奖励色：星亮、尾巴发光、碎片、门槛达成。禁止装饰性使用

个性色池（五色，每角色取一，占比 ≤ 10%）

喙橙 #E07A3F阿鸦：只用于喙与脚
湖青 #3F8F9E点点：只用于校服领口
苔绿 #5E8C61阿基：只用于支点 / 杠杆一处
藕紫 #8A6FA8妙笔：只用于笔锋一处（五色笔取其一）
陶红 #C0574FX 博士：只用于一处（如护目镜边或烧瓶口）
规则内容
色彩比例每个角色：鸦青 + 宣白 ≥ 80%，羽蓝 ≤ 10%，个性色 ≤ 10%
个性色位置只能出现在一个部位（阿鸦的喙与脚视为一个部位），不得铺满衣物或身体
个性色分配（v1.2）五色池刚好分给五位有个性色的角色：阿鸦喙橙、点点湖青、阿基苔绿、妙笔藕紫、X 博士陶红。考官型三位（方圆、春秋、雅典娜）不取个性色，只用鸦青与宣白——素色是距离感的一部分，也让三位考官一眼可辨为同一类。这一条同时关闭了"考官型是否取池外色"的待决
星光金不属于任何角色；出现时以描边外发光形式，持续时间见第五章；星图上"亮星"的填充色也是它
学科与色的关系个性色不代表学科，不做"物理 = 蓝、化学 = 绿"的映射；学科识别靠形态隐喻与界面，不靠角色配色
主题适配角色色板不变；深色主题下描边切换为宣白 60%，宣白平涂降为 90% 不透明以免刺眼
可访问性个性色与鸦青的对比度 ≥ 3:1；不用颜色单独承载信息（讲话者靠线宽，门槛靠发光 + 文案）

星形符号规范（v1.1 新增）

平台定名点斗 StarBuddy 后，"星"成为整个界面的进度符号：每个能力点一颗星，每科一片星空。星不是角色，但它与角色同台，所以纳入家族规范：同一套线宽、同一块星光金、同一种克制。

图 2b · 星的三态。五角、圆角端点、描边 1 线；半亮对应掌握门槛的中间层，让"快亮了"可见而不虚报。

规则内容
形状五角星，转角圆角半径 = 1 线；不用四角闪光、不用六角、不用光斑
三态未亮 / 半亮 / 亮，对应掌握门槛的"理解、执行 / 稳定、迁移"三段；"保持"层用亮星外一圈细描边表示，复测失败退回半亮
点亮动效与第五章星光金发光一致：1.2 秒播一次，不循环；阿鸦尾巴发光与星亮同一时刻
最小尺寸16px 下三态仍可区分（靠填充比例，不靠颜色深浅）
禁止星不出现在同伴视角；不做"星数排行"；不把学习力、家庭维度画成星；星不作为角色的装饰元素贴在身上
其他意象鲤鱼、桂花、龙门、朱衣等命名讨论中出现过的意象不进入产品视觉
四表情

家族共用的五个教学表情

角色不做"喜怒哀乐"的通用表情集，而做"教学状态"表情集。五个状态对应教学动作，每个角色用自己的形态实现同一组状态；点点额外实现两个 AI 同学专用状态。这保证两个角色在同一课堂里的情绪节奏一致，也避免了为角色画一堆用不上的表情。

状态触发的教学动作阿鸦实现点点实现禁止
静默学生作答中、老师不出声眼微闭，尾巴静止，呼吸幅度 2%侧身半退，视线朝白板眨眼卖萌循环
思考验证器计算中、等待结果头微偏，圆规耳一侧轻抬手（若有）托下巴的简化姿态转圈加载动画贴在角色上
追问苏格拉底式提问、强制思考动作身体前倾，喙微张，星图眼聚焦身体前倾指向学生的手势
肯定某一步做对、门槛达成喙合拢上扬；门槛达成时尾巴发光（与星亮同步）点头一次跳跃、撒花、连续动作
示弱"这题我第一次见也绕了一下"耳朵垂下，视线下移挠头的简化姿态夸张的哭脸
犯错（点点专用）AI 同学出场给出错误解法—自信姿态（错得理直气壮，才有纠正价值）预先露出"我在装"的表情
恍然（点点专用）学生指出错误后—眼睛睁大一拍，随即点头过度感谢

阿鸦的三个设定元素（耳、尾、眼）各自参与两到三个状态，这是它们"不是装饰"的另一层证明。设定元素的出现频次上限仍遵守阿鸦规格书 2.2。

五动

家族基因 · 动

动效原则只有一条：角色只在教学动作上动。学生在思考时，屏幕上不应有任何东西在争夺注意力。

项目规定
静默态只有呼吸：整体缩放 ±2%，周期 4 秒；无眨眼循环、无摆尾循环
状态切换表情切换 200–300 ms，缓动 ease-out；一次只变一个部位
讲话喙 / 嘴的开合与语音包络同步，幅度小；不做口型对位
星光金发光描边外发光由 0 到 6 线宽再回到 0，总时长 1.2 秒，只播一次；不循环、不闪烁；角色发光与星图上的星亮共用同一动效
出场与退场点点从舞台左下淡入（300 ms），退场淡出；阿鸦不出场不退场，它一直在
减少动态偏好系统开启 reduce-motion 时：呼吸关闭、发光改为静态描边变色、切换改为直接替换
实现SVG + CSS 动画优先；复杂状态用 Rive 或 Lottie，但资产必须能导出为静态 SVG 供离线包与家长端回放使用
六舞台

角色在舞台上的位置与尺寸

舞台以白板为主体。老师锚定在右下（与书写方向一致，角色不遮挡演算的起笔处），点点从左下出场，尺寸略小于老师——讲解权的层级用位置和尺寸表达，不用颜色。星图不在课堂舞台内常驻，只在开课定位与门槛达成两个时刻以小图短暂出现。

图 3 · 舞台布局。老师常驻右下，点点仅在 AI 同学环节从左下出场；学生作答时两者都退让。英语的 NPC 场景不适用本布局，沿用开口成章自己的场景舞台。

规则内容
老师尺寸桌面 / 平板：舞台高 22%；手机：18%。永不遮挡白板当前书写行
点点尺寸老师的 0.85 倍；同台时长 ≤ 课堂 20%（工程约束来自两份规格书）
学生作答态两个角色缩至舞台高 12%，饱和度降为 60%，表情切换为"静默"
讲解权可视化讲话者主轮廓 1.25 线 + 对话条名字加粗；不用颜色、不用光圈、不用箭头
开卷双科（道法 / 历史）点点主持课堂，占用老师锚点（右下），尺寸按老师规格
家长端不出现任何角色形象；白板回放中保留角色但不做包装
七个体基因

三个槽位的填写

阿鸦（已定，本规范据此反推）

槽位内容
物种与形态大嘴鸦；椭圆身 + 三角喙 + 曲线尾三个几何体；头身比 2.2
个性色喙橙，只用于喙与脚
设定元素圆规耳（画图）· 函数尾（变量关系）· 星图眼（定位已知所求）；规律碎片与尾巴发光是机制不是外形
签名动作追问时身体前倾、喙微张

点点（建议方向，待决）

决策记录要求"非动物、非写实真人、低细节半拟人"。三个候选方向：

方向描述优点风险判断
A · 文具拟人书包、便签、笔袋之类的现实物件拟人化住在现实里，识别度高低幼；与"学长"身份冲突；难做示弱与恍然表情不建议
B · 线稿同学圆头 + 胶囊身，只有眼睛与嘴，无鼻无发型细节，性别中性；穿南京学生校服的轮廓，领口一处湖青与"住在学生现实里"完全一致；低细节规避恐怖谷；中性；与阿鸦的"生灵 / 同学"结构对比清晰；与"点点"这个名字的轻盈感匹配可能显得"空"；需靠姿态而非五官表达状态建议
C · 几何生灵与阿鸦同类的抽象生灵家族感最强违反"不共享世界观"；学生会把它当成阿鸦的同类不建议

方向 B 的设定元素建议不超过两个，且都是"学生的东西"：一支笔（记忆与约定——点点记东西时拿出来）、一块手表或手环（日程与节律——提醒时抬手看）。两者都绑定点点的职责，不绑定任何学科。名字"点点"与"点亮"同源，但**不把星画在点点身上**——点点是点亮星星的人，不是星本身。

新角色的生成规则

  1. 来历先于形象。先有一条能讲清的出处链（来源 → 学科对应 → 师者身份 → 信条），再定形态；形态不限动物，可拟人，但须有不言而明的师者身份。
  2. IP 边界。只从公版来源延伸；借原型不借造型；形象定稿前做相似性自查（《七科 AI 老师角色规范》v1.1 第四章）。
  3. 设定元素各绑一个教学功能，常驻型 ≤ 3、考官型 ≤ 1；名字与元素不得与既有老师重复。
  4. 个性色：五色池已分配完毕；新增常驻型角色需先扩池，考官型一律素色。
  5. 头身比在 2.0–2.6 内且与既有角色错开，保证剪影区分。
  6. 通过第八章全部测试后，才可进入语料与动效制作。

关于文砺教师（v1.2 已决）："产品化的特级语文教师"改为妙笔——一支笔成精的主笔。它进入视觉家族。文砺的逐句朱批仍然是它的"脸"，只是这张脸现在有了一个身体：笔。v1.0 的"不进入家族"建议作废。
