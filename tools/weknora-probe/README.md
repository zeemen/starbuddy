# tools/weknora-probe · WeKnora 技术验证探针

对应 `specs/kb-weknora-integration/weknora-validation-plan.md`（v0.2，已确认，随 staging 集群暂缓）第四节里能自动化的验证项。
只用标准库；只对**测试知识库**运行，只写**合成数据**；报告不含地址、密钥、正文与查询原文。

> 接口形状按 WeKnora 官方文档（`website-docs/04-api`，2026-11-03 初读，v0.9.0）写成，**还没有在真实实例上跑过**。
> 第一次对测试库运行时先跑 `--probes V11`，按报告里的 `hit_keys`、`outer_keys` 修正 `weknora_probe/client.py` 的字段映射。

## 探针

| 项 | 名称 | 判定 | 说明 |
|---|---|---|---|
| V03 | 鉴权与最小权限 | 自动 | 无密钥、错误密钥被拒；只读密钥能检索、不能写入、不能访问白名单以外的库 |
| V07 | 多维“且”过滤 ★ | 自动 | 合成“同名不同版”干扰集（同一知识点 5 个省份 / 出版社 / 版本组合）；比较三种做法：允许清单（`knowledge_ids`）、组合标签、按维度分库；测多个单维度标签之间是“且”还是“或”；测允许清单长度 10 / 100 / 1000 时是否被接受与耗时 |
| V08 | 元数据承载量 | 自动 | 20 个字段能否写入、第 21 个是否被拒、检索结果是否带元数据 |
| V09 | 稳定 ID 与更新 | 自动 | 重复写入的行为；整篇替换后新内容可检索、旧内容不再命中；删除后检索不到 |
| V11 | 纯检索接口的返回形状 | 自动 | 记录返回字段名；能否拿到切块 ID、文档 ID、分数、正文 |
| V16 | 公式与表格 | 自动 | `$$…$$` 公式块与 Markdown 表格是否在同一切块里完整返回 |
| V17 | 检索查询是否落库或留日志 ★ | **人工** | 发出 3 次带金丝雀字符串的纯检索；生成只读扫描 SQL（`v17-canary-scan.sql`），由数据开发团队在测试库的数据库上执行，并在日志与 Redis 里搜索金丝雀；结论由合规负责人确认 |
| V18 | 结果不回写 | 自动 | 检索前后文档内容与元数据不变（时间、计数类字段除外，报告里列出被忽略的字段） |

计划里的其他项（V01、V02、V04–V06、V10、V12–V15、V19、V20）需要人工或在集群里做；V12（检索质量）在 `evals/kge-compile` 里做，见那里的 README。
关键项（V07、V17 等标 ★ 的）不通过时，报告与退出信息会写“按计划先停下，交用户决定”（已定事项第 4 条）。

## 运行

地址与密钥由数据开发团队发放，只限测试库，**不写进仓库**：

| 环境变量 | 必填 | 说明 |
|---|---|---|
| `WEKNORA_TARGET` | 是 | 必须是 `test`，防止误对生产库运行 |
| `WEKNORA_BASE_URL` | 是 | WeKnora 地址（只开内网） |
| `WEKNORA_API_KEY` | 是 | 测试库的写入 + 检索密钥 |
| `WEKNORA_KB_ID` | 是 | 测试库 ID |
| `WEKNORA_RETRIEVE_API_KEY` | 否 | 只有检索能力的密钥（V03 最小权限） |
| `WEKNORA_OTHER_KB_ID` | 否 | 只读密钥不应能访问的另一个库（V03） |
| `WEKNORA_PARTITION_KB_IDS` | 否 | 逗号分隔，至少 2 个测试库（V07 按维度分库） |
| `WEKNORA_INDEX_TIMEOUT` | 否 | 等待建索引的秒数，默认 120 |

```bash
cd tools/weknora-probe && python3 -m weknora_probe --out <报告目录>
```

可选 `--probes V11,V07` 只跑部分；`--keep` 保留本次写入的合成文档（标题前缀 `sbprobe-<run_id>-`）。
退出码：0 没有失败项；1 有不通过或出错；2 参数或环境错误。

## 测试

`make weknora-probe-test`：对进程内的模拟 WeKnora（`weknora_probe/fake.py`，只监听 127.0.0.1）运行全部探针。
模拟服务按文档描述的语义实现（标签之间是“或”、元数据最多 20 个字段），并带缺陷开关：打开过滤失效、不校验密钥、替换不生效、
删除不生效、检索改动文档、切断公式表格时，对应探针必须判失败。模拟服务不代表 WeKnora 的真实行为，真实结论以测试库为准。
