# 执行手册：真实试点的 Gate 1 证据核对（只读，本仓不执行）

对应 `specs/gate1-evidence-sie04/spec.md` 范围 4。**本仓 CI 不执行本手册，也没有连接试点库的代码**；本仓只有合成管线
（`make gate1-evidence`，样例见 `sample/`，标“合成，不是试点结论”）。真实核对的取数脚本另起任务实现，照搬
`tools/e2e-cohort/e2e_cohort/verify.py` 的只读护栏；用哪一份结果作 Gate 1 证据由人判定。

## 0. 前置条件（缺一不可，任何一项不满足就停止）

| # | 条件 | 负责人 | 记录 |
|---|---|---|---|
| 1 | 试点学生的监护人同意已签署，用途包含“学习效果评估与预测核对”（`platform.consent_record` 有对应条目） | 合规 / 产品 | 授权记录编号（下文 `AUTH_REF`） |
| 2 | 试点环境在境内、已完成部署评审；只连试点库，**不连生产**（规则 9） | 平台负责人 | 环境名 |
| 3 | `config.unsigned.json` 的每一节已由 SIE 负责人、教研、产品签字（signoff 不再是“待签字”，`signed_by / signed_at` 已填）；签字前只能出“对照未签字阈值”的结果 | SIE 负责人 | 配置指纹 |
| 4 | 8 周复测点已按 KGE-05 打开、作答用途映射已确认（本管线不改这两项） | KGE 负责人 | 开关记录 |
| 5 | 已开通一个**只读核对登录**（第 1 节），由 DBA 发放、用完即停 | DBA | 登录名、有效期 |

## 1. 只读护栏（与 Gate 0 核对相同，任一不满足即拒绝、返回 2、不写输出）

- 连接串只从环境变量读，不写命令行、不进仓库、不进日志；
- 连上的库名必须等于 `--expect-db`；登录角色不能是超级用户；
- 会话必须只读（`default_transaction_read_only = on`，每条查询在 `READ ONLY` 事务里执行）；
- `--out` 解析后不能落在仓库目录之内（汇总不进仓库）；输出目录必须不存在或为空（与 `write_pack` 的规则一致）。

**读取方式：只经定义者只读汇总视图（推荐且唯一可行的形态）。** 个人层表都是 `FORCE ROW LEVEL SECURITY`，普通只读角色读到 0 行，
报表会“全部样本不足”却什么也没核对。核对角色不直接读个人层表，只调用一组 `SECURITY DEFINER` 的只读函数 / 视图：
按授权名单过滤、在库内完成按学生的聚合，**只返回聚合值**（计数、比率、按学生聚合后的配对值或组内统计），不返回学生 ID、作答、分数明细。
这组函数是 RLS 与权限策略变更，**必停项**：由人确认后另起 PR（迁移 + 测试），本任务不写迁移。
`BYPASSRLS` 角色**不可用**于本核对（会让核对角色看到全部个人层明细，与“只出汇总”相冲突）；如确有必要也只能另起必停 PR 由人决定，不作为并列选项。

## 2. 取数口径（与合成管线同一套报表纯函数）

只读出报表需要的最小字段，在执行机内存里喂给 `gate1_evidence/reports.py` 的同一组纯函数：

| 报表 | 读什么 | 喂给 |
|---|---|---|
| G1-2 8 周复测 | 首轮与 8 周后复测作答的当前判分（只 correct / incorrect） | `improvement` |
| G1-2 续用 | 授权名单内全部入组学生的入组时间（含从未使用者）与会话开始事件的时间 | `continuation` |
| G1-3 考试对账 | 冻结的预测区间、预测依据（`exam_prediction.basis`）、实得分数 | `exam_report`（区间内外由洞察服务 `reconcile_plan` 判；中值一律用 `gate1_evidence/basis.py` 的 `predicted_median(basis, 满分)`，即依据里的得分率均值 × 满分、保留一位，不用其他来源的中值） |
| G1-4 效度 | 测量时点以前的作答事实（洞察服务 `metrics.py` 的输入形状）与之后的结局 | `validity_pairs` 的同一计算 → `student_pairs`（按学生聚合）→ `validity_report` |
| 附加 分组误差 | 预测依据与实得 + **已签字的**非敏感分组键 | `fairness_report`（中值同样用 `predicted_median`） |

口径说明（都待签字，见 `config.unsigned.json` 的注释）：
- **改善是幸存者口径**：只有首轮与 8 周后都做够题的学生进入配对；中途停用、没有 8 周后复测的学生不进入改善的计算，
  只体现在续用率里，改善可能被高估。汇总里必须同时报告配对人数与续用率，不能单独引用改善。
- **续用率分母**是授权名单内入组学生中观察窗完整者（入组后第 56 天起 14 天的窗口不晚于数据截止），**含入组后从未使用的学生**（计为未续用）；
  不能只从会话表取学生，否则会漏掉从未使用者。
- **样本门槛按学生计**：考试每轮、分组每组同时要求记录数与不同学生数；效度先按学生聚合（各科取均值），一名学生一对。

分组键只能用签字时列明的非敏感键；**不用地区、学校、家庭推断，不从群体推给个人**（规则 12）。SIE 分册原文“不同学校”一项待人确认。

## 3. 只输出汇总

- 输出只有汇总：每项报表的计数、比率、相关系数、组间差距与 `insufficient_sample / 对照阈值` 的结果、配置指纹、授权编号；
- **不输出任何学生级明细**（没有学生 ID、节点、作答、分数）；合成管线里的逐学生 CSV 只在合成数据上生成；
- 每项都带最小样本门槛：样本不足时只写 `insufficient_sample`，不出结论；
- Gate 1 判定仍写“满足 / 不满足 / 无法自动判断（需人）”之一，由人在 `docs/gates/gate-1-evidence.md` 填写，不下总体结论。

## 4. 停止条件

任一前置条件缺失、连接的不是试点库、输出里出现任何学生级字段、需要写入才能继续、或取数范围触及留出集——立即停止，
记录在 `specs/gate1-evidence-sie04/lessons.md` 的“待人确认”。
