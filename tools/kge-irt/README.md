# tools/kge-irt：IRT 试点评估第一步（KGE-10，离线、只用合成数据）

对应 `specs/kge10-irt-pilot/spec.md`。回答“在现有作答量下，IRT 题目参数是否比先验难度更好、IRT 预测是否比现行掌握估计更准”。
**结论只是评估报告**：不替换先验难度、不改掌握计算（BKT 与五道门槛不动）、不写库、不连库、不调用模型、零迁移、不改契约。
替换先验难度或改掌握计算另起必停任务。

> **真实导出必停。** 本步只接受 `synthetic=true` 且伪名为 `syn-` 开头的输入。读试点作答与掌握估计的只读导出函数
> （可复用 KGE-09 的导出草案 `tools/kge-calibrate/sql/`）、授权与放开 synthetic 守卫，须另起 `[NEEDS-HUMAN]` 任务、经人确认；
> 在那之前不得做任何真实导出，流程演练只用 `python -m kge_irt synth` 生成的合成数据。

> **不是真相源（规则 2）。** `irt-report.json` 顶层 `"not_a_source_of_truth": true`。输出不得写入 `kge.item_tag` 或 `platform.*`，
> 不得被知识服务、适配器、审核台导入。“先验难度疑似标错”只是候选、仅供教研参考：修改先验难度走 KGE-02 打标流程，
> 不得照抄或换算本报表的 IRT 值；按候选修改先验另起 `[NEEDS-HUMAN]` 任务。

## 用法

```bash
cd tools/kge-irt
PYTHONDONTWRITEBYTECODE=1 python -m kge_irt synth --out <空目录>/in
PYTHONDONTWRITEBYTECODE=1 python -m kge_irt run --items <空目录>/in/items.json --responses <空目录>/in/responses.csv \
    --baseline <空目录>/in/baseline.csv --out <空目录>/out
```

输出 `irt-report.json` 与 `irt-report.md`（首段“合成，不是试点结论”），逐字节可复现；目标目录必须不存在或为空，文件 0600 独占新建。
测试与变异：`make kge-irt-test`、`make kge-irt-mutation`（接在 `make check` 末尾）。样例 `sample/irt-report.md`；JSON 以 sha256 固定在测试里。

## 输入

| 文件 | 内容 | 层 |
|---|---|---|
| `items.json` | 题目快照：`item_id`、`node_id`（= `kge.item_tag.main_node_id`，只计主节点，次要节点不计）、`cognitive_level`、`item_type`、`prior_difficulty`（`kge.item_tag.prior_difficulty`，[0, 1]，越大越难，可为空）、`family_code`（= `kge.item_family.code`，可为空，只随报表列出） | 公共层 |
| `responses.csv` | 伪名 × 题目 × 节点 × 对错 × 时间序 `seq` × 段 `segment`（fit / eval）；每名学生每道题一行（独立作答的第一次，口径同 KGE-09） | 个人层，只在内存 |
| `baseline.csv` | 同一切分点上现行掌握估计的掌握概率：伪名 × 节点 × 认知层次（与 `platform.mastery_estimate` 同粒度） | 个人层，只在内存 |

切分点由导出决定（基线就是在这一刻取的），工具核对 fit 段时间序全部早于 eval 段、拟合比例落在配置范围内（报表只写配置范围）。
守卫直接复用 `tools/kge-calibrate`（元数据行、synthetic、伪名格式、个人信息列名与单元格、读前限长、行数上限、题目 ID 格式与 UUID 拒绝）；
快照里的题目 ID、题型、题目族编码同样过 `looks_personal`。synthetic 标记取自元数据。

## 口径

- **模型**：P(答对) = σ(a(θ − b))，θ ~ N(0, 1)。按节点分块，1PL（块内共同区分度）与 2PL（各题区分度）；另有对照“先验难度 + 能力”
  （b = c0 + c1 ×（先验 − 0.5））。边际最大似然 + EM，Gauss–Hermite 固定节点（默认 15），M 步 Fisher 得分 + 步长减半（广义 EM，
  目标单调不降，测试逐轮核对），参数界与先验在 `config.json`，初值由拟合段正确率确定，无随机性。
- **现行掌握估计基线**：BKT 参数、证据权重、来源权重、错因系数一律从 `baseline.source` 所指的学习服务掌握配置读取（不抄数值）。
  预测 = p (1 − slip) + (1 − p) × p_guess(题型)，p 取该题单元（主节点 × 认知层次）在切分点的掌握概率，没有记录的用 p_init。
  合成基线按学习服务同一口径重放（独立作答、A 级、日常练习来源、默认错因系数，强度 = |证据权重| × 等级 × 来源 × 错因，同一题目族
  只计第一次）；测试在同一合成输入上调用 `services/learning` 的 `replay` 逐个核对，差 < 2e-6。
  非合成输入时 `baseline.source` 必须是已签字（`signed_by`、`signed_at`）且 `synthetic=false` 的掌握配置，否则拒绝。
- **BKT + Platt**：基线概率 logit 上的逻辑回归校准，按记录键把后段学生分两半交叉拟合。
- **只用先验难度**：σ(β0_节点 + β1 ×（先验 − 0.5）)，按节点截距、共同斜率，在拟合段汇总上拟合。
- **评估**（后段作答）：对数损失、Brier、AUC，六种方法同一批作答。每名学生每道题只有一行，后段只含该生在拟合段没答过的题；
  拟合段没人答过的题、没有先验难度的题不评估（后者从两种先验对照中剔除，为保持配对也不进其余方法，报表给出题数）。
  “有拟合数据”与“冷启动”（拟合段在该块没有作答，IRT 用先验 N(0, 1)）两组分开报告，各自过人数门槛。
- **每生一个点**：对数损失与 Brier 先按学生平均再对学生平均；AUC 按 1 / 该生后段作答数加权。
- **判定**：每生配对差 d = 对照 − IRT（该生平均对数损失），均值与配对自助法区间（按学生重抽，固定种子）各只加一次 ±2 格扰动
  （粒度 = 2 × ln(1/clip) ÷ 扰动后人数）。**有效门槛**：公开区间下端 > 0 且公开均值 ≥ `min_logloss_gain`（0.02）才写“IRT 更好”，
  对称地写“IRT 更差”，否则“差别不大”。人数约 480 时粒度 0.02，即均值至少 0.02、且区间扣除扰动后仍不含 0。
- **稳定性**：2PL 自助法（块内学生有放回重抽，固定种子），插值分位数区间；**可能偏窄**（次数与每次轮数有限，见 `bootstrap`，且不含模型误设）。
- **秩相关**：公开的 IRT 难度与先验难度的 Spearman；**先验难度疑似标错**：按节点对公开值做 Theil–Sen 稳健直线，残差绝对值超过门槛
  且 2PL 自助法区间不覆盖直线上的值，列为候选（仅供教研参考）。
- **可识别性告警**：作答人数不足、接近全对或全错、区分度或难度接近参数界、块内学生不足不拟合、未收敛（只在扰动后块人数达标时给）。

## 防泄露（规则 13；沿用 KGE-09 与 PLT-17 的先例）

- 只输出题目级与节点级聚合；不输出学生能力、后验、伪名、作答次数、实际拟合比例；出口检查渲染文本里不得出现任何输入伪名。
- 题目：表键 = 拟合段作答过该题的学生集合（`kge_calibrate.calibrate.set_key`）；答对、答错两格各加 −2…+2 扰动，扰动后人数 ≥ 24
  （真实 ≥ 20）且两格 ≥ 22 才给参数（同 KGE-09 精确正确率门槛），人数向下取整到 10。
- 参数与区间端点：取整到格点后按表键加 −2…+2 格。区分度格点 0.1；难度格点逐题按单人影响上界加粗
  （≈ 1 / (a n p (1 − p))，取 0.1 × {1, 2, 5, 10} 中第一个 ≥ 2 倍影响的值，a、n、p 只用公开值与扰动后计数）。
- **1PL 与 2PL 难度各用独立扰动**（与审查 S2 的偏差）：共用一个扰动会让两者之差（取整后）精确公开。合成队列上的强攻击者实测
  （知道其余所有人作答、逐题反转此人对错重拟合）：共用扰动时 51 次检查有 20 次能定出此人对错，独立扰动时 0 次（3 名学生，含人数刚过门槛的稀疏题）。
- 评估指标：组内学生（扰动后）≥ 22 才给；粒度 = 取值范围 ÷ 扰动后人数（向上取到格点），再加 −2…+2 格；AUC 的正例占比门槛只看
  扰动后的两类按人加权总量（留余量），占比恰在门槛时不由精确值决定。
- 秩相关、疑似标错与判定只由公开值算出。
- 测试：删一人重跑（人数、指标、AUC 单人影响）；强攻击者对难度逐题反事实重拟合，真实情况必须相容、被定格的不超过 10%；
  对应变异（去掉各项扰动、表键与成员无关、门槛不留余量、AUC 占比用精确值、1PL / 2PL 共用扰动、难度格点不加粗等）全部被发现。
- 合成队列 487 人（避开取整到 10 的边界）。

## 限制与残余风险

- **表键扰动不是差分隐私**：合成队列上强攻击者 51 次检查没有定格，但这只是一个合成样本；扰动只有 ±2 格，单人影响跨过半格且扰动
  恰在边上时仍可定格（测试的容忍上限是 10%）；同一批人多次导出会进一步泄露。
  区分度没有单调方向，扰动对它的保护只靠格点与门槛。是否改用差分隐私与 KGE-09 待确认项一并决定。
- 难度格点本身由扰动后计数与公开区分度决定，可能在档位边界随一人翻转（只透露极粗的信息，未单独防护）。
- 学生总数与块内人数跨取整档会透露“少了一人”（不透露其作答）。
- 静态 IRT：不建模学习（合成真值也是静态的，所以合成上 IRT 必然占优，**不能**外推到真实数据）；单维；不含猜测参数（3PL）。
- **基线口径的简化**：只重放 BKT 的掌握概率，不重放门槛状态机、复测、置信度与衰减（基线预测只用掌握概率）；证据口径固定为独立作答、
  A 级、日常练习、默认错因系数，不区分提示、迁移、延迟复测、B 级、诊断来源与错因大类；真实导出须按同一口径筛选或另行对齐。
  未校准的 BKT 基线没有按题目难度调整，校准偏差会抬高它的对数损失；Platt 只修正整体偏差。
- **Platt 校准的取法**（与审查“拟合段校准”的偏差）：拟合段没有逐次作答前的掌握概率（只有切分点上的），在拟合段校准会用到
  “看过答案”的概率；改为后段按学生两折交叉拟合（用另一半学生的后段作答）。若导出能提供拟合段逐次作答前的掌握概率，可改回。
- 分块只支持节点；主题 / 学科分块需地图快照，题目族不共享参数。“先验难度 + 能力”结构里没有先验的题按先验 0.5 参与拟合（不评估）。
- 小组（冷启动、稀疏节点）的粒度与判定门槛很粗，方法间差别看不出。

## 待人确认

1. 最少作答人数（20）、两格门槛（20）、时间切分比例（0.5–0.9，合成 0.7）、求积节点数（15）、参数界（b ∈ [−4, 4]、a ∈ [0.25, 4]）
   与先验（`difficulty_prior_sd` 2、`log_discrimination_prior_sd` 0.5、`prior_slope_sd` 5）、`min_block_students`（50）、
   自助法次数（参数 30、配对 200）与每次轮数（30）。
2. “IRT 更好”的判定门槛（`min_logloss_gain` 0.02 + 配对区间不含 0）；达到后是否建议试点替换先验难度。
3. 分块粒度（节点 / 主题 / 学科）与题目族内是否共享参数。
4. 疑似标错门槛 `prior_mismatch_logits`（1.0）、接近参数界 `near_bound_steps`（1）、秩相关最少题数 `min_items_for_rank`（5）、
   概率截断 `prob_clip`（0.01）、AUC 占比门槛（0.25）。
5. 真实导出函数与授权（必停，另起；可复用 KGE-09 导出草案）；基线须换成已签字的学科掌握配置（现 aya 配置 bkt 段为空，合成样例用测试占位配置）；
   导出是否提供拟合段逐次作答前的掌握概率（决定 Platt 在哪里校准）；基线口径简化是否可接受。
6. 扰动机制是否改为差分隐私（同 KGE-09 待确认 3）；1PL / 2PL 难度用独立扰动（偏离审查 S2，理由见上）是否接受。
