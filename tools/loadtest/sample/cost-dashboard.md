# 成本仪表盘（PLT-17 第一步）：合成，不是试点结论；价格为示例价

> **合成，不是试点结论；价格为示例价**。消耗聚合行与调用记录都是固定种子的合成队列（`python -m loadtest dashboard-synth`），只用于检验口径与报表；价格表是占位示例，不是任何真实供应商的价格。档位为导出时档位，期内升降档未拆分；统计窗口为每名学生的当前计费周期（滚动 30 天，与自然月不对齐，导出时可能未满；month 列为周期开始的月份），多个周期时按人取月均。

> 只出聚合：每名学生一个点；组人数加 ±2 的确定性扰动，扰动后 < 22 只写“样本不足”（保证真实人数 ≥ 20），公开的人数为扰动后人数向下取整到 10；P50 / P90 为相邻两秩插值后粗化（消耗到该档额度的 5% 一档、使用率到 5%、成本到 0.1 CNY），P90 以上不足 5 人时 P90 写“样本不足”；不含伪名。额度取草稿配置 `v12-pilot@1`（迁移 0015，未发布）。单位：CNY / 学生 / 月。

队列：学生数 约 200，月份 2026-09。
